## 第 167 轮 · 屏幕空间反射

- 提交：Renderer `bd744a6 → 12e2b63`；Test `082807e → 8e2b5c3`（均已推送）。
- **根因结案**：UBO `view_proj` 为 glm 列主序直写，反投影本就正确；上一轮「法线错误」实为**通道序误读**（sRGB(0.866)=239、sRGB(0.5)=188，实为 `(0, 0.50, 0.87)`），反射为 0 的真因是目标立方体放在了镜面后方。
- **实现**：`inverse(view_proj)` 反投影 + `dFdx/dFdy` 法线 + 世界空间步进（8..48 步，探针视深与表面视深差 ≤ 厚度判命中）+ 屏幕边缘淡出。
- 验证：强度 0 **最大差 0**；强度 1 产生 **48 像素**反射差异；后处理链 **59 / 59**；全量回归 **1007 例 / 62 套件 / 1007 通过 / 0 失败 / 0 跳过**；校验 0 消息；Debug ＋ Release 0 error。
