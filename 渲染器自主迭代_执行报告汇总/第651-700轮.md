## 第 661 轮 · 阴影纹素上限钳制 ＋ 级联切换带自动淡化（深研方向八 B1 剩余）

- `Light_Data.shadow_texel_max`（世界单位 / 纹素，0 = 关闭）＋ `shadow_cascade_blend_auto`（0 = 关闭）＋ `Scene_Data` 透传 ＋ 四个门面方法；
- 钳制：每片半径先按 `r ≤ 上限 × 分片边长 / 2` 收紧（单级用阴影图边长、多级用边长 / 级联数），再算机位 / 深度 / 正交投影 / 纹素对齐；半径外片元按既有口径受光（覆盖面收缩）；
- 自动淡化：仅自动开启 ＋ 显式比例 0 ＋ 级联数 ≥ 2 时，按 `4 / 分片边长`（切换带半宽 ≥ 2 纹素）取 [0.005, 0.1]，显式比例 > 0 时优先；
- 诊断：`Frame_Stats.shadow_texel_world`（多级取最大片）与 `cascade_blend_applied`；
- 用例 4 例（默认不干预并逐字节复原 / 钳制后面收缩 / 自动建议与显式优先 / 扁平透传）；场景 **160 / 160**（241.3 s）；
- 发现：大半径下「跨度 × 偏置」的法线偏移等效世界量会超过遮挡间距导致自阴影失效（既有现象，钳制通过收紧半径缓解）；
