## 三、方案

1. 新建 `Application/Test/src/单元测试/Renderer/渲染聚光阴影测试.cpp`，套件名仍为 `Renderer_Level_Test`；
2. 新文件匿名命名空间内复制所需辅助：`level_dir` / `level_utf8` / `write_text` / `write_cube_assets` /
   `write_eight_spot_level` / `changed_pixels`（以及用例实际引用的其它小工具，逐例核对）；
3. 原文件删除对应 TEST 块与仅被它们使用的辅助（保留其余用例仍在用的）；
4. CMake 采用 `GLOB_RECURSE src/*.cpp`，新文件无需登记；改后须重配测试层一次。

## 四、验收

1. 关卡套件用例数不变（**68**，17 例仅换文件）；
2. 全量 **1334 例 / 77 套件 / 0 失败** 不变；
3. 逐例断言与打印文本零改动。

## 五、风险

- 辅助函数被两侧共用时易误删：以「先复制、后删除」为序，构建失败即回退；
- `write_eight_spot_level` 等生成 `out/关卡测试/` 同名文件，两文件共用目录无冲突（同一 TU 内顺序执行）；
- 中文用例名与文件名的编码须保持 UTF-8 无 BOM。
