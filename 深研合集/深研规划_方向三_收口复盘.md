## 二、复开发必读

1. **参数通道**：offset 80 尺寸 / 96 四参 / 112 颜色 / **128 extra**（第 401 轮扩块；设备 < 144 时整块降为 128 并拒绝 extra）。
2. 自定义阶段一律用 `post_stage_vec4_set` / `post_stage_color4_set` / `post_stage_extra_set`（`param4_set` 带调色范围校验，会被整次忽略）。
3. 阴影采样：后处理集 `binding 4` 为方向光阴影图；级联选择、阴影图 X 切片、32 位打包深度解码必须与 `场景.frag` 完全一致。
4. 体积光阴影的「空气点」无法被遮蔽（屏幕空间朝光源采样结构的限制）；遮蔽表现为几何点受光判定与光路截断。
5. 改着色器后 Test 必须 `cmake -S/-B`；新增门面后 Test 需构建 **`RendererIncludeSnapshot`**。
