# 深研预研 · 多盏聚光灯阴影（图集方案）

> 状态：预研（第 498 轮，2026-11-02）；未实施。
> 上游：`深研预研_聚光灯阴影.md`（方案 A → 方案 B 已落地，单盏、按序号遮蔽）。

## 一、现状与限制（已落地事实）

| 项 | 现状 |
| --- | --- |
| 阴影目标 | `spot_shadow_target` 单张 RGBA8 1024²，与方向光阴影同参数 |
| 描述符 | set 1 `binding 9`，`sampler2D spot_shadow_map` |
| UBO | `spot_view_proj`（304..319）＋ `spot_shadow_extra.x`（320，深度跨度）；`spot_shadow_params`（300..303） |
| 选择口径 | `spot_shadow_index` 0..7 → 前向槽位；Cluster 路径用 `Light_Record.reserved` 同口径 |
| pass | 方向光级联之后追加**单级**聚光 pass（清整幅、同管线、push 矩阵） |
| 签名 | `shadow_signature_build` 已混入 `spot_view_proj` 16 浮点 |

限制：**同一时刻只能有一盏聚光灯投影**；多盏聚光灯需要切换序号并重绘整张图，开销翻倍。

## 二、候选方案

### 方案 1：图集 2×2（最多 4 盏）— 首选

- 阴影目标仍为单张 1024²，但按 512² 切成 2×2 四个视口；
- 每盏聚光灯一轮 pass，`vkCmdSetViewport/Scissor` 限定到各自瓦片，**不清整幅**（首次清一次）；
- UBO：`spot_view_proj` 每盏一份 → 需扩为 `mat4[4]`（64 浮点）；`spot_shadow_extra` 扩为 `vec4`（每盏跨度）＋ 瓦片坐标；
- 片元：`spot_shadow_factor(world, normal, index)` 按 `index` 选矩阵与瓦片 uv 偏移；
- 关卡：`light spot_shadow_index` 允许 0..3（瓦片号），或保留 0..7 但按「灯序号 → 瓦片序号」映射；
- 代价：UBO 324 → 约 420 浮点（1680 字节）；阴影 pass 最多 4 次；每瓦片分辨率降到 512²。

### 方案 2：`sampler2DArray` 分层

- 目标改为 4 层数组纹理（1024²×4），`binding 9` 改 `sampler2DArray`；
- 每盏一个图层，`gl_Layer` 由几何/片元选择（Vulkan 需 `shaderDrawParameters` 或实例化写入）；
- 片元 `texture(sampler2DArray, vec3(uv, layer))`；
- 代价：描述符类型变更（全链路 view 类型改动）、显存 ×4、无瓦片分辨率损失。

### 方案 3：多目标各一张图（每盏独立 1024²）

- `spot_shadow_target[i]`，binding 9..12（或数组）；
- 质量最高、显存最高（4 张 1024² RGBA8 ≈ 16 MB）；
- 描述符布局需扩 3 条，池系数再乘。

## 三、方案对比

| 维度 | 方案 1 图集 2×2 | 方案 2 数组层 | 方案 3 多目标 |
| --- | --- | --- | --- |
| 显存 | 1×1024²（不变） | 4×1024² | 4×1024² |
| 每盏分辨率 | 512² | 1024² | 1024² |
| 描述符改动 | 无（仍 sampler2D） | 类型变更 | 新增 3 条 |
| 着色器改动 | 瓦片 uv 偏移 ＋ 矩阵选择 | 采样类型 ＋ 层选择 | 多采样器选择 |
| 实施风险 | **低** | 中（全链路 view 类型） | 中（布局/池） |
| 适用盏数 | ≤ 4 | ≤ 4（可扩） | 任意（受显存） |

**结论：先做方案 1**（不动描述符，风险最低）；若后续需要 4 盏以上或 1024² 质量，再评估方案 2。

## 四、方案 1 落地步骤（下窗口执行顺序）

1. **UBO 扩容**：`SCENE_BLOCK_FLOATS` 324 → 420（1680 字节），新增 `mat4 spot_view_proj_tiles[4]` ＋ `vec4 spot_shadow_tiles[4]`；
   同步 `管线.cpp` 两处 `buffer_info.range` 与 `渲染场景数据测试.cpp` 断言（纪律：三处必须同改）。
2. **数据侧**：`Light_Data.spot_shadow_index` 语义改为「瓦片号 0..3」；`scene_apply` 收集**全部**有效聚光灯（最多 4 盏）并写入各自矩阵。
3. **阴影 pass**：循环 4 盏；首盏清整幅，其余只 `vkCmdSetViewport` 到瓦片；
   签名（`shadow_signature_build`）混入 4 份矩阵。
4. **着色器**：`spot_shadow_factor` 增瓦片参数（`tile_size = 0.5`、`tile_origin` 由 `index` 换算）；越界 uv 需 `clamp` 到瓦片内，避免跨瓦片采样。
5. **关卡语法**：`light spot_shadow_index <0..3>`（原 0..7 兼容：≥4 视为关闭并告警）；
6. **测试**：两盏各一瓦片遮蔽差异 > 800 像素；第 3 / 4 盏独立；序号越界 0 差异；分辨率切换仍同步（单目标，天然一致）；Cluster 路径同口径。

## 五、风险

1. **瓦片接缝**：512² 下软阴影采样可能跨瓦片，需 `clamp` 或半像素内缩；
2. **清屏口径**：多盏 pass 必须只在首盏清整幅，否则后续瓦片被清掉；
3. **性能**：最多 4 遍阴影 pass，绘制项翻倍；需在 720p 实测 GPU 帧增量（预期 +0.2–0.5 ms）；
4. **语义变化**：`spot_shadow_index` 从「灯序号」变为「瓦片号」，需同步更新关卡文档与既有用例（46 例中 4 例受影响）；
5. **Cluster 口径**：仍以 `Light_Record.reserved` 匹配前向槽位，瓦片映射在 CPU 侧完成，着色器只吃瓦片号。

## 六、验收口径

- 关卡：至少 4 盏聚光灯各自遮蔽，差异像素独立可辨；
- 场景：UBO 1680 字节断言通过；旧语法 0..7 越界用例改为告警回退；
- 全量：1311 例基线不回退；
- 性能：4 盏开启相对单盏 GPU 帧增量记录到 `性能基线_方向七.md`（或新建）。

## 八、已实施（第五百零七轮）

实现**偏离**预研方案 1 的一处：`Frame_Context::render_to_target` 不支持自定义视口 / 剪刀，
无法把 4 盏灯渲染进单张图的 2×2 瓦片，故改为：

| 项 | 实际落地 |
| --- | --- |
| 目标 | `spot_shadow_targets[4]`，**4 张独立 1024²**（瓦片 1..3 按需创建，首次开启多盏时建立） |
| 描述符 | set 1 `binding 9` 一条，`descriptorCount = 4`（同一 binding 的 4 个数组元素），池系数 10 → 13 |
| UBO | 324 → **384 浮点（1536 B）**：304..367 四矩阵、368..371 四跨度、372..379 槽位→瓦片 |
| 关卡 | 新增 `light spot_shadow_all <0|1>`（缺省 0） |
| 着色器 | `sampler2D spot_shadow_map[4]` ＋ `spot_view_proj_tiles[4]` ＋ `spot_shadow_spans` ＋ `spot_shadow_slots[2]`；按槽位映射取瓦片，采样器走显式四分支 |
| 兼容 | `spot_shadow_all` 为 0 时仅瓦片 0 参与，行为与 494 轮单盏完全一致 |
