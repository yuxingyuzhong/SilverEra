# 方向二 · 阶段 E 预研：软粒子（深度淡入）

> 状态：**仅预研，未实现**（2026-11-01 第 359 轮，窗口收口二之后）
> 基线版次：Renderer `ec660a8` / Test `61bb964`；粒子外观已可配（颜色覆盖 ＋ 软边宽度，见导航 `粒子系统.md` §5.12）

## 一、目标与判据

粒子与场景几何相交时，默认 Alpha 粒子会在交线处出现硬切边（半透明圆盘被不透明表面截断）。
软粒子（soft particles）用场景深度对粒子片元做「离表面越近越透明」的淡出，消除硬切边。

验收判据（建议写入用例）：

1. 同一枚粒子靠近地面时，其底缘像素 Alpha 明显低于远离地面时（整幅通道累加值下降 ≥ 20%）；
2. 关闭该功能（默认）时画面与基线**逐字节一致**（沿用粒子既有「默认关闭不变」约定）；
3. CPU / GPU 直接 / GPU 间接三条路径同口径（与颜色覆盖 / 软边一致的推送块与断言方式）。

## 二、现状约束（已核实）

| 事实 | 出处 |
| --- | --- |
| 场景 pass 主渲染期间**不能**同时采样本 pass 的深度附件（附件处于 DEPTH_ATTACHMENT 布局，且写入未完成） | Vulkan 布局 / 读写冲突 |
| 场景 pass 结束后，若开启 MSAA 深度解析，单采样深度会被解析出来，供景深 / 深度描边 / SSAO 等后处理读取 | `渲染器.h` §「MSAA 深度解析」（第一百九十轮） |
| 已有「每帧槽深度历史 ＋ mip 金字塔」（HiZ），`hiz_history_ready(slot)` 可查询就绪，但**未公开图像句柄** | `渲染器.h` `hiz_enable_set` / `hiz_history_ready` |
| 粒子三条绘制路径的推送块为 128 B：`0..15` 相机 / 尺寸、`64 / 80 / 96` 外观（后两 vec4 已用） | 导航 `粒子系统.md` §5.10 / §5.12 |
| 粒子管线与场景管线共用管线布局（set0 场景 / set1 采样器），粒子 `粒子.frag` 不采样任何纹理 | `渲染器.cpp` `particle_draw_ensure` / `粒子.frag` |

## 三、两条可行路线

### 路线 A：上一帧深度（帧延迟，改动最小）

- 数据来源：复用 HiZ 的每帧槽深度历史（同一尺寸的 `R32_SFLOAT`）；
- 通道：粒子片元新增深度采样（建议放在 set1 的空白 binding 或独立 set2，CPU / GPU 两套粒子管线同步改布局与描述符集）；
- 深度比较：`scene_depth = 线性化采样值`、`particle_depth = 由 gl_FragCoord.z 换算`，`soft = clamp((scene_depth − particle_depth) / range, 0, 1)`，`alpha *= soft`；
- 参数：新增 `Particle_Params::soft_depth_range`（世界单位或视图深度差，0 = 关闭；默认 0 保持画面不变）；
- 优点：无需额外 pass，开销只有一次纹理采样；
- 缺点 / 风险：**一帧延迟**（快速运动相机下粒子遮挡会「慢半拍」）；深度历史需与当前相机严格同尺寸（窗口 / 目标切换要重建或回落关闭）。

### 路线 B：同帧深度预 pass（精确，开销更大）

- 场景 pass 前先渲染一遍**仅深度**（只写 D32 深度附件，无颜色输出，跳过材质与光照）；
- 录制顺序：深度预 pass → 屏障（`DEPTH_ATTACHMENT_WRITE → SHADER_READ`）→ 场景 pass（深度附件仍为读/写，或改用复制副本）；
- 需要把同一深度图像同时作为「附件」与「采样源」→ 必须**深度副本**（`vkCmdCopyImage` 到一张 `DEPTH_SAMPLED` 图）或双深度附件；
- 优点：同帧精确、无延迟；
- 缺点：多一遍几何提交（与主 pass 顶点量级相近，对百万实例场景不现实）；需要新增帧模块通道与内存副本（每帧槽一张深度拷贝）；
- 裁剪建议：仅当「软粒子已启用且粒子量 ≤ 某阈值」时才走路线 B，其余回落路线 A 或关闭。

## 四、推荐与实施顺序（若进入阶段 E）

1. **先做路线 A 的参数与关闭不变式**：`soft_depth_range = 0` 时零改动；参数校验 [0, 1] 视图深度差（或世界单位）；
2. HiZ 深度历史公开只读句柄（或新增「上一帧深度采样」专用描述符绑定），粒子管线补深度采样与描述符集；
3. 用例：A/B 对照（关闭 / 开启同一粒子靠近地面的底缘 Alpha 累加）+ 三路径同口径；
4. 若延迟问题影响成品观感，再评估路线 B（单独一轮，先做预 pass 骨架与耗时基线，再决定是否默认启用）。

## 五、开放问题（进入开发前需拍板）

1. 路线 A 的一帧延迟是否可接受？（若相机高速平移会明显）
2. `soft_depth_range` 用「世界单位」还是「视图空间深度差」？前者直观，后者与投影精度线性可分；
3. MSAA 场景下读哪张深度：解析后的单采样深度（延迟一帧）还是多重采样样本 0 直读（需要 `texture2DMS` 与额外准备）；
4. 深度历史资源当前随 HiZ 开关惰性创建；软粒子是否应独立开关（避免被 HiZ 关闭拖累）？

## 六、结论

现阶段粒子已具备「颜色 / 软边」两项外观参数，软边只影响圆盘自身轮廓，**无法解决与几何相交的硬切边**。
阶段 E 的收益明确，但路线 A 有帧延迟、路线 B 有整遍几何开销，需按上表开放问题先做路线决策再实施。
