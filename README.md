# 白银纪元 · agent 工作站

本仓库（`doc` 分支）存放「白银纪元」项目的**工作站文档**，不含项目源码。
项目源码在 `https://github.com/yuxingyuzhong/SilverEra.git` 的 `main` 与各层分支（`engine` / `system` / `test` / `game`）。

## 为什么需要这份索引

「任务报告合集」按《agent开发指南》的约定，在分支目录内再按**创建年／月／日**三级隔离（`main/2026年/10月/03日/<报告目录>/`），日期层级之外仍是**「新增功能_代码推送哈希值」**命名（多笔提交用 `+` 连接）。「项目导航合集」则仍是平铺命名、**不含日期**。哈希是内容寻址的，与时间没有对应关系；而文件系统与 GitHub 网页又都按**目录名的 Unicode 码位序**排列，不按修改时间排列 —— 就项目导航而言，目录列表看上去仍是乱的（最新的一份往往夹在中间）。

**因此，判断版次先后请以本文件与各合集下的 `README.md` 为准 —— 它们都按时间倒序维护，最新的在最上面。**
