## 仓库基本信息

- 顶层仓库：`https://github.com/yuxingyuzhong/SilverEra.git`
- 当前分支：`main`
- 远端分支：`main`、`system`、`engine`、`game`、`test`、`doc`
- 工作区结构：`Engine/{EngineCore,EngineSystem}` ＋ `Application/{Test,Game}`（`Engine` 为**聚合层**，无嵌套 `.git`，随顶层入库）
  - `EngineCore` / `EngineSystem` / `Test` / `Game` 各自为**独立 git 仓库**，顶层仓库以嵌套方式统辖它们
  - 因此顶层仓库的提交只反映各层的子模块/目录指针变化，各层自身的提交历史需分别在其仓库内查看
  - 2026-10-03 起顶层**不再做源码快照**（git 不收录含自身 `.git` 的子目录），只记录目录指针
