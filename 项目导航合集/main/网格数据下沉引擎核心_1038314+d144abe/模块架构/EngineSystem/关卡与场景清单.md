## 一、模块介绍

- 源码：`Engine/EngineSystem/src/scene/`
  - `Level/关卡数据.h`：中立关卡数据 `Level_Camera / Level_Light / Level_Fog / Level_Material / Level_Data`，字段与默认值逐字段对齐渲染层 `Camera_Data / Light_Data / Fog_Data`（应用层只做逐字段拷贝，不做语义换算）。
  - `Level/关卡文本.h` ＋ `core/关卡文本.cpp`：`level_text_read / level_text_write`、材质实例 `level_material_find / _update / _add / _remove`。
  - `Level/core/关卡变换.cpp`：`level_transform_build`（T·R·S，列主序 4×4，欧拉角 XYZ）。
  - `Manifest/场景清单.h` ＋ `core/场景清单解析.cpp`：`Scene_Mesh_Ref / Scene_Mtl_Ref / Scene_Place / Scene_Manifest`、`scene_manifest_parse`（文件）与 `scene_manifest_parse_lines`（内存行，供关卡资产段落复用）。
- 迁移来源：`Application/Renderer/src/render/Level/`（整目录删除）与 `Asset/core/场景清单加载.cpp`（删除）；语法、错误口径、`%.9g` 往返逐位一致等约束原样保留。
- CMake：本层 GLOB 收录 `src/scene/*.cpp|*.c|*.h|*.hpp` 并登记 `src/scene` 为配置依赖。

## 二、公开接口

| 接口 | 语义 |
| --- | --- |
| `level_text_read(path, out)` | 行式语法解析（`level/version/camera/light/fog/material/mesh/mtl/place`）；失败清空输出 |
| `level_text_write(level, path)` | 固定顺序写出；写出前校验版本 ≥ 1 与全部浮点有限；失败不落盘 |
| `level_material_find/_update/_add/_remove` | 按实例名查表 / 整体替换 / 追加（上限 256、同名拒绝）/ 删除首个匹配 |
| `level_transform_build(pos, rot_deg, scale, out)` | `M = T·R·S`；可直接交给 `mesh_draw` 系列 |
| `scene_manifest_parse(path, out, 实例名表)` | 文件版清单；至少一条 `place`，ID 重复 / 引用未知 ID / 未知指令均失败 |
| `scene_manifest_parse_lines(lines, out, 实例名表)` | 内存行版（关卡资产段落），语法与错误口径同文件版 |

## 三、内部实现

- 文本层：`std::ifstream` 逐行 + `std::istringstream` 分列；数值解析用 `strtof/strtoull/strtoll` 且要求完整消费、有限值；浮点写出统一 `%.9g`（32 位浮点可唯一还原）。
- 关卡文件上限 2 MiB、资产行上限 20000、材质实例上限 256、点光/聚光各 8 盏；失败用「清空守卫」保证输出为空。
- 清单解析仅做语法与引用检查（`place` 的网格 ID 必须存在；材质列须命中实例名或材质库 ID），不校验 OBJ/MTL 存在。
- 路径按 UTF-8 解释（`EngineCore::detail::string_to_path`）。

## 四、设计要点

- EngineSystem 不依赖渲染层：渲染层 `Camera_Data` 等仍归渲染层，应用层用 `level_camera_map / level_light_map / level_fog_map` 逐字段映射后 `scene_apply`。
- 数据类型与文本 IO 同属系统层；应用层装配桥只消费，不复制语法逻辑。
- 渲染层 `level_save / level_load / level_unload / scene_load / scene_unload / scene_draw` 全部删除，`apply_scene` 开关随之消失。

## 五、运行链路

```text
关卡文件 ──level_text_read──▶ Level_Data
                               │
应用层 关卡装配桥 ◀────────────┘
  ├─ scene_manifest_parse_lines(asset_lines) ─▶ Scene_Manifest
  ├─ mesh_load_obj / material_load_mtl（渲染层资源门面）
  ├─ 填 Asset_Scene（对象 / 材质 / 实例覆盖）
  ├─ level_camera/light/fog_map + scene_apply（可选）
  └─ level_bridge_draw → mesh_draw_sections
```
