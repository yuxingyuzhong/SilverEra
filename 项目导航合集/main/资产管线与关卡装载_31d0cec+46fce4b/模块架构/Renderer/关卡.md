## §1 模块介绍

`src/render/Level/` 是「关卡即数据」的数据层：把关卡名、相机 / 光照 / 雾三组、资产声明行收进 `Level_Data`，
提供**行式文本双向读写**与**摆放变换矩阵构造**。模块只依赖 Vulkan-free 的
`Scene/场景数据.h`，不建 GPU 资源；资源装配与场景应用由门面完成。

## §2 公开接口

| 名称 | 签名 | 说明 |
| --- | --- | --- |
| `Level_Data` | `struct { std::string name; Camera_Data camera; Light_Data light; Fog_Data fog; std::vector<std::string> asset_lines; }` | 关卡数据（三组直接复用既有结构） |
| `level_text_read` | `bool level_text_read(const std::string& path, Level_Data& out)` | 读文本；失败清空输出（清空守卫） |
| `level_text_write` | `bool level_text_write(const Level_Data& level, const std::string& path)` | 按固定顺序写全部受支持字段；自动创建父目录 |
| `level_transform_build` | `void level_transform_build(const float position[3], const float rotation_deg[3], const float scale[3], float out[16])` | M = T·R·S（列主序；旋转为度，X→Y→Z） |

## §5 设计细节

1. **文本格式**（行式，`#` 注释，空行忽略）：`level <名称>`；`camera *`（position / target / up / clear / fov / near / far /
   ortho / ortho_height / aspect）；`light *`（direction / color / intensity / ambient / specular / attenuation_mode /
   ambient_color / ambient_ground / ambient_hemisphere / fill_direction / fill_color / fill_intensity / specular_scale /
   shadow / pbr / toon / outline，以及逐盏 `point` / `spot`）；`fog *`（color / density / range / mode / height_falloff）；
   资产行 `mesh` / `mtl` / `place` 原样保留。
2. **往返逐位一致**：浮点写 `%.9g`；测试用 `memcmp` 逐字段验证（不做近似比较）。
3. **严格拒绝**：未知段 / 未知键 / 字段数不符 / 非有限值 / 开关非 0-1 / 点光或聚光超过 8 盏 / 资产行缺字段 → 整份拒绝。
4. **缺省补齐**：未出现的键保持 `Camera_Data` / `Light_Data` / `Fog_Data` 的默认值。
5. **多段混合字段**：阴影 = 开关（整数）＋ 3 浮点 ＋ 分辨率（整数）；PBR = 开关 ＋ 2 浮点；卡通 = 色阶（整数）＋ 5 浮点；
   点光 = 8 浮点 ＋ 衰减（整数）＋ 2 浮点；聚光 = 13 浮点 ＋ 衰减（整数）＋ 2 浮点。
6. **矩阵**：列主序 16 浮点；`R = Rz·Ry·Rx`（先 X 后 Y 后 Z）；缩放乘在旋转各列，平移进第 4 列；
   旋转全零 → 对角缩放 ＋ 末列平移。
7. **不落 GPU**：`level_text_*` 只做文本；`level_load` 才装配资产 / 应用三组。

## §6 运行链路

`Renderer::level_load(level, scene, path, apply_scene)`：
`level_text_read` → 相机合法性校验（fov ∈ (0, π)、near > 0、far > near、正交高度 > 0）→
资产行 `scene_manifest_parse_lines` → `asset_scene_build`（目录 = 关卡文件目录）→ 成功后才
`scene_apply(camera, light, fog)`（`apply_scene = false` 时跳过）→ 写出 `level_out` / `scene_out`。
任一步失败：整体回退、输出清空、**既有场景不被改动**。

展廊接入（第 432 轮）：展区㉔ 在 `init` 时写 `out/关卡展示/{面板.obj, 面板.mtl, 关卡甲.level, 关卡乙.level}`，
每 5 秒 `level_unload` → `level_load(..., false)` 切换；`frame_draw` 用 `level_transform_build` ＋
`mesh_draw_sections` 逐对象登记绘制；`shutdown` 释放。

## §8 材质实例行（第四百六十六轮；方向七阶段 B-A）

- **结构**：`Level_Material { 实例名; 模板; use_tint ＋ tint[4]; use_emissive ＋ emissive }`，只存声明、不持有句柄；
- **语法**：`material <实例名> <模板材质名> [tint r g b a] [emissive v]`，覆盖项顺序固定；
- **保存位置**：结构化字段 `Level_Data.materials`（**不进入** `asset_lines`，后者仍只含 `mesh` / `mtl` / `place`）；
- **拒绝**：缺名 / 缺模板 / 重名 / 未知项 / 重复或顺序颠倒 / 字段数不符 / 非有限 / 越界 → 整份失败并清空输出；实例上限 256；
- **写出**：实例行先于资产行，浮点 `%.9g`；写出前校验版本、全字段有限、覆盖值 [0,1]，失败不落盘；
- **兼容**：旧关卡无 `material` 行，`materials` 为空，行为不变。
- **用例**：往返 / 缺省 / 数值越界（6 组） / 结构非法（5 组） / 重名，关卡 23 / 23（`渲染关卡测试.cpp`）。
- **装配（第 467 轮 · 阶段 B-B）**：`level_load` 把 `Level_Data.materials` 传给 `asset_scene_build`，并把实例名表传给
  `scene_manifest_parse_lines`（`place` 材质列先查实例、未命中再查材质库）；实例模板按「模板材质名」在全部材质库中
  解析句柄（`material_load_mtl` 增名称输出），未命中 / 数据非法 → 整体回退；命中实例的对象
  `materials = {模板句柄}`、`material_instances = {覆盖数据}`；默认覆盖与直接绑模板画面 0 差异（关卡 **25 / 25**）。
- **展区数据（第 468 轮）**：展区㉔ 关卡甲 / 乙各补 2 条实例（暖 / 亮、冷 / 青）并让 4 个 `place` 引用实例名；
  阶段 C 合成未接入，外观暂等价；巡查 720 样本失败 0。
- **覆盖合成（第 469 轮 · 阶段 C）**：`scene_draw` 在「实例与材质等长」时把 `material_instances` 传给
  `mesh_draw_sections`（新增可选参数）；每段 `material_bind_set` 后套用：**tint 乘性**叠加（默认 1 等价模板）、
  **emissive 直接覆盖**；结束 `material_bind_set(0)` 自动复位。用例：tint / 自发光差异各 1516 像素、状态复位断言；关卡 **27 / 27**。
