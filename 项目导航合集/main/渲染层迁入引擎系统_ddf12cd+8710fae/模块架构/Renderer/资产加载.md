## §1 模块介绍

`src/render/Asset/` 是「文件 → 解析结果」的数据层：OBJ 网格、MTL 材质库、场景清单（网格 ＋ 材质 ＋ 摆放）。
模块**不创建任何 GPU 资源**，只读文件、校验语法并输出 Vulkan-free 结构；资源创建、失败整体回退、
缓存登记与异步状态机都在门面实现侧（`Renderer/core/渲染器.cpp`）。

模块不依赖 Vulkan / VMA / SDL3 / glm，只依赖 `Mesh/网格数据.h` 的 `Mesh_Data` / `Mesh_Section`。

## §5 设计细节

1. **上限**：OBJ 64 MiB / 400 万属性 / 1200 万索引；MTL 16 MiB / 4096 材质；清单 2 MiB / 20000 摆放。
2. **顶点键**：`(v, vt, vn)` 三元组去重；缺 `vt` 填 (0,0)；缺 `vn` 按相邻三角形面积加权（叉积累加）补全，零长度回落 +Z。
3. **负索引**：按 `属性数量 + 负值` 解析；越界拒绝整份文件。
4. **多边形**：扇形三角化（`v0, vi, vi+1`）；不足 3 顶点拒绝。
5. **字段换算在门面**：MTL 只给原始字段；`material_load_mtl` 才做 `tint = Kd`（w = d）、`roughness = √(2/(Ns+2))` 下限 0.06、
   `metallic = 0`、`emissive = Ke 亮度`、`d < 0.999 → alpha_cutoff = 0.5`、贴图相对 MTL 目录解码。
6. **清单严格性**：未知指令 / 字段缺失 / ID 重复 / 引用未知 ID / 无 `place` 一律拒绝；失败用清空守卫复位输出。
7. **`place` 语法**：`place <网格ID> [材质ID] x y z sx sy sz [rx ry rz]`；材质列可省略（下一标记可解析为数字即视为坐标）；
   旋转必须正好三个数，给 1–2 个或超过 3 个 → 拒绝。
8. **路径编码**：入参一律按 UTF-8 解释（`path_from_utf8`）；宽字符写盘由调用方负责。

## §6 运行链路

- **网格**：`Renderer::mesh_load_obj(handle, path)` → `obj_mesh_load` → 逐段 `mesh_create`（`Mesh_Section.material = 段序号`）；
  失败回退已建段。
- **材质**：`Renderer::material_load_mtl(handles, path)` → `mtl_materials_load` → 逐项换算 `Material_Data` ＋
  `texture_load_file`（贴图路径 = MTL 目录 ＋ 相对路径）→ `material_create`；任一失败卸载本次已建材质与纹理。
- **清单**：`Renderer::scene_load(scene, path)` → `scene_manifest_parse` → `asset_scene_build`
  （网格 / 材质按 ID 建句柄表，同一文件只加载一次，place 按序装配 `Asset_Object`）。
- **关卡**：`Renderer::level_load(level, scene, path, apply_scene)` → `level_text_read` → 相机校验 →
  `scene_manifest_parse_lines` → `asset_scene_build` → 可选 `scene_apply`。
