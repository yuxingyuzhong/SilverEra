## 一、模块功能介绍

粒子系统（`src/render/Particle/`）提供「CPU 参考模拟 ＋ GPU 计算推进 ＋ billboard 绘制 ＋ 深度分桶」四段能力，形态为
Vulkan-free 数据与池 ＋ 渲染门面扩展。默认**关闭**：`particle_enable_set(true)` 之前不发射、不推进、不登记任何绘制项，
既有画面逐字节不变。

| 能力 | 入口 | 说明 |
| --- | --- | --- |
| 数据与参数 | `粒子数据.h` / `core/粒子数据.cpp` | `Particle_State`（32 字节）、发射器、模拟参数（含 8 力场、碰撞球）、校验 |
| 粒子池 | `粒子系统.h` / `core/粒子系统.cpp` | 容量钳制、LIFO 分配回收、CPU 参考步进与发射（确定性 LCG） |
| 计算推进 | `Particle推进.comp` ＋ 门面 `particle_gpu_*` | 双缓冲 SSBO ＋ 力场 SSBO；与 CPU 同序积分 / 力场 / 碰撞 / 寿命 |
| 绘制 | `粒子.vert` / `粒子.frag` ＋ 门面 `particle_draw` | 相机朝向 billboard、年龄颜色曲线、Alpha / Additive、颜色 / 尺寸随年龄 |
| 排序近似 | 门面 `particle_sort_buckets_*` | 按视线距离分桶、桶间由远及近，不做逐粒子排序 |

## 二、公开接口（门面）

### 2.1 生命周期与池

| 接口 | 语义 |
| --- | --- |
| `bool particle_supported(void) const` | 已初始化且计算路径可用 |
| `bool particle_enable_set(bool)` / `bool particle_enable_get(void) const` | 开关；关闭不释放容量与池内容 |
| `bool particle_capacity_set(uint32_t)` / `uint32_t particle_capacity_get(void) const` | 容量钳制 [1, 1 048 576]；重建池并释放旧尺寸 GPU 资源 |
| `bool particle_emitter_set(const Particle_Emitter&)` | 非法参数整次拒绝（形状 / 数量 / 速度 / 寿命 / 半尺寸 / 方向） |
| `bool particle_params_set(const Particle_Params&)` | 非法参数整次拒绝（阻尼 / 反弹 / 摩擦 / 力场 / 碰撞球） |
| `uint32_t particle_emit(uint32_t count)` | 返回实际发射数（未开启 / 未配置 / 池满则小于 count） |
| `uint32_t particle_step(float dt)` | CPU 参考步进（未开启 / 步长非法返回 0），返回本步死亡数 |
| `uint32_t particle_active_count(void) const` | 活跃数（未开启为 0） |
| `bool particle_state_get(uint32_t, Particle_State&) const` | 按索引读取活跃粒子（非活跃 / 越界返回假） |

### 2.2 GPU 推进

| 接口 | 语义 |
| --- | --- |
| `bool particle_gpu_available(void)` | 计算可用 ＋ 粒子开启 ＋ 惰性资源成功 |
| `bool particle_gpu_probe(void)` | 零步自检：上传镜像 → 调度（dt 0 / 阻尼 1）→ 回读比对活跃粒子 |
| `bool particle_gpu_step(float dt)` | 上传镜像 ＋ 力场 → 调度 → 回读覆盖镜像 → 按 `lifetime ≤ 0` 回收并统计死亡（常驻模式下恒返回假） |
| `uint32_t particle_gpu_died_last(void) const` | 最近一次 GPU 单步判定的死亡数 |
| `bool particle_resident_set(bool)` / `bool particle_resident_get(void) const` | 常驻模式开关（状态只留 GPU，CPU 镜像不再逐帧上传 / 回读） |
| `uint32_t particle_gpu_emit(uint32_t count)` | 常驻发射：控制缓冲环形写指针 ＋ 活跃位图，返回本次实际写入数 |
| `bool particle_gpu_step_resident(float dt)` | 常驻推进：front 只读 → back 只写 → 交换，死亡侧在 GPU 内清位与减计数 |
| `bool particle_gpu_compact(void)` | 常驻紧凑：位图 → 连续索引数组 ＋ 紧凑计数（每帧一次的前置步骤，1M 实测 1.23 ms） |
| `uint32_t particle_compact_count_get(void) const` | 最近一次紧凑的索引数（= 活跃数；未开常驻为 0） |
| `uint32_t particle_compact_indices_get(uint32_t*, uint32_t)` | 回读紧凑索引（诊断 / 测试用；顺序不保证升序） |
| `std::size_t particle_gpu_bytes(void) const` | GPU 资源字节数：双缓冲 ＋ 力场 ＋ 控制缓冲 ＋ 紧凑索引（容量×4）＋ 紧凑计数（4 B） |

### 2.3 绘制

| 接口 | 语义 |
| --- | --- |
| `bool particle_draw(float size)` | 活跃粒子按相机朝向构造 billboard 矩阵并实例化登记（一个或每桶一个绘制项）；常驻模式下按活跃位图展开，容量 > 65536 拒绝 |
| `bool particle_blend_set(Blend_Mode)` / `Blend_Mode particle_blend_get(void) const` | 仅 Alpha / Additive；默认 Alpha；切档重建管线 |
| `bool particle_depth_write_set(bool)` / `bool particle_depth_write_get(void) const` | 默认关闭；切档重建管线 |
| `bool particle_sort_buckets_set(uint32_t)` / `uint32_t particle_sort_buckets_get(void) const` | 0 = 关闭；1..16 分桶 |

## 四、模块内部架构

```
src/render/Particle/
├── 粒子数据.h                  ← Vulkan-free：状态 / 发射器 / 参数 / 力场 / 碰撞球 / 常量
├── 局部命名空间使用.h
├── core/
│   ├── 粒子数据.cpp            ← 发射器与参数校验
│   └── 粒子系统.cpp            ← 池、CPU 参考 step / emit
├── 粒子系统.h                  ← Particle_System（池与参考模拟）
渲染层着色器：
assets/shaders/Particle推进.comp ← GPU 推进（状态 / 力场 / 碰撞 / 寿命）
assets/shaders/Particle发射.comp ← 常驻发射（环形写指针 ＋ 位图标记 ＋ 计数递增）
assets/shaders/Particle常驻推进.comp ← 常驻推进（front → back，死亡清位 / 减计数）
assets/shaders/Particle紧凑.comp ← 活跃位图 → 连续索引 ＋ 紧凑计数（阶段 D）
assets/shaders/粒子.vert / 粒子.frag ← billboard 顶点与年龄曲线片元
```

数据与 GPU 的字节契约：`Particle_State` 32 B（position[3] → velocity[3] → age → lifetime）；
`Particle_Force_Field` 40 B（`position[3]`、`radius`、`strength`、`direction[3]`、`type`、`padding`），
着色器侧一律用 `float` 数组（避免 `vec3` 的 16 字节对齐差异）。

## 五、设计与实现细节

### 5.1 固定步长与同序公式

CPU 与 GPU 的每步顺序固定为：

```
v += gravity·dt
逐力场（按配置顺序）：
    Wind      : v += normalize(direction)·strength·dt
    Attractor : 半径内 v -= normalize(p − center)·strength·(1 − d/r)·dt
    Vortex    : 半径内 v += normalize(cross(axis, p − center))·strength·(1 − d/r)·dt
v *= damping
p += v·dt
碰撞：地面（钳位 / 法向回弹 / 切向摩擦）→ 球体（推出 / 法向回弹 / 切向摩擦）
age += dt；age ≥ lifetime 时 lifetime = 0
```

### 5.2 GPU 推送常量（64 字节）

| 偏移 | 字段 |
| --- | --- |
| 0 | `gravity_dt`（xyz = 重力、w = dt） |
| 16 | `params`（x = damping、y = capacity、z = force_count） |
| 32 | `sphere`（xyz = 球心、w = 半径；≤ 0 关闭） |
| 48 | `surface`（x = floor_y、y = restitution、z = friction） |

### 5.3 计算描述符集（set 0）

binding 0 只读上一步状态、binding 1 只写下一步状态、binding 2 只读力场数组。

### 5.4 生命周期与「零寿命不变式」

GPU 以 `lifetime ≤ 0` 标记死亡；回读后镜像侧逐索引 `recycle`（LIFO 复用）并统计死亡，
同时把所有非活跃槽位的 `lifetime` 清零，保证下次上传时非活跃槽位被着色器原样写回（无幽灵粒子）。

### 5.5 billboard 与年龄编码

- 顶点着色器只做世界变换；billboard 基向量（右 / 上 × 半尺寸 ＋ 中心）在 CPU 侧按「相机 → 粒子」构造；
- 实例矩阵第 3 列 `w` 承载归一化年龄（`flat` 下传）；
- 片元为程序化圆盘软边，颜色 `暖白 (1, 0.92, 0.62) → 暗红 (1, 0.22, 0.05)`，后 40% 生命期淡出；
- 尺寸随年龄最多收缩 35%。

### 5.6 深度分桶

`particle_sort_buckets = 0` 时单次实例化（池索引顺序）；`1..16` 时按视线距离求范围、逐桶计数与填充，
桶间**由远及近**各登记一次实例化绘制，桶内保持池索引顺序，不做逐粒子排序。

### 5.7 常驻控制缓冲（阶段 C）

控制缓冲为 `uint32` 数组，长度 `2 + ⌈容量/32⌉`：

| 偏移 | 字段 |
| --- | --- |
| `[0]` | 环形写指针（发射用 `atomicAdd(control[0], 1)` 取槽，`slot % 容量` 定索引） |
| `[1]` | 活跃计数（发射 `+1`、推进侧死亡 `+0xFFFFFFFF` 减一，即 `atomicAdd` 补码减） |
| `[2 + i]` | 活跃位图，第 `i` 字第 `b` 位对应粒子索引 `32i + b`（`atomicOr` 置位 / `atomicAnd` 清位） |

发射与推进均为 `local_size = 64`，set 0 见 §5.3 同构扩展：发射侧 binding 0 只写状态、1 控制缓冲，
推送常量 `{emit_position, speed_lifetime, params, main_direction}`；常驻推进侧 binding 0 只读 front、
1 只写 back、2 力场、3 控制缓冲。死亡清位用「先 `atomicAnd` 取旧值、旧值含目标位才减计数」，
避免重复减计数（GLSL 无 `atomicSub`，减一统一写 `atomicAdd(control[1], 0xFFFFFFFFu)`）。

### 5.8 常驻绘制与容量上限

常驻模式下 `particle_draw` 不再使用 CPU 镜像：先回读控制缓冲 `[2..]` 位图（偏移 8）与整块状态
（`容量 × 32 B`），按位展开 `resident_alive`，再复用非驻留路径的 billboard 构造与分桶登记。
受主机侧逐帧回读与实例缓冲规模限制，**容量 > 65 536 时常驻绘制直接返回假**（其余常驻 API 不受限）。
`particle_gpu_step` 与 `particle_gpu_probe` 在常驻模式下返回假（避免两套状态互相污染）。

### 5.9 紧凑索引（阶段 D）

`Particle紧凑.comp`（`local_size = 64`，set 0）：binding 0 = 控制缓冲（只读位图）、binding 1 = 紧凑索引（只写）、
binding 2 = 紧凑计数（原子）；推送常量 `uvec4 {容量, 位图字数, 0, 0}`。
每线程判一位图位，活跃则 `atomicAdd(count,1)` 取位写索引。
主机侧 `particle_gpu_compact` 每帧流程：写 4 B 零值清零计数 → 绑定 0/1/2 → `compute_dispatch(容量, 64)` → 回读 4 B。
**顺序口径**：紧凑数组元素互异且覆盖全部活跃索引，但**不保证池索引升序**（原子取位由并发决定）；
索引缓冲 `uint32 × 容量`、计数缓冲 4 B，随容量重建并与 `particle_gpu_bytes` 一同统计。

## 六、运行链路详例

### 6.1 发射 → CPU 步进 → 绘制（离屏定位用例路径）

1. `particle_enable_set(true)` → `particle_capacity_set(8)` → `particle_emitter_set(...)` → `particle_params_set(...)`；
2. `particle_emit(1)`：池内取索引、填充位置 / 速度 / 年龄 / 寿命；
3. `particle_step(0.05)`：CPU 参考按 §5.1 推进并回收死亡；
4. `particle_draw(0.5)`：`particle_draw_ensure` → 构造 billboard 矩阵 → 临时切换粒子管线 → `mesh_draw_instanced` 登记一个绘制项；
5. `frame_render()`：绘制项进入场景 pass，中心像素呈暖黄色、边角保持清屏色。

### 6.2 GPU 推进同步（`particle_gpu_step`）

1. `particle_gpu_available()` → `particle_gpu_ensure`（双缓冲 / 力场缓冲 / 推进管线）；
2. `compute_buffer_write` 上传 CPU 镜像与前 `force_count` 项力场；
3. `compute_buffer_bind` 0 / 1 / 2 → `compute_dispatch`（`local_size = 64`，推送 64 字节）；
4. `compute_buffer_read` 回读覆盖 CPU 镜像；
5. 逐索引回收 `lifetime ≤ 0` 的活跃槽位并清零非活跃槽位寿命，写 `particle_gpu_died_last`。

### 6.3 常驻链路（`particle_resident_set(true)` → 发射 / 推进 / 绘制）

1. `particle_capacity_set(N)` → `particle_resident_set(true)`（CPU 镜像退居配置侧，状态以 GPU 为准）；
2. `particle_gpu_emit(k)`：回读 `control[1]` → 剩余容量钳制 → bind 0 / 1 / 2 / 3 → `compute_dispatch`（`local_size = 64`）
   → 再回读 `control[1]`，`particle_born_total += spawned`；
3. `particle_gpu_step_resident(dt)`：回读 `control[1]` 为 before → 上传力场 → bind front / back / 力场 / 控制
   → 调度 → **交换 front / back** → 回读 after，`died = before − after` 计入统计；
4. `particle_draw(size)`：按 §5.8 展开活跃位图并登记实例化绘制项；
5. `frame_render()` 输出画面，`particle_active_count()` 来自 GPU 计数（与发射 / 死亡统计守恒）。

### 6.4 紧凑链路（`particle_gpu_compact`；阶段 D 前置）

1. `particle_resident_set(true)` ＋ `particle_gpu_emit(k)` ＋ `particle_gpu_step_resident(dt)`（见 §6.3）；
2. `particle_gpu_compact()`：清零计数 → 位图逐位判活并写索引 → 回读计数（= 活跃数）；
3. `particle_compact_indices_get(buf, n)` 抽查索引集合（互异、范围 `[0, 容量)`）；
4. 后续（设计见工作站 `深研规划_方向二_阶段D_间接绘制.md`）：紧凑计数直接写 `VkDrawIndexedIndirectCommand.instance_count`，
   `粒子GPU.vert` 按 `gl_InstanceIndex` 取索引 → 状态 → 着色器内构造 billboard。

### 6.5 关闭与销毁

`shutdown` 中先归还粒子四边形网格（`mesh_unload`），再销毁帧上下文；
计算缓冲与管线随门面计算资源表统一销毁，粒子相关句柄全部复位为 0。
