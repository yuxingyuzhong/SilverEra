# 项目导航合集 · 索引

> 存放「白银纪元」各代码版次的**项目导航**文档，按「分支 / 版次」隔离存储。
> 版次目录命名遵循《agent开发指南》：「新增功能_代码推送哈希值」，**不含日期**。
> 文件系统与 GitHub 网页均按**目录名（Unicode 码位序）**排列目录，与时间无关 —— 因此上层的目录列表不能反映版次先后，最新的一份往往夹在中间。
> **本文件按时间倒序维护（最新在最上），是判断最新版次的依据。**

## 存储结构

```
项目导航合集/
└── <分支名>/
    ├── 分支提交历史.md          # 该分支的代码提交时间线与各版次摘要
    └── <版次目录>/              # 命名：<新增功能>_<代码推送哈希值>
        ├── 项目架构.md          # 项目目录架构图 / 各模块功能 / 模块间交互关系
        └── 模块架构/            # 每个模块一份单一文件
```
