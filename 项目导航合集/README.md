# 项目导航合集

> 文件索引：[报告汇总索引](../渲染器自主迭代_执行报告汇总/索引.md) ｜ [计划汇总索引](../渲染器自主迭代_执行计划汇总/索引.md)

本目录按**分支隔离**存储各版次「项目导航」：每个分支单独一个目录，分支目录下每个代码版次一个子目录（以该版次「代码推送哈希值」命名）。

---

## 存储规则

1. 分支目录：`main/`（主分支）；其余分支按分支名单独建立。
2. **每次开发窗口建立一次版次目录**，窗口内各轮**就地增量**；窗口收口时按上限淘汰最旧。
3. 版次上限：**main 最多 4 个**，其余分支最多 2 个。
4. 每个分支目录下维护文件 `分支提交历史`，记录代码提交哈希顺序与每版次新增功能。

---

## 版次目录结构

```
<版本哈希>/
├── 项目架构.md              # 目录架构图、各模块功能与交互关系
├── 模块架构/                # 各模块单一文件（含文件内目录、接口、实现细节、运行链路）
│   ├── Renderer/…
│   ├── Test/…
│   ├── EngineCore/…
│   └── EngineSystem/…
└── 待答疑清单.md            # 设计疑问 / 候选方案 / 临时做法（附编号与结案状态）
```

单文件规模建议 25 KB–500 KB（源码单薄的模块可低于 25 KB）。
