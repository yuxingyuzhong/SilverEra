# 任务报告合集 · 索引

> 存放「白银纪元」各任务的**执行计划**与**执行报告**，按「分支 / 版次」隔离存储。
> 报告目录命名遵循《agent开发指南》：「新增功能_代码推送哈希值」，**不含日期**。
> 文件系统与 GitHub 网页均按**目录名（Unicode 码位序）**排列目录，与时间无关 —— 因此上层的目录列表不能反映先后，最新的一份往往夹在中间。
> **本文件按时间倒序维护（最新在最上），是判断最新报告的依据。**

## 存储结构

```
任务报告合集/
└── <分支名>/
    ├── 报告提交历史.md          # 该分支的报告时间线与各任务摘要
    └── <报告目录>/              # 命名：<新增功能>_<代码推送哈希值>
        ├── 执行计划.md
        └── 执行报告.md
```
