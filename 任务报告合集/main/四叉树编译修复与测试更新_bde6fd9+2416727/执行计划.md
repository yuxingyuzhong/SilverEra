## 三、当前编译错误（权威来源：实际构建输出，共 3 处）

```
Quadtree/core/区块信息检索.hpp(229): error C2676: 二进制“[”:
    variant<array<Node*,4>, shared_ptr<T>> 不定义该运算符
Quadtree/core/区块信息检索.hpp(363): error C2676: 同上
Quadtree_Manager/core/区块信息检索.hpp(55): error C2440: 无法从
    std::_Vb_reference<...>* 转换为 bool*
```

根因：

1. `Node::data` 已由 `union` 改为 `std::variant<std::array<Node*, 4>, std::shared_ptr<T>>`，
   全模块基本已改用 `std::get<0>/<1>`，仅 [区块信息检索.hpp:229](file:///d:/代码存储/代码仓库/白银纪元/引擎层/src/core/spatial/partition/Quadtree/core/区块信息检索.hpp#L229)
   与 [区块信息检索.hpp:363](file:///d:/代码存储/代码仓库/白银纪元/引擎层/src/core/spatial/partition/Quadtree/core/区块信息检索.hpp#L363)
   两处仍用旧的 `data[direct]` 下标写法。
2. 管理器侧 `target_excel` 已由 `std::shared_ptr<bool>` 改为 `std::vector<bool>`，
   但 [区块信息检索.hpp:55](file:///d:/代码存储/代码仓库/白银纪元/引擎层/src/core/spatial/partition/Quadtree_Manager/core/区块信息检索.hpp#L55)
   仍按 `bool* p = &excel.front() + row * width` 取行首指针，而 `vector<bool>` 的 `front()` 返回代理引用。

| 项 | 旧 | 新 |
|---|---|---|
| 坐标类型 | `Point2i` / `Rect2i` | `Point2l` / `Rect2l` |

| 智能创建 | `quadtree_build_smart(std::vector<Point2i>)` | `quadtree_build_smart(std::vector<Point2l>)` |

### 阶段三：撰写缺陷报告（任务报告）

- 产物：本目录下 `执行报告.md`，其中单列「四叉树 / 四叉树管理器缺陷清单」一节。
- 已初步识别、待证实后写入的候选缺陷（**只报告，不擅自修复**）：
  1. 卸载路径 `node->data.reset()` 会把 `variant` 置于 valueless 状态，后续 `std::get<0>/<1>` 会抛 `std::bad_variant_access`。
  2. 卸载未把父节点子指针置空、也未回收叶子节点内存。
  3. 管理器 `seek(Rect2l)` 中 `target_range_amend(tree_range, ...)` 的网格参数疑似与
     `excel_element_to_coord(seekable_range, ...)` 的网格不一致，可能漏标记已覆盖区块。
