## 二、结论（详见 `渲染层下轮方向.md` 的「阶段 C 可行性预研」小节）
1. Vulkan 约束：拷贝命令必须同队列提交；跨线程只能「各自录制 → 统一提交」或「独立提交 + 信号量」。
2. 延迟销毁按帧号释放，后台提交必须纳入同一帧号体系，否则会「提前释放仍在使用的资源」。
3. `buffer_write` 线程安全但区间不得重叠 → 并行写入须按块切分（与实例差异扫描同模式）。
4. **首版建议**：仅并行化 CPU 侧 mip 生成（纯计算、可逐字节比对）；次版再并行化像素解码 / 格式转换；
   独立上传队列 + 跨队列信号量留到收益明确的场景再做。
