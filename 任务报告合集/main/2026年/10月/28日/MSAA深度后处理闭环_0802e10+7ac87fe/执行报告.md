## 三、用例口径
1. 同一四边形（距相机 3），`景深.frag` 单级链；
2. 分别以「对焦 3.0（清晰）」与「对焦 0.6（严重离焦，最大模糊 6）」渲染一帧；
3. 统计两帧「任一通道差 > 12」的像素数；1× 基线与 4× 结果相差 ≤ 50%；
4. 深度解析失效时（深度全 0 / 全 1），两帧画面几乎一致 → 差异像素数塌到 0 → 用例失败。
