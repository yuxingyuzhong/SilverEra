# 执行计划 · 第 191 轮 · MSAA 下深度类后处理闭环

## 一、背景
第 190 轮为 MSAA 增加了「深度解析」（场景 pass 结束时把多重采样深度按样本 0 写入单采样深度图）。
本轮补齐其后的连锁收口：让所有依赖深度的后处理（景深 / 屏幕空间反射 / 屏幕空间遮蔽）在 MSAA 下
「有据可依」，并用用例把「MSAA 下景深仍能区分对焦与离焦」固化为回归。

## 二、范围
| 文件 | 改动 |
| --- | --- |
| `Application/Renderer/assets/shaders/屏幕空间反射.frag` | 注释：由「MSAA 下需 1×」改为「已由深度解析供单采样深度」 |
| `Application/Test/src/单元测试/Renderer/渲染后处理链测试辅助.h` | 新增 `msaa_config(samples)`（与 `hidden_config` 同尺寸，仅改采样数） |
| `Application/Test/src/单元测试/Renderer/渲染后处理景深测试.cpp` | 新增用例 `景深在MSAA下区分对焦与离焦` |

（`景深.frag` 注释已在第 190 轮同步。）

## 三、用例口径
- 1× 与 4× 各自：离屏场景目标 → 单级「景深」链 → 交换链；同一四边形分别以「对焦 3.0（面距相机 3）」与「对焦 0.6（严重离焦）」各渲染一帧；
- 统计两帧「任一通道差 > 12」的像素数；1× 基线与 4× 结果同量级（相差 ≤ 50%）；
- 深度解析失效时（深度全 0 / 全 1），两帧画面接近一致，差异像素数塌到 0，用例即失败。

## 四、验收
- 新用例通过且 1× / 4× 差异像素数同量级；
- 全量回归全绿（第 190 轮基线 1043 例 / 64 套件）；
- 三树构建 0 error。
