# 执行计划 · 材质 UV 旋转与 Alpha 裁剪（第一百八十三轮）

- 代码版次：Renderer `eeed7d3 → b3ed93e`；Test `8a49af6 → 44216ac`
- 日期：2026-10-28
- 目标：材质层补两个贴图能力——**UV 旋转**（贴图整体旋转）与 **Alpha 裁剪**（镂空贴图按 alpha 阈值丢弃片元），默认值下画面逐字节不变。

## 一、现状与约束

1. 材质已有 `uv_scale` / `uv_offset`（推送常量 offset 96），但无旋转；`material_extras`（offset 80）的 z / w 两个分量此前未被场景着色器使用。
2. 无 Alpha 裁剪使「树叶 / 镂空花纹」类贴图只能依赖 alpha 混合，排序成本高。
3. 材质字段属**数据驱动**通道（`Material_Data`），与 `uv_scale` / `uv_offset` 同级别，本轮沿用「记录 → 绑定吸附 → 推送常量」链路，不新增门面方法。

## 三、分段执行

1. 数据与吸附：字段、归一（旋转非有限按 0；裁剪越界按 0）、绑定同步与复位。
2. 推送常量：`offset 80` 的 z = 裁剪阈值、w = 旋转角；`mesh_draw` 与 `mesh_draw_instanced` 两条路径都写。
3. 着色器：旋转用 cos / sin，角度 0 时严格恒等；裁剪用于采样反照率之后。
4. 用例：四象象纹理旋转 90° 变化像素 > 100；左半不透明 / 右半 alpha 0 的纹理在阈值 0.5 下右半被丢弃、左半逐字节不变。
5. 三树构建（Test 重配以刷新 `.spv`）→ 全量回归 → 收口文档。

## 四、风险与口径

- 旋转 0 时 `cos 0 = 1 / sin 0 = 0`，`x' = x·1 − y·0`、`y' = x·0 + y·1` 与未旋转逐字节一致。
- 裁剪阈值 0 时整段短路，不做任何 `discard`。
- 文字管线对 offset 80 的解释（描边参数）不受影响：`文字.frag` 不读 `material_extras`。
- 已知未覆盖：`mesh_draw_instanced` 路径此前未写 offset 80 的 x / y（法线强度 / 粗糙度贴图开关），本轮不擅自扩大改动范围。
