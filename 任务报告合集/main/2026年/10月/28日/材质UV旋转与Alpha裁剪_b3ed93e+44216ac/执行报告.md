## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 推送布局 | offset 80 的 vec4 现为 x 法线强度、y 粗糙度贴图开关、**z Alpha 裁剪阈值、w UV 旋转角**（后两者此前恒 0） |
| 恒等性 | 旋转 0 时 `cos=1 / sin=0`，旋转表达式退化为原值；裁剪阈值 0 时整段短路 → 与旧版逐字节一致 |
| 变换顺序 | 先缩放、再旋转、后偏移；旋转以 UV 原点为中心 |
| 归一 | 旋转仅要求有限值；裁剪阈值须落在 (0, 1]，否则按 0（关闭） |
| 双路径 | `mesh_draw` 与 `mesh_draw_instanced` 均写 z / w，故实例化绘制同样支持两个新能力 |
| 文字隔离 | `文字.frag` 对 offset 80 的解释是描边参数，不读 `material_extras`，无冲突 |
