## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 深度来源 | 后处理链的 `post_depth_bind`（set1 binding 2），主 pass 结束时深度已转 `SHADER_READ_ONLY_OPTIMAL` |
| 边缘算子 | `|4·d_center − (d_left + d_right + d_up + d_down)|`，对轮廓阶跃敏感、对缓坡不敏感 |
| 自适应阈值 | `(0.0005 + z·0.005) × (1 + 2·d_center)`；远景物深度变化慢，阈值自动放宽 |
| 参数域 | 复用 `post_stage_param4_set`：x = 强度 0..1、z = 阈值档 0..10（其余分量忽略） |
| 直通保证 | 强度 0 时压暗权重恒 0 → 与参考直通逐字节一致 |
