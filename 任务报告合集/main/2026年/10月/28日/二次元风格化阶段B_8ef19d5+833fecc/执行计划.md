# 执行计划 · 二次元风格化阶段 B：深度描边（第一百七十六轮）

- 代码版次：Renderer `2120993 → 8ef19d5`；Test `6ad5ca1 → 833fecc`
- 日期：2026-10-28
- 目标：为二次元风格化增加「几何轮廓描边」——在后处理链中用场景深度做边缘检测并压暗轮廓。

## 一、现状与约束

1. 后处理链已支持任意预设：上层 `pipeline_load` 登记 `后处理.vert` + 自定义 `.frag`，再用 `post_chain_set` 入链，无需新增门面 API。
2. 后处理采样集提供 set1 binding 0（源）、1（场景目标）、2（场景深度）、3（LUT），深度可直接用于边缘检测。
3. 推送常量已含 offset 80 `size_xy` 与 offset 96 `post_param`；参数沿用 `post_stage_param4_set`（x 强度 0..1、z 0..10）。
4. 既有 `描边.frag` 为亮度 Sobel，本阶段新增的是**深度**描边，两者互补。

## 二、拟修改文件（相对项目根）

| 文件 | 计划改动 |

## 三、分段执行

1. 着色器：深度邻域采样 + Laplacian + 阈值自适应 + 压暗。
2. 用例：立方体提供深度断层；强度 0 与直通逐字节比较，强度 1 统计压暗像素数。
3. 三树构建（含新着色器编译与测试层重配）→ 全量回归 → 收口文档。

## 四、风险与口径

- 非线性深度在近处变化剧烈，阈值随中心视深放大，避免近处细碎误判。
- 强度 0 时压暗权重恒 0，保证与原链逐字节一致。
- 描边色暂固定为「压暗到黑」，可配置色留待后续阶段。
