# 执行计划 · 第 197 轮 · 多线程渲染阶段 B（场景 pass 次级命令缓冲并行录制）

## 一、背景
台账候选 1（最高优先级）：多线程阶段 B。阶段 A（第 177 轮）已并行化「实例级视锥剔除」与「实例缓冲差异扫描」；
本轮把**命令录制本身**拆到工作线程：场景 pass 的绘制项按段分给多个次级命令缓冲并行录制。

## 二、关键约束（Vulkan）
1. 动态渲染实例**不可跨命令缓冲**：每个次级缓冲必须完整包含 `vkCmdBeginRendering … vkCmdEndRendering`；
2. 主缓冲不得处于渲染实例中才能 `vkCmdExecuteCommands`；
3. 同一附件的多个渲染实例之间无需布局转换（同一布局），但首段必须 CLEAR、后续段 LOAD；
4. 多重采样颜色 / 深度解析**只能在末段**启用（中间段 `resolveMode = NONE`）；
5. 次级缓冲需在 `VkCommandBufferBeginInfo::pInheritanceInfo` 中挂 `VkCommandBufferInheritanceRenderingInfo`
   （声明颜色 / 深度格式与采样数），供校验层核对兼容性；不设置 `RENDER_PASS_CONTINUE`（不在主缓冲的渲染实例内执行）。

## 四、验收
- 单线程与四线程在「64 个独立绘制项 + 单级后处理链」下：像素差 ≤ 2、绘制项 / 实例数一致、并行派发 > 0；
- 线程数 0、项数 < 32、段数 < 2 时走原路径（画面逐字节不变）；
- 全量回归与基线一致；三树 0 error。
