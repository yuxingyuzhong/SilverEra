## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 线程池语义 | `ranges_run(total, min_chunk, body)` 同步阻塞：先登记任务→唤醒全部工作线程→调用线程也参与领块→`done` 等全部工作线程收尾；返回即全部块已完成 |
| 块划分 | `chunk = max(total / (线程数 × 4), min_chunk)`，且 `chunk ≤ total/2`（保证至少两块）；`total < 2 × min_chunk` 或无线程时退化为整段单线程 |
| 确定性 | 两处热点都只把「可见性 / 变化标记」写到各自下标的掩码槽；压缩可见实例、合并连续变化段仍是单线程按原顺序扫描，故实例顺序与上传区间与单线程完全一致 |
| 实例剔除 | `mesh_draw_instanced`：`thread_pool.active() && count ≥ 256` 走并行，否则直跑；掩码 1 = 可见 |
| 差异扫描 | 实例缓冲按需写入：`instance_count ≥ 512` 时并行算 `instance_changed_mask`，随后按掩码扫描连续段（与逐实例比较结果一致） |
| 门面切换 | `render_threads_set` 钳 0..64、同值空操作、先停旧线程再起新线程；启动失败回落 0 并告警 |
| 容量 | `instance_capacity` 钳 [16, 1048576]，在实例缓冲分配之前生效；默认 256 与引入前一致 |
| 观测 | `Frame_Stats::render_threads` = 当前线程数；`parallel_dispatches` = 累计真正派发的并行任务数（退化任务不计） |
