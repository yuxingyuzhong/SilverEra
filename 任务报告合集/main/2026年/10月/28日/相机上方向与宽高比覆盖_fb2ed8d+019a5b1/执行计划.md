# 执行计划 · 相机上方向与宽高比覆盖（第一百八十六轮）

- 代码版次：Renderer `8d030c6 → fb2ed8d`；Test `8c3fbfc → 019a5b1`
- 日期：2026-10-28
- 目标：把相机模块已有的 `up_set` 接入公共面，并新增宽高比覆盖，使离屏 / 非窗口比例输出可固定投影比例。

## 一、现状与约束

1. `Camera::up_set` 早已存在但无人调用（上方向恒为 (0,1,0)），`Camera_Data` / `Scene_Data` 亦无对应字段。
2. 宽高比每帧由交换链范围自动写入（`aspect_set`），现状无法固定为任意比例。
3. 二者默认值必须保持既有画面逐字节不变：上方向默认 (0,1,0)、宽高比覆盖默认 0（跟随窗口）。

## 三、分段执行

1. 相机模块：覆盖字段与生效宽高比。
2. 数据与门面：字段转发、参数归一（全零上方向忽略；非有限宽高比按跟随窗口）。
3. 用例：滚转 / 覆盖改变画面，恢复默认后与基准最大差 ≤ 2。
4. 三树构建 → 全量回归 → 收口文档。

## 四、风险与口径

- 上方向 (0,1,0) 与覆盖 0 时与旧路径完全等价。
- 立方体正视时滚转 90° 因旋转对称不可见，用例改用绕 Y 轴偏转的模型矩阵。
