## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 上方向 | `camera_up_set` 拒绝全零与非有限分量（避免视图矩阵退化）；其余原样交给 `Camera::up_set` |
| 宽高比 | 每帧仍由交换链范围写入 `aspect`；`aspect_override > 0` 时投影改用覆盖值，故「跟随窗口」语义不变 |
| 数据化 | 两条 `scene_apply` 路径都把字段转发到同一组入口，保证门面 / 数据行为一致 |
| 恒等性 | 默认上方向与默认覆盖下 `view_proj_get` 与旧实现完全一致 |
