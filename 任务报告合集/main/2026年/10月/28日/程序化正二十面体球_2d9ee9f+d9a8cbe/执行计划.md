# 执行计划 · 程序化正二十面体球（第一百八十九轮）

- 代码版次：Renderer `630b3b6 → 2d9ee9f`；Test `019a5b1 → d9a8cbe`
- 日期：2026-10-28
- 目标：新增三角形分布均匀的球体程序化网格（正二十面体细分球），补充既有 UV 球在形变 / 物理近似上的不足。

## 一、现状与约束

1. 既有程序化图元：三角形 / 立方体 / 圆柱 / 圆环 / UV 球 / 平面；UV 球两极三角形退化、分布不均。
2. 正二十面体球需要「中点缓存复用」避免细分后出现裂缝；顶点归一化后法线可直接取归一化位置。
3. 参数口径与既有程序化入口一致：非法参数整次拒绝（句柄置 0）并告警。

## 三、分段执行

1. 生成器：基础二十面体 ＋ 中点缓存细分 ＋ 归一化 ＋ UV。
2. 门面：参数校验与句柄语义对齐既有入口。
3. 用例：`vertices/indices` 计数与包围盒断言。
4. 三树构建 → 全量回归 → 收口文档。

## 四、风险与口径

- 绕序沿用正二十面体标准外向逆时针表，背面剔除行为与其它程序化图元一致。
- 细分上限 4（5120 面），避免误用造成巨量顶点。
- 球面 UV 在经度接缝处不做顶点复制（仅影响纹理接缝表现，不影响几何与法线）。
