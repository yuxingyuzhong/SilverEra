## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 基础拓扑 | 正二十面体 12 顶点 / 20 面，绕序为外向逆时针（与其它程序化图元一致，背面剔除无需特判） |
| 细分 | 每级把每个三角面拆成 4 个；中点按顶点对缓存复用，避免相邻面生成重复中点导致裂缝 |
| 归一化 | 所有顶点（含中点）除以自身长度后乘半径；法线取归一化位置 |
| UV | `u = atan2(z, x) / 2π + 0.5`、`v = 0.5 − asin(y) / π`；纬度参数先钳到 [−1,1] 防浮点越界 |
| 参数口径 | 半径 ≤ 0 / 非数、细分 > 4 均整次拒绝并把句柄置 0 并告警 |
