## 一、问题与方案

MSAA 采样数 > 1 时，场景 pass 的深度只写入多重采样深度附件，单采样深度图像（`Render_Target_Record::depth_image`）
在整帧中从未被写入；而后处理阶段（`post_sets_bind` 的 binding 2）绑定的正是这张单采样深度视图，
因此景深 / 深度描边 / 屏幕空间遮蔽在 MSAA 下读到的是未定义内容（`景深.frag` 注释此前明确标注「MSAA 下不可用」）。

方案：使用 Vulkan 1.3 动态渲染的深度解析——场景 pass 的深度附件在 `VkRenderingAttachmentInfo` 上
设置 `resolveMode = VK_RESOLVE_MODE_SAMPLE_ZERO_BIT`、`resolveImageView = 单采样深度视图`、
`resolveImageLayout = VK_IMAGE_LAYOUT_DEPTH_ATTACHMENT_OPTIMAL`，由 `vkCmdEndRendering` 内建解析完成；
不新增 pass、管线或描述符集。

## 三、行为口径

1. **默认开启**：`msaa_depth_resolve = true`；采样数 1 时 `msaa_depth_image` 为空 → 帧模块跳过全部新增分支，画面逐字节不变。
2. **解析模式**：`SAMPLE_ZERO`（规范保证 depth resolve 必须支持该模式）。
3. **目标缺失时降级**：`msaa_depth_image` 或 `depth_image` 为空时 `resolveMode` 保持 `NONE`，行为回到修复前（不崩）。
4. **运行时切换**：`msaa_depth_resolve_set` 只改 Impl 开关，下一帧生效，不重建任何资源。
5. **交换链直通路径不受影响**：仅「场景目标 → 同帧后处理链」路径取多重采样深度图像。

## 四、测试用例设计（`渲染MSAA测试.cpp`）

- 1× 与 4× 各自：创建离屏场景目标 → `render_target_present_set` → 单级「深度描边」链；
- 先以 `post_stage_param_set(0, 0, 0, 0.5)`（强度 0 = 直通）渲染一帧作为对照，再以强度 1 渲染一帧；
- 统计两帧「任一通道差 > 20」的像素数；断言 4× 的差异像素数 > 0 且与 1× 相差不超过 50%；
- 追加门面开关默认值 / 切换 / 查询断言。

实测：1× = 588，4× = 586（几乎一致）。修复前 4× 深度为未定义内容，差异像素数恒为 0。
