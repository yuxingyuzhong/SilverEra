# 执行计划 · 第 190 轮 · MSAA 深度解析

## 一、本轮方向（自主决策）
台账《渲染层下轮方向.md》第七节候选 1：**MSAA 深度解析**。

问题：MSAA 采样数 > 1 时，场景 pass 只把深度写进多重采样深度附件，单采样深度图像从未被写入；
景深 / 深度描边 / 屏幕空间遮蔽等深度类后处理仍从单采样深度图采样，读到的是未定义内容
（`景深.frag` 注释里明确写着「MSAA 下不可用」）。

方案：利用 Vulkan 1.3 动态渲染的**深度解析**能力——场景 pass 的深度附件（多重采样）在
`VkRenderingAttachmentInfo` 上设置 `resolveMode = VK_RESOLVE_MODE_SAMPLE_ZERO_BIT`、
`resolveImageView = 单采样深度视图`，由 `vkCmdEndRendering` 内建解析完成，无需额外 pass / 管线 / 描述符集。

## 三、分段执行
1. **目标接口**：RenderTarget 暴露多重采样深度图像。
2. **帧录制**：深度附件屏障 + 解析字段 + 采样前屏障扩展。
3. **门面**：配置字段、开关、组装、查询方法。
4. **验收**：1× 与 4× 各跑「强度 0（直通）/ 强度 1（深度描边）」两帧，比较差异像素数；随后全量回归。

## 四、验收口径
- 4× 下「直通 vs 描边」差异像素数应与 1× 同量级（实测 586 vs 588，差异 ≤ 50%）；
- `msaa_depth_resolve` 默认开启、可运行时切换（不重建资源）；
- 采样数 1 或目标无多重采样深度时行为逐字节不变（字段为空，帧模块跳过解析）；
- 全量回归全绿。
