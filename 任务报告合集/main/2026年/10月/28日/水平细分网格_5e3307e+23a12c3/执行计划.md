# 执行计划 · 第 193 轮 · 程序化 XZ 水平细分网格

## 一、背景与命名冲突
台账候选 3「程序化几何扩充（细分平面网格）」。开工时发现项目**已有** `mesh_grid_load(width, height, columns, rows)`
（第 93 轮）：那是 **XY 平面**（竖直，法线 +Z）的规则网格，不适合做地形 / 水面底板。
故本轮新增的是 **XZ 水平面**版本，并改名为 `mesh_ground_grid_load` / `ground_grid_generate`，与既有版本并存、语义不重叠。

## 二、修改文件（相对项目根）
| 文件 | 改动 |
| --- | --- |
| `Application/Renderer/src/render/Mesh/网格.h` | 新增 `ground_grid_generate(width, depth, segments_x, segments_z)` 声明 |
| `Application/Renderer/src/render/Mesh/core/网格加载器.cpp` | 实现：顶点 (sx+1)×(sz+1)、索引 sx×sz×6、法线恒 +Y、UV 归一化、正面绕序「从 +Y 看逆时针」 |
| `Application/Renderer/src/render/Renderer/渲染器.h` | 新增 `mesh_ground_grid_load` 声明（参数校验说明） |
| `Application/Renderer/src/render/Renderer/core/渲染器.cpp` | 实现：宽/深 > 0、分段 1..512、顶点总数 ≤ 2^20，通过后复用 `mesh_load` |
| `Application/Test/src/单元测试/Renderer/渲染网格纹理测试.cpp` | 新增用例 `程序化水平细分平面加载`（3×2 分段 → 12 / 36） |

## 三、分段
1. Mesh 生成器（纯数据，无 Vulkan）；
2. 门面入口（校验 + 复用加载路径）；
3. 用例与回归（网格夹具 + 全量）。

## 四、验收
- 3×2 分段：顶点 12 / 索引 36；包围盒 X ±1.5、Z ±1、Y 恒 0；非法参数（宽 0 / 分段 0 / 分段 513）整次拒绝；
- 网格夹具 18/18；全量回归除并行会话在建用例外全过；三树 0 error。

## 五、教训（写入流程）
新增门面方法前必须 `grep` 一次同名符号：本轮曾因与既有 `grid_generate` 签名相同而触发 `C2535` 重复定义，
改名后解决。
