## 二、实现要点

1. **段数口径唯一化**：`min(线程数, parallel_max_segments, 项数 / 16)`，且需 `项数 ≥ parallel_min_items`、次级缓冲就绪、段数 ≥ 2；三条路径不再各写一份。
2. **分段录制唯一化**：每段次级缓冲完整包含一个动态渲染实例（继承信息声明颜色 / 深度格式与采样数）；
   首段沿用入参 `loadOp`（清屏或保留）、其余 `LOAD`；多重采样解析只在末段开启；单采样 UI 回调放末段。
3. **批量执行**：主缓冲一次 `vkCmdExecuteCommands` 顺序执行全部段（直通 / 离屏两处此前仍逐段调用，本轮补齐）。
4. **统计汇总**：各段只写自己的统计槽，录制后汇总进 `frame_recorded` 并回填 `last_parallel_segments`。
