## 二、代码改动

### 新增 `src/render/Frame/core/并行录制.cpp`

1. `Frame_Context::parallel_plan(Frame_Slot&, item_count, color_format, depth_format, sample_count)`
   - 判定：线程池存在且已启动（> 1 线程）、`item_count >= parallel_min_items`、
     段数 = `min(线程数, parallel_max_segments, item_count / 16)`，且 ≥ 2、`secondary_buffers_ensure` 成功；
   - 满足则填充 `active_secondary / active_secondary_count / active_color_format / active_depth_format /
     active_sample_count / parallel_counts` 并返回段数，否则返回 0。
2. `Frame_Context::scene_parallel_record(command_buffer, rendering_info, color_attachment, depth_attachment,
   viewport, scissor, items, item_count, sample_count, ui_callback)`
   - 段内：`VkCommandBufferInheritanceRenderingInfo`（颜色格式数组取址、深度格式、采样数）→ 次级缓冲 `begin`；
   - 附件：首段沿用入参 `loadOp`、其余 `LOAD`；非末段把颜色与深度的 `resolveMode / resolveImageView` 一并清零；
   - UI：`segment + 1 == segment_count && sample_count <= 1` 时调用回调（与单线程位置一致）；
   - 收尾：一次 `vkCmdExecuteCommands(command_buffer, segment_count, active_secondary)`；
     汇总 `parallel_counts` 进 `frame_recorded`；回填 `last_parallel_segments`；返回段数。
