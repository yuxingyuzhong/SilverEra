## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| UBO 布局 | **零变更**（292 浮点 / 1168 字节）：色调 R / G 落 `camera_range.zw`，B 落 `cascade_params2.w`（三者此前均为保留分量） |
| 暗部判定 | 主方向光的量化后 `ndotl`；未提供法线或方向光强度 0 时保持 1 → 权重 0 → 不染色 |
| 权重曲线 | `1 − smoothstep(0, 0.5, shade)`：受光面（≥ 0.5）权重 0，全背光权重 1，过渡区平滑 |
| 作用对象 | 合成后的 `lit`（含环境光基底、PBR 漫反射权重与镜面），故环境光照亮的暗部同样被染色 |
| 关闭保证 | 默认 (1,1,1)：`mix(1, tint, w) == 1`，且着色器以 `any(notEqual(...))` 整段短路 |
| 取值归一 | 各分量非有限值按 1（白 = 关闭）、否则钳 [0, 1] |
