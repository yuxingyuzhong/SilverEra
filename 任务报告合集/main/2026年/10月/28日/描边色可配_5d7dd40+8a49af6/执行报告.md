## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 推送布局 | offset 80..91 尺寸、92..103 泛光参数（原 96 起 8 浮点保持不变）、112..127 描边色；范围 128 |
| 等价性 | `mix(a, 0, t) = a × (1 − t)`，故默认黑描边与旧实现逐字节相同 |
| 逐级语义 | 与 `post_stage_param4_set` 同口径：级序须在当前链内；链变更 / 清链 / 卸载管线 / 关闭均清除专设色 |
| 取值归一 | 各分量非有限值按 0（黑），其余钳 [0, 1]；第四分量保留恒 0 |
| 合批 | `batch_adjacent_items` 追加 `post_color` 逐字节比较，避免把不同描边色的项误合批 |
