## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| UBO 复用 | 沿用 `pbr_params.w`（243）与 `sky_params.w`（271）两个保留分量，UBO 仍为 292 浮点 / 1168 字节，**布局零变更** |
| 量化 | `floor(clamp(N·L,0,1) × steps + 0.5) / steps`；steps ≤ 0.5 时原样返回（关闭） |
| 边缘光 | 仅用几何法线（`in_normal`），强度钳到 [0,1]，三次方收窄，系数 2 保证可见 |
| 数据化 | `Light_Data` / `Scene_Data` 字段 → `scene_apply` → 门面 setter，三条路径同一口径 |
| 默认不变 | steps=0 时量化函数直接返回原值；rim=0 时整段跳过 → 既有画面逐字节不变 |

## 三、新增用例口径

| 用例 | 断言 | 实测 |
| --- | --- | --- |
| 色阶量化改变分面明暗 | 立方体 + 斜射光；steps=1（二值化）与 steps=0 两帧逐像素差 ≥ 20 的像素数 ≥ 30 | 通过（受光面整体拉满） |
| 边缘光抬升表面亮度 | 45° 倾斜面、无光照：关闭时中心 ≤ 20（黑），rim=1 时中心 ≥ 40 | 通过 |
| 风格化参数钳制与数据路径 | steps=100 → 8；rim=2 → 1、-1 → 0；`Scene_Data` / `Light_Data` 路径与 setter 一致 | 通过 |

> 调试记录：首版用例用 steps=3 时断言失败（变化像素 0）——原因是斜射光在立方体各面的 N·L ≈ 0.577，三档量化后从 0.577 → 0.667，sRGB 差仅约 14，低于 20 阈值。改为 steps=1（二值化）后差异约 55，用例稳定通过。功能本身无缺陷。
