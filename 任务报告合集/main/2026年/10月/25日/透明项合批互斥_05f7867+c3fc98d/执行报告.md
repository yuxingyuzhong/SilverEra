## 二、实现要点

1. **混合档查询**：`Pipeline_Context::pipeline_blend_mode_get()` 只读 `active_handle` 对应条目，不改变激活状态、不创建管线；未登记时按 `Opaque` 处理。
2. **绘制项标记**：门面在 `mesh_draw` 与 `mesh_draw_instanced` 组装 `Frame_Render_Item` 时置 `transparent = (混合档 != Opaque)`；文字管线为 `Alpha`，故文字绘制项全部为透明项。
3. **合批判据**：`batch_adjacent_items` 追加 `!last.transparent && !item.transparent`，透明项既不并入前项也不会被后项并入；其余等价条件（管线 / 布局 / 缓冲 / 索引区 / 推送常量 / 实例区连续 / 阴影标记 / 采样数）保持不变。
4. **字段隔离**：`transparent` 仅供门面合批使用，帧模块录制与统计路径不读取，故录制行为逐字节不变。
