## 二、实现要点

1. **主时间戳池扩为 4 查询**：0 = 帧始、1 = 场景结束、2 = 后处理结束、3 = 帧末。总耗时口径不变（3 − 0）；场景 = 1 − 0；后处理 = 2 − 1。
2. **三条录制路径写入分段点**：交换链直通在场景 `vkCmdEndRendering` 后连写 1 / 2（无后处理 → 后处理耗时≈0）；离屏路径同样连写 1 / 2；后处理链在场景结束写 1、全部后处理级结束后写 2。
3. **阴影独立计时**：阴影 pass 是独立提交，若复用主池会覆盖主帧时间戳；每帧槽另建 2 查询池，`render_to_target(..., shadow_pass = true)` 时使用该池，等尽在途帧后立即 `shadow_gpu_ms_read`。
4. **降级**：设备不支持 GPU 时间戳时三个分解字段恒 0；查询池创建失败仅告警并降级。
5. **统计口径**：`gpu_scene_ms + gpu_post_ms ≤ gpu_frame_ms`（差值为收尾布局转换与呈现准备）；`gpu_shadow_ms` 为最近一次实际执行的阴影 pass。
