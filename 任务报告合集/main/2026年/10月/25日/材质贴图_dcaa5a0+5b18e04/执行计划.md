# 执行计划 · 材质法线 / 粗糙度贴图（第一百二十四轮）

## 一、任务来源

用户 2026-10-25 列出的十项迭代方向第 6 项：

> PBR 贴图化：法线贴图 / 粗糙度贴图（材质数据扩展 + 实例材质索引），保留无贴图路径逐字节不变。

方向 5（景深）已在第 123 轮完成，本轮继续方向 6。

## 二、方案取舍

1. **贴图走 set 1 新增 binding 3 / 4**：现有绘制路径的 sampler set 是每帧槽一份、全帧共享，无法同帧逐物体换贴图；因此「实例材质索引」以**逐实例材质标量（法线强度）＋ 绘制期贴图绑定**的最小形态落地，真正的每实例索引用例留待结构性改造。
2. **以白纹理为默认**：未配置贴图时绑定内置默认白纹理，粗糙度乘子恒 1；法线强度 0 时着色器整段跳过 —— 二者共同保证无贴图路径逐字节不变。
3. **屏幕空间 TBN**：网格无切线属性，用法线贴图时以 `dFdx/dFdy` 的世界位置与 uv 导数现场构造切线基，避免改动网格格式与顶点属性。
4. **状态复位**：单独切换反照率时把 binding 3 / 4 复位为默认白纹理，防止上一材质贴图残留。

## 四、分段执行

1. **第一段：材质数据与登记** —— `Material_Data` 扩字段，`material_load` 记录并校验强度。
2. **第二段：描述符与绑定** —— set 1 增 binding 3 / 4，池容量扩容；`material_texture_bind`；`texture_bind_set` 复位。
3. **第三段：推送与着色器** —— 推送块 offset 80 下发法线强度；`场景.frag` 增加法线扰动与粗糙度乘子。
4. **第四段：测试与收口** —— 3 例即测；全量回归、双构建、文档。

## 五、验收口径

- 无贴图材质路径与直接绑定纹理逐字节一致（差 0）。
- 法线贴图（切线空间倾斜 45°、强度 1）使中心受光明显下降（≥ 20）。
- 粗糙度贴图 0.2 与 1.0 的高光亮度差 ≥ 20（方向不作断言）。
- 校验层 0 消息；Debug / Release 0 error。
