## 二、实现要点

1. **描述符而非实例索引**：现有绘制路径中 sampler set 是「每帧槽一份、全帧共享」（`texture_bind_set` 立即写满全部槽），无法做到同帧逐物体切换贴图。故贴图走 set 1 新增的 binding 3 / 4（与反照率同为绘制期状态），「实例材质索引」以**逐实例材质标量（法线强度）＋ 绘制期贴图绑定**的最小形态落地。
2. **无贴图即白纹理**：未配置时绑定内置默认白纹理，粗糙度乘子恒 1；法线强度 0 时着色器整段跳过法线分支 —— 两者共同保证无贴图路径**逐字节不变**（用例断言差 0）。
3. **无切线属性的 TBN**：网格顶点没有切线/副切线，法线贴图用屏幕空间导数（`dFdx/dFdy` 的世界位置与 uv）现场构造切线基，省掉网格格式与顶点属性改造。
4. **状态复位**：`texture_bind_set` 会把 binding 3 / 4 复位为白，避免「上一材质有法线贴图、下一材质没有」时的残留。
5. **校验口径**：`normal_strength` 合法域 (0, 4]，越界或非数按 0 登记并告警；贴图句柄无效在绑定期回落默认白纹理。
