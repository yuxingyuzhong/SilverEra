# 执行计划 · 分级调色后处理级（第一百二十二轮）

## 一、任务来源

用户 2026-10-25 列出的十项迭代方向第 4 项：

> LUT 色彩校正：新增 3D LUT 或解析式 color grading（lift/gamma/gain + 饱和度），作为后处理级；
> 验收与直通/反色链路一致。

方向 3（级联阴影）已在第 121 轮完成，本轮继续方向 4。

## 二、方案取舍

1. **取解析式，不取 3D LUT 贴图**：原文允许二选一。解析式的参数可直接复用既有「逐级后处理参数」（推送常量 offset 96），**不新增纹理资源、不改描述符布局**，改动面最小且与链式路径天然兼容。
2. **四参通道**：既有 `post_stage_param_set` 只接受三参（第四分量恒 0），而调色需要 lift / gamma / gain / saturation 四个自由度，故新增 `post_stage_param4_set`，与旧接口共用同一份逐级参数数组。
3. **恒等参数 `(0, 1, 1, 1)`**：保证默认参数下该级近似直通，可直接插进任意链而不改变画面（仅剩一次附件编解码取整）。
4. **双重钳制**：门面按合法域整次校验；着色器同口径 `clamp`，防止异常值使 `pow` 未定义。

## 四、分段执行

1. **第一段：着色器** —— 按 `Push_Post` 契约写 `分级调色.frag`，恒等参数下逐像素等于取源。
2. **第二段：门面接口** —— `post_stage_param4_set` ＋ 合法域校验；级序须在链内。
3. **第三段：测试** —— 恒等与直通链一致、增益 / 伽马方向、饱和度归零、非法参数忽略、串联反色可逆。
4. **第四段：收口** —— 后处理链套件 ＋ 全量回归 ＋ Debug / Release 双构建 ＋ 文档。

## 五、验收口径

- 链「直通 → 反色」与「分级调色(恒等) → 反色」逐像素最大差 ≤ 4（取整容差）。
- 中灰纹理：gain 0.5 明显变暗；gamma 2.0 明显提亮；gamma 0.5 明显变暗。
- 纯红纹理：饱和度 0 后三通道差 < 20。
- 越界 gamma / 越界饱和度 / 链外级序均整次忽略，该级参数保持原值。
- 「恒等调色 → 反色 → 反色」回到原画面（差 ≤ 4）。
- 校验层 0 消息；Debug / Release 0 error。
