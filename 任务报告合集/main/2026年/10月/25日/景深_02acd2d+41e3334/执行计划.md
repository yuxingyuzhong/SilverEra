# 执行计划 · 景深后处理级（第一百二十三轮）

## 一、任务来源

用户 2026-10-25 列出的十项迭代方向第 5 项：

> 景深（DoF）：基于深度图的单级后处理（对焦距离 / 光圈 / 最大模糊可配）；验收近景 / 远景模糊梯度可观测。

方向 4（分级调色）已在第 122 轮完成，本轮继续方向 5。

## 二、方案取舍

1. **用真实深度图，不用颜色 alpha 编码**：后处理采样集新增 binding 2 绑定场景深度，避免借用 alpha 影响透明混合与既有链路；代价是描述符布局与深度布局转换。
2. **布局转换放在帧模块**：只有后处理链需要深度；`Frame_Render_Target::depth_image` 为空时全部跳过，故 `render` / `render_to_target` / SSAA 三条路径行为不变。
3. **近远平面来自场景 UBO**：深度缓冲是 NDC 值，需近远平面才能换回世界距离；追加 `camera_range`（1072 字节）而非写死常数，保证相机近远可配时仍正确。
4. **参数复用既有逐级参数接口**：`post_stage_param_set(stage, 对焦距离, 光圈, 最大模糊)`，不新增门面 API。
5. **半径为 0 时直接写回**：保证「最大模糊 ≈ 0」与直通逐字节一致，便于回归定位。

## 四、分段执行

1. **第一段：深度可采样** —— 深度图加 `SAMPLED`；目标模块提供 `target_depth_get`。
2. **第二段：描述符与绑定** —— set 1 增 binding 2；池容量 ×3；`post_depth_bind`；`post_sets_bind` 携带深度视图并纳入签名缓存。
3. **第三段：布局转换** —— 链路径场景 pass 后转只读、链末转回深度附件。
4. **第四段：UBO 与着色器** —— 追加 `camera_range`（1072 字节）；写 `景深.frag`（CoC ＋ 12 抽样）。
5. **第五段：测试与收口** —— 3 例即测；全量回归、双构建、文档。

## 五、验收口径

- 对焦距离 = 物体到相机距离时，四边形内部像素与直通规格内一致（差 ≤ 2）。
- 严重离焦时，四边形上边缘之外同列像素明显变亮（≥ +8），中心仍 ≥200。
- 最大模糊 0.001 时整帧与直通一致（差 ≤ 2）。
- 校验层 0 消息；Debug / Release 0 error。
