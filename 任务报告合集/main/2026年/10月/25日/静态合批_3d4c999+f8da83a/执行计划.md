## 三、口径与取舍

1. **只合并相邻项**：不重排绘制顺序，避免改变透明混合次序与深度结果；非连续等价项不合并。
2. **等价判据**：管线 / 布局 / 顶点与索引缓冲 / 索引偏移与数量 / 推送常量逐字节 / 实例缓冲与连续区间 / 阴影标记 / 采样数全部一致。
3. **实例数守恒**：合并后实例区仍为原连续区间，`instance_count` 累加；`instances` / `drawn_instances` 不变。
4. **统计口径**：合并发生在录制列表组装期，故 `draw_items` 与 `drawn_items` 同步下降；`instances` 仍为所有实例数。
