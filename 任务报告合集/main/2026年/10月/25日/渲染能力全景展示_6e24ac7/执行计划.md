## 一、目标

1. 一条**交互巡览**用例：打开真实窗口，把渲染层当前全部能力按阶段自动轮播，配中文字幕与实时观测，供人眼验收 / 客户演示。
2. 一条**无人值守冒烟**用例：默认随全量回归运行，逐阶段渲染并断言「登记量 / 绘制量」，保证展示代码与渲染层接口同步、不会因迭代而失效。
3. 建立**同步机制**：展示内容由「阶段表」数据驱动，新增能力只需追加一项；维护约定写入文件头与工作站文档。

## 二、实现方式（自定方案，无需答疑）

| 设计点 | 决策 |
| --- | --- |
| 阶段划分 | 11 个阶段：程序化网格与纹理 / 光照 / PBR 材质 / 阴影与级联 / 实例化与合批 / 天空盒与雾 / 泛光 / 调色链 / 景深 / 抗锯齿 / 文字 |
| 数据驱动 | `展示阶段{名称, 说明, 应用函数}` 阶段表 ＋ 统一的「默认状态恢复」；阶段函数自包含，先复位再配置 |
| 绘制口径 | 每帧调用阶段函数重新登记绘制项（绘制项按帧消费），字幕走 `text_draw` / `text_draw_layout` |
| 交互门控 | 环境变量 `BYJY_SHOWCASE=1` 才运行交互巡览（默认跳过，避免无人值守时弹窗）；每阶段 150 帧、轮播 3 轮后自动结束，关窗即退出 |
| 冒烟门控 | 无门控；隐藏窗口 64×36，逐阶段三帧，断言 `draw_items` 增量与 `last_draw_items > 0` |
| 资源 | 8 种程序化网格、5 类纹理（棋盘 / 中灰 / 法线 / 粗糙 / 立方体天空）、7 条后处理管线、两台中间目标、一个中文字体句柄；由「资源准备 / 资源释放」成对管理 |
| 管线缓存 | 交互模式写入 `out/渲染展示管线缓存.bin`，二次启动更快 |
