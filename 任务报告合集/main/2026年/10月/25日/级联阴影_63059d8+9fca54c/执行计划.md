# 执行计划 · 级联阴影两级最小实现（第一百二十一轮）

## 一、任务来源

用户 2026-10-25 列出的十项迭代方向中第 3 项：

> 级联阴影（CSM）预研与最小实现：2 级级联 + 按视锥切分选择，先保证单级行为不变；
> 若复杂度过高则退化为「范围可配 + 分辨率自适应」。

方向 1（管线缓存持久化）与方向 2（阴影范围可配）已在第 106 / 107 轮完成；本轮从方向 3 起补做。

## 二、约束与取舍

1. **单级行为必须逐字节不变**：级联为可选开关（默认 1 级），关闭时沿用「以世界原点为中心、半宽 12、光源机位固定 `-light_dir × 20`、近远 1/60」的既有口径。
2. **不引入视场角依赖**：两片级联定为「以相机为中心的包围球」，半径分别为 `split_distance` 与 `split_distance × far_scale`。片元按「与相机的世界距离」选级，与包围球定义严格一致，无需视场角与宽高比参与。
3. **不新增渲染目标 / 描述符绑定**：两片共用同一张阴影图，沿 X 轴切成左右半片（各占边长一半），靠「子视口 + 分次提交」写入，避免改动描述符布局与采样器数量。
4. **UBO 扩容一次到位**：远区矩阵 ＋ 级联参数一次追加（244 → 264 浮点，976 → 1056 字节），同步修改着色器 std140 契约与门面按需写入的逐帧槽缓存。

## 四、分段执行

1. **第一段：帧模块子视口与保留式加载** —— 只加不改：新增字段默认「整幅目标」，新增语义仅在传空清屏色时生效，保证既有四条录制路径行为不变。
2. **第二段：级联矩阵与分片绘制** —— 双级时逐片计算光源机位 / 正交范围 / 深度跨度，阴影 pass 对同一目标两次 `render_to_target`（首片清屏、次片保留）。
3. **第三段：UBO 与着色器契约** —— 场景 UBO 扩至 264 浮点，着色器同步扩容；选级阈值取 1.5（级联数为 1 时不触发双级）。
4. **第四段：门面接口** —— `shadow_cascade_set/get`，非法参数整次忽略并置阴影图失效。
5. **第五段：测试与收口** —— 新增 4 例，跑场景套件与全量回归，Debug / Release 双构建，最后文档收口。

## 五、验收口径

- 默认（1 级）与显式设为 1 级两帧逐字节一致；中心仍被遮蔽。
- 相机移到 x = 20 时：单级覆盖不到（中心受光 ≥150），双级覆盖（中心 <60）。
- 双级下近区仍遮蔽中心；切回单级后与原单级帧逐字节一致。
- 非法级联参数（级联数 3 / 远区倍数 0.5 / 切换距离 −1）整次忽略。
- 校验层 0 消息；Debug / Release 0 error。
