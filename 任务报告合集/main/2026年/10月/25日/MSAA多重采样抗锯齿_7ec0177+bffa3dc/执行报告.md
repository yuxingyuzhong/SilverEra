## 交付

1. **图像采样数**：`Memory_Context::image_create` 增 `samples` 参数（默认 1），MSAA 附件按 2/4/8 创建。
2. **交换链 MSAA**：`Swapchain_Context` 增采样数配置与每交换链图像的多重采样颜色 / 深度图像与视图；重建时随旧资源整体移交延迟销毁；深度附件在创建后统一转入 `DEPTH_ATTACHMENT_OPTIMAL`。
3. **渲染目标 MSAA**：`Render_Target_Record` 增多重采样附件与采样数 / 跟随标记；`sample_count_set` 按新采样数重建全部跟随目标（句柄不变）；阴影目标固定 1×；MSAA 下 `target_readback_depth` 明确拒绝。
4. **管线采样数**：`Pipeline_Config.sample_count` ＋ `Pipeline_Entry.sample_count`（0 = 跟随配置，非 0 = 固定）；阴影管线固定 1×；`pipeline_rebuild` 同时比较格式与采样数。
5. **动态渲染解析**：交换链直通、离屏目标、同色后处理链各级均以「多重采样颜色/深度附件 ＋ `resolveMode=AVERAGE` → 单采样目标」录制；MSAA 下 UI 改为解析完成后另起单采样通道（`loadOp=LOAD`）。
6. **门面**：`Renderer_Config::msaa_samples`、`msaa_samples_set` / `msaa_samples`；初始按「颜色 ＋ 深度格式共同支持」钳制；运行时切换依次等尽在途帧 → 重建交换链附件 → 重建渲染目标 → 重建全部管线，并把当前绑定视图回落默认白纹理。
