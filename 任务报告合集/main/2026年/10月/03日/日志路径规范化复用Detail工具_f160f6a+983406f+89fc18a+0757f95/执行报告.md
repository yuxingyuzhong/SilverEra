## 三、实现细节

### 3.1 新增 `detail::path_key_normalize`（`文件路径规范化.h`）

```cpp
#pragma once
//预编译头
#include "common/前置头文件包含.h"
//获取路径字符串转换工具
#include "路径字符串转换.h"

namespace engine
{
    namespace detail
    {
        //路径规范化（统一目录分隔符并消除尾部分隔符，供路径比较与哈希使用）—— 零改动
        inline std::filesystem::path path_normalize(const std::filesystem::path& path) { /* 原样 */ }

        //路径键规范化（在路径规范化基础上剥离到项目根相对路径，统一 '/' 分隔符并末尾补 '/'，供路径前缀比较与哈希使用）
        //root_anchor：项目根目录名（以 '/' 结尾），用于把绝对路径裁剪为项目内相对路径
        inline std::string path_key_normalize(const std::string& raw, const std::string& root_anchor)
        {
            //复用通用路径规范化（统一分隔符并消解"."与".."）后转回 UTF-8 文本
            std::string path = path_to_string(path_normalize(string_to_path(raw)));
            //统一路径分隔符为正斜杠
            for (char& ch : path) { if (ch == '\\') ch = '/'; }
            //取项目根锚点最后一次出现的位置
            const size_t anchor_pos = path.rfind(root_anchor);
            //若锚点存在则剥离锚点及其之前的部分
            if (anchor_pos != std::string::npos)
                path.erase(0, anchor_pos + root_anchor.size());
            //剥离开头的前导分隔符与 './' 片段
            for (;;) { /* 去前导 '/' ；去前导 './' */ }
            //末尾补 '/'，使目录节点与文件节点共用同一套路径段前缀比较
            if (!path.empty() && path.back() != '/')
                path.push_back('/');
            //返回规范化路径键
            return path;
        }
    }
}
```

（以上为便于阅读的压缩示意，实际源码为完整逐行注释版，共 75 行。）

**设计要点**：词法规范化（分隔符统一、`.`/`..` 消解）与 UTF-8 编解码**全部下沉**到 Detail，日志侧不再持有任何路径规范化算法。`root_anchor` 由调用方传入 ⇒ 通用工具内**不出现项目名**。
