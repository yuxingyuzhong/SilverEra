## 二、现状核对

### 2.1 两条实现的职责与产出

| 项 | `detail::path_normalize`（`Detail/文件路径规范化.h`，属 `package/路径操作工具.h` 包） | `Stream_Tree::path_normalize`（`Logging/Stream_Tree/流节点树.h`） |
| --- | --- | --- |
| 签名 | `std::filesystem::path → std::filesystem::path` | `const std::string& → std::string`（私有成员） |
| 步骤 | ① `lexically_normal()`（消解 `.`/`..`）② 以 `root_path()` 逐节 `operator/=` 重组 | ① `\`→`/` ② 按锚点 `白银纪元/` 裁到项目内相对路径 ③ 去前导 `/`、`./` ④ 末尾补 `/` |
| 产出形态 | 绝对路径 + **平台首选分隔符**（Windows 为 `\`）+ 无尾分隔符 | 项目内相对路径 + `/` + 尾分隔符 |

### 2.2 结论：不能整函数替换

通用版产出「绝对路径 + 平台分隔符 + 无尾分隔符」，日志需要「项目内相对路径 + `/` + 尾分隔符」的**树键**（键恒以 `/` 结尾，供 `prefix_common` 在路径段边界做前缀比较）。两者产出形态不同，故按任务后一种路径 —— **增量改进**。

可复用的部分：词法规范化（分隔符统一／`.`、`..` 消解）＋ UTF-8 编码转换。日志专属部分：锚点裁剪 ＋ 尾补 `/`（树键格式）。

## 三、方案（裁定 B）

在 `文件路径规范化.h` 新增 `detail::path_key_normalize`，**构建在既有 `path_normalize` 之上**（词法口径唯一），职责 = 词法规范化 ＋ UTF-8 转换 ＋ 锚点裁剪 ＋ 统一 `/` ＋ 尾补 `/`。

- `detail::path_normalize` 的签名与语义 **零改动** ⇒ `Config_Content` 的 4 处调用、`operator==`、`std::hash` 特化全部兼容；`Config_Loader` 使用方式不变。
- `package/路径操作工具.h` 保持**纯聚合**（与 `package/数据校验工具.h` 同构），新增函数自动经其透出。
- 日志侧：删除自实现逻辑，改调用 `detail::path_key_normalize`；锚点常量留在日志侧（裁定：留在日志侧）。

### 4.1 `path_key_normalize` 拟定实现

```cpp
//路径键规范化（在路径规范化基础上剥离到项目根相对路径，统一 '/' 分隔符并末尾补 '/'，供路径前缀比较与哈希使用）
//root_anchor：项目根目录名（以 '/' 结尾），用于把绝对路径裁剪为项目内相对路径
inline std::string path_key_normalize(const std::string& raw, const std::string& root_anchor)
{
    //复用通用路径规范化（统一分隔符并消解 "." 与 ".."），再转回 UTF-8 文本
    std::string path = path_to_string(path_normalize(string_to_path(raw)));
    //统一路径分隔符为正斜杠
    for (char& ch : path)
    {
        if (ch == '\\')
            ch = '/';
    }
    //取锚点最后一次出现的位置
    const size_t anchor_pos = path.rfind(root_anchor);
    //若锚点存在则剥离锚点及其之前的部分
    if (anchor_pos != std::string::npos)
        path.erase(0, anchor_pos + root_anchor.size());
    //剥离开头的前导分隔符与 './' 片段
    for (;;)
    {
        if (!path.empty() && path.front() == '/')
        {
            path.erase(0, 1);
            continue;
        }
        if (path.compare(0, 2, "./") == 0)
        {
            path.erase(0, 2);
            continue;
        }
        break;
    }
    //末尾补 '/'，使目录节点与文件节点共用同一套路径段前缀比较
    if (!path.empty() && path.back() != '/')
        path.push_back('/');
    //返回规范化路径键
    return path;
}
```
