## 三、目标结构（对照 spatial 层级）

```
src/tools/Logging/
├── 日志系统运行包.h              # 一键获取完整日志系统 + inline Log logger;
├── Log/日志系统.h                # class Log（门面，has-a Stream_Tree）
├── Stream_Tree/流节点树.h        # class Stream_Tree（节点结构 + 树操作 + 容器解析；has-a Node_Cache）
├── Stream_Sink/输出目标.h        # class Stream_Sink + Log_Stream 别名
└── Node_Cache/节点缓存.h         # template<Node> class Node_Cache
```

- 模块对外总头＝`日志系统运行包.h`（与 `事件系统运行包.h` / `对象系统运行包.h` / `碰撞系统运行包.h` 同一约定）。
- 模块为纯头文件，故各子文件夹不带 `局部命名空间使用.h`（沿用项目原始文件架构）。
- 模块内部用相对路径互相包含；模块外调用点一律用根相对路径 `src/tools/Logging/日志系统运行包.h`。
