## 三、结构与职责

```
src/tools/Logging/
├── 日志系统运行包.h              ← 模块对外总头：一键获取 + inline Log logger;
├── Log/日志系统.h                ← class Log
├── Stream_Tree/流节点树.h        ← class Stream_Tree
├── Stream_Sink/输出目标.h        ← class Stream_Sink + Log_Stream
└── Node_Cache/节点缓存.h         ← template<Node> class Node_Cache
```

has-a 关系（均为**值成员**，非指针/引用）：

```
Log ──has-a──► Stream_Tree ──has-a──► Node_Cache<Stream_Node>
                              └──aggregate(shared_ptr 容器)──► Stream_Sink
```

| 类 | 单一职责 | 对外接口 |
| --- | --- | --- |
| `Stream_Sink` | 线程安全输出目标（内部互斥 + 缓冲，达阈值落盘） | `write` / `flush` |
| `Node_Cache<Node>` | 调用处文件指针 → 节点指针 的线程安全缓存 | `cache_fetch` / `cache_store` |
| `Stream_Tree` | 链表树建立与路径规范化、节点定位、生效容器解析、整树落盘、日志行路由 | `stream_bind`×2 / `stream_clear` / `stream_flush` / `stream_output` |
| `Log` | 日志门面：调用处捕获、消息行合成、对外转发 | `info`/`warn`/`error`/`debug` / `stream_bind`×2 / `stream_clear` / `stream_flush` / `Format` / `Stream` |

**兼容性保持**：
- `Log::Stream` 仍存在（`using Stream = Log_Stream;`），故测试中 `engine::Log::Stream()` 无需改动；
- `logger.info/warn/error/debug/stream_bind/stream_clear/stream_flush` 的调用形式与语义完全不变；
- 上轮实现的并发与缓存机制（节点级锁、`tree_epoch` 版本号校验、调用点缓存 O(1) 定位、Sink 阈值缓冲）**原样迁移**，未改语义。
