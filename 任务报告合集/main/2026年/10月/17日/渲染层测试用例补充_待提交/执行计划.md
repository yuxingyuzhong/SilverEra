## 二、关键判定：本轮用例形态 = 公共 API 集成测试

渲染层以内隔离（私有包含根）把 SDL3 / Vulkan / VMA 全部关在层内，Test 层**拿不到 Vulkan 头**，因此**无法** include 渲染层的模块私有头（`Pipeline/管线.h`、`Shader/着色器模块.h`、`Scene/相机.h` 等），也就无法做模块级单元测试。本轮用例定为**公共 API 集成测试**（`Renderer` 门面），模块级回归点按下表处置：

| 汇总文件条目 | 本轮处置 |
| --- | --- |
| L1-01~04 / L2-01~08 / L3-01~03 | 直接可测（公共 API） |
| R-01 销毁顺序 | 可测：`init` → `shutdown`，校验层无「表面晚于实例销毁」报错 |
| R-05 帧计数合并 | 可测：`frame_count()` 递增且等于成功帧数（间接覆盖槽号 = `count % overlap`） |
| R-06 `frame_overlap` 钳制 | 间接：`frame_overlap` 取 1/2/3 与「超图像数」各能 `init` 并连续跑帧不崩 |
| R-07 暂存顺序写 | 间接：网格/纹理上传后绘制成功 |
| R-08/R-09 着色器短读/魔数 | 可测：`shader_dir` 指向含「截断 / 魔数错」`.spv` 的临时目录 → `init` 返回假 |
| R-10 纹理销毁顺序无关 | 间接：多纹理创建后逐条 `texture_unload` → 无崩溃 |
| R-13 同帧多网格 | 可测：同帧 `mesh_draw` ×2 → `frame_render` 为真 |
| R-14 `texture_unload` | 可测：`texture_load` → `texture_unload` → 再 `texture_bind_set` 后跑帧无崩 |
| R-02 像素尺寸事件 | **不可测**（公共面无 resize 入口）→ 记为不可测 |
| R-03a/b `pipeline_rebuild` | 间接（`L2-02` resize 重建时同格式为空操作路径）；异格式无法从公共面构造 → 部分不可测 |
| R-04 顶点布局 `static_assert` | 编译期，由「双树构建通过」覆盖 |
| R-11 共享采样器 | **不可测**（无公共观测点）→ 记为不可测 |
| R-12 `orbit` up 归一化 | **不可测**（`orbit` 不在公共面）→ 记为不可测 |
| R-15 私有包含根隔离 | 由「Test 编译时拿不到 Vulkan 头」自然旁证 |

## 五、风险与说明

1. **真机依赖**：L1/L2 虽不弹窗，但仍需真实 Vulkan 设备与显示环境（`hidden=true` 仍创建真实窗口与表面）。若本机无可用设备，L1/L2 会失败并回报。
2. **重复 init/shutdown**：用例会多次创建/销毁 SDL 与 Vulkan 实例，依赖门面 `shutdown` 幂等（已核实会复位 `initialized`/`frame_count`/待绘制项）。
3. **着色器路径**：Test 输出目录的 `shaders/` 必须与所链 `RendererCore.lib` **同版次**；故着色器源目录按 `RendererCore` 的 `IMPORTED_LOCATION` 同源推导，不写死 Debug/Release。
4. **L3 默认不跑**：以环境变量（如 `BYJY_RUN_L3=1`）开启，避免无人值守运行被弹窗挂住；默认全跑时计为 skip。
5. **不提交**：按用户口径本轮不做 git 提交，改动留在工作区供后期「项目导航」更新取 diff；任务报告目录暂以 `_待提交` 结尾，待提交后改名为哈希。
6. **不可测项**：R-02 / R-11 / R-12 与 R-03 的「异格式重建」分支无法从公共面构造，已在《测试用例汇总.md》与本计划中记明，留待后续若开放对应公共入口再补。
