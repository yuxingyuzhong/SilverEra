## 三、分段执行

### 阶段一：物理重组（目录搬移）
把 `任务报告合集/main/<报告目录>/` 逐一搬入 `任务报告合集/main/<年>年/<月>月/<日>日/<报告目录>/`，共 34 份。
`报告提交历史.md` 属**分支级索引**，留在分支根，不随日期下沉。

搬移驱动方式：**TSV 数据 ＋ 纯 ASCII PowerShell 脚本**
（`临时/重组清单.tsv` ＋ `临时/任务报告重组.ps1`，一行为 `<目标相对目录>\t<报告目录名>`，首行 `@BRANCH` 声明分支根）。

### 阶段二：索引路径改写
三份索引文件中的路径引用按**各自前缀规则**补入日期层级：

| 文件 | 旧形态 | 新形态 | 处数 |
| --- | --- | --- | --- |
| `README.md`（工作站根） | `任务报告合集/main/{N}` | `任务报告合集/main/{D}/{N}` | 32 |
| `任务报告合集/README.md` | `](main/{N}` | `](main/{D}/{N}` | 32 |
| `任务报告合集/main/报告提交历史.md` | `任务报告合集/main/{N}` | `任务报告合集/main/{D}/{N}` | 55 |

驱动方式：`临时/补丁规则.tsv`（`<文件相对路径>\t<旧模板>\t<新模板>`，模板中 `{N}`＝报告目录名、`{D}`＝日期层级）＋ `临时/索引修补.ps1`。
替换**按报告目录名长度降序**执行，防止一个名字是另一个名字前缀时相互污染。

> 注意：两份 README 的前缀规则不同 —— 根 README 与 `报告提交历史.md` 用 `任务报告合集/main/`，而 `任务报告合集/README.md` 用 `](main/`。若统一处理会误伤 `项目导航合集/main/` 下的同名目录（如 `构建系统适配Engine聚合层_…`、`日志系统链表树分流_63a51b6+e0a3ed5`、`碰撞步长检测与位移帧挂钩_2d5f704` 在两个合集下同名）。

## 六、风险与对策

| 风险 | 对策 |
| --- | --- |
| 无 BOM 的 `.ps1` 被 PowerShell 5.1 按 ANSI(936) 解读，中文注释与中文字面量必然解析失败 | 脚本**保持纯 ASCII**（含注释），全部中文数据（映射清单、补丁规则）放独立 UTF-8 文件，由脚本以 `UTF8Encoding($false)` 显式读取 |
| 读写编码被写坏（写入 BOM／转为 ANSI） | 一律 `[System.IO.File]::ReadAllText/ReadAllLines` ＋ `WriteAllText/WriteAllLines` 配 `UTF8Encoding($false)`；事前已核验三份索引文件均无 BOM |
| 目录名互为前缀导致替换污染 | 已核验 34 个目录名两两不存在「一个是另一个的严格前缀」；并额外按长度降序替换兜底 |
| 三份索引文件前缀规则不同，统一替换会误伤项目导航合集 | 「补丁规则.tsv」按文件分别给出旧/新模板，逐文件处理 |
| 目录搬移误伤已存在的同日目录 | 搬移脚本对目标目录做「不存在则创建」，逐条 `Move-Item -LiteralPath`；搬移后逐层核验目录数与目录内文件 |
