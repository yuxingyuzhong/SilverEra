## 五、SDL3 就地裁剪口径

**保留**：

- `include/`（整棵，含 `include/build_config/`：`SDL_build_config.h` 派发头与
  `SDL_build_config_windows.h` 等，SDL3 非 CMake 构建正是靠它工作；含 `include/SDL3/SDL_revision.h`）
- `src/` 中 **`VisualC/SDL/SDL.vcxproj` 文件清单（`ClCompile` ＋ `ClInclude` 并集）所列的全部文件**
- `LICENSE.txt`

**删除**：`.github/`、`android-project/`、`build-scripts/`、`cmake/`、`docs/`、`examples/`、`test/`、
`VisualC/`、`VisualC-GDK/`、`wayland-protocols/`、`Xcode/`，以及 `src/` 中不在上述并集内的全部文件
（含 x11 / wayland / alsa / pulseaudio / coreaudio / android 等非 Windows 后端），随后清理空目录，
再删除 `.clang-format`、`.clang-tidy`、`.editorconfig`、`.gitignore`、`.wikiheaders-options`、`AGENTS.md`、
`Android.mk`、`BUGS.txt`、`CLAUDE.md`、`CMakeLists.txt`、`CREDITS.md`、`INSTALL.md`、`README.md`、`WhatsNew.txt`。

**为什么裁剪 `src/` 用显式清单而不是「删平台目录」**：显式清单是官方工程的实际编译集合，一次做对；
裁剪后 `external/SDL3/src` 恰好只余该集合，`CMakeLists.txt` 直接 `file(GLOB_RECURSE)` 即可，
后续 SDL 升级也只需重跑同一裁剪脚本。

**已知取舍**：`src/core/windows/pch.c`、`pch_cpp.cpp` 是官方工程的预编译头单元，渲染层不开预编译头，
二者编译为空单元，保留（保持「保留集合 = vcxproj 并集」这条简单规则，不做特例）。

**风险与回退**：若裁剪误删了传递包含所需的头，构建会以「找不到头」明确失败；按报错从原目录补回即可
（裁剪脚本在一次运行内完成，可重复执行）。

## 六、Vulkan SDK 探测口径（`cmake/VulkanSDK探测.cmake`）

```
① $ENV{VULKAN_SDK} 非空且 <该目录>/Include/vulkan/vulkan.h 存在 → 采用
② 否则枚举 C:/VulkanSDK/*，取版本号最大者，要求其含 Include/vulkan/vulkan.h ＋ Lib/vulkan-1.lib
③ 都不满足 → FATAL_ERROR，并打印排查提示（不静默降级、不猜路径）
```

产物变量：`BYJY_VULKAN_SDK_ROOT`、`BYJY_VULKAN_INCLUDE_DIR`、`BYJY_VULKAN_LIB`。

## 七、构建脚本设计要点（`Application/Renderer/CMakeLists.txt`）

1. `cmake_minimum_required 3.20`；`/WX-`；`project(Renderer LANGUAGES C CXX)`；C++20 强制。
2. **构建类型校验块**：照抄 `EngineSystem/CMakeLists.txt`（空 → 按 Debug 并打印提示；非法 → `FATAL_ERROR`）。
3. **下层接入**：`include(cmake/接入下层.cmake)` → `byjy_jieru_xiaceng(<项目根>/Engine/cmake/对外接口.cmake, BYJY_ENGINE, BYJY_ENGINE_LIB_PATH)`。
4. **本层库类型本地映射**（用户追加要求）：
   - `BYJY_ENGINE_LIB_PATH` 声明为 `CACHE STRING`，**留空 = 自动按本层构建类型映射**；
   - `Debug`（及 `RelWithDebInfo`/`MinSizeRel` 之外的缺省）→ `Engine/EngineSystem/out/build/x64-Debug/lib/EngineSystem.lib` ＋ `Engine/EngineCore/out/build/x64-Debug/lib/EngineCore.lib`；
   - `Release` → 同名 `x64-Release` 两份；
   - 显式指定 `-DBYJY_ENGINE_LIB_PATH=a;b` 时**优先用户给定**（不覆盖用户意志）；
   - 映射结果作为普通变量传给接入函数（不写回 cache），保证 `接入下层.cmake` 无需改动。
5. **头快照接入**：`byjy_tou_kuaizhao_gen(... EngineCore)` / `(... EngineSystem)`，包含根
   `[EngineCore 快照根, EngineSystem 快照根, 项目根]`（快照在前，次序不可颠倒）。
6. **源收集**：
   - 本层：`src/**/*.cpp|c|h|hpp`；
   - SDL3：`external/SDL3/src/**/*.c|cpp`（裁剪后即官方并集）＋ 头文件仅作索引；
   - 已裁剪目录逐个登记 `CMAKE_CONFIGURE_DEPENDS`（沿用修「VS 增删文件不同步」的做法）。
7. **单一目标** `RendererCore`（STATIC）：
   - PUBLIC 包含根 = 下层快照 ＋ 项目根 ＋ `BYJY_RENDERER_OUT_INC`（沿用 `EngineSystem` 的写法，让对外面成为唯一真源）；
   - PRIVATE 包含根 = `external/SDL3/include`、`external/SDL3/src`、`external/VulkanMemoryAllocator/include`、`<Vulkan SDK>/Include`；
   - PUBLIC 链接 = `EngineCore` `EngineSystem` ＋ `BYJY_RENDERER_OUT_LINK` ＋ `BYJY_RENDERER_OUT_SYS`；
   - 编译选项与下层一致（`/MP /utf-8`、`_CRT_SECURE_NO_WARNINGS`）；
   - 输出到 `<构建树>/lib/RendererCore.lib`。
   - **注意**：SDL3 用相对路径 `./khronos/vulkan/vulkan.h` 引用自带 Khronos 头，
     故**不得**把 `external/SDL3/src/video/khronos` 加进包含路径，避免遮蔽 Vulkan SDK 的 `vulkan.hpp`。
8. **对外头快照导出**：复用 `Engine/EngineCore/cmake/导出头快照.cmake`，
   `MIRROR_DIRS=Application/Renderer/common;Application/Renderer/src`（external 不镜像）。
9. 归档响应文件 BOM 包装器：**照搬 `EngineCore` 的做法**（中文源文件名 + Ninja + MSVC 的 `LNK1181` 对策）。

## 八、对外接口（`cmake/对外接口.cmake`）设计

- 首行 `include("${CMAKE_CURRENT_LIST_DIR}/../../Engine/cmake/对外接口.cmake")`（并入 Engine 聚合面）；
- `BYJY_RENDERER_OUT_LIB = RendererCore`；`BYJY_RENDERER_OUT_LIBDIR = Application/Renderer`；
- `BYJY_RENDERER_OUT_INC = ${BYJY_ENGINE_OUT_INC}`（本层自有包含由「项目根」承担）；
- `BYJY_RENDERER_OUT_DEF = ${BYJY_ENGINE_OUT_DEF}`；
- `BYJY_RENDERER_OUT_LINK = ${BYJY_ENGINE_OUT_LINK}` ＋ `${BYJY_VULKAN_LIB}`（`RendererCore` 内含 Vulkan 符号，最终链接需要 `vulkan-1.lib`）；
- `BYJY_RENDERER_OUT_SYS = ${BYJY_ENGINE_OUT_SYS}` ＋ SDL3 在 Windows 上的额外系统库
  （`setupapi;winmm;imm32;version;ole32;oleaut32;advapi32;uuid`，口径取自 `SDL.vcxproj` 的 `AdditionalDependencies`）。
