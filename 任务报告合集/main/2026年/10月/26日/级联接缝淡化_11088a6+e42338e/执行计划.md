# 执行计划 · 级联接缝淡化（第一百四十八轮）

- 轮次：第 148 轮
- 日期：2026-10-26
- 起始代码版次：Renderer `b710e30`；Test `01ddf92`
- 目标：在级联切换阈值两侧做平滑混合，消除分辨率突变接缝；默认 0 保持硬切换的逐字节行为。

## 一、分段执行

1. **着色器重构**：把单级阴影采样抽为 `shadow_sample(index, count, world_pos, normal)`，
   矩阵 / 深度跨度按级序取；像素级逻辑（级选择、贴图分片、PCF）语义不变。
2. **接缝淡化**：`cascade_params2.z` 承载淡化带宽比例（0..0.5）；在阈值 ±（阈值 × 比例）带内，
   对相邻两片因子做 `smoothstep` 加权混合；比例为 0 时整段跳过。
3. **门面**：新增 `shadow_cascade_blend_set(0..0.5)` 与 `shadow_cascade_blend()`；UBO 写 290 号槽。
4. **测试**：三帧序列「硬切换 → 淡化 0.3 → 归零」，断言中心亮度变化与逐字节恢复。
5. **展示同步（规则 §4.1）**：展示场景淡化设为 0.2，GUI 清单标注「接缝淡化」。
