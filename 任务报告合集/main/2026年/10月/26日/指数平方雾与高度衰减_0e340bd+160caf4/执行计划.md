# 执行计划 · 指数平方雾与高度衰减（第一百四十三轮）

- 轮次：第 143 轮
- 日期：2026-10-26
- 起始代码版次：Renderer `4dbdaaa`；Test `fe964ca`
- 目标：雾模型从单一线性区间扩为「线性 / 指数平方」双模式，并补高度衰减；默认参数保持既有画面逐字节不变。

## 一、分段执行

1. **数据面**
   - `Fog_Data` 增 `mode`（0 线性、1 指数平方）与 `height_falloff`（每世界单位系数，0 = 关闭）。
   - 扁平 `Scene_Data` 对应增 `fog_mode` / `fog_height_falloff`，保持字段默认值不改变既有语义。
2. **门面**
   - 新增 `fog_exp2_set(color, density, start)`：`1 − exp(−(density × (距离 − start))²)`，成功即切模式 1。
   - `fog_set` 成功即复位模式 0；新增 `fog_height_set(falloff)`（0..10，非法整次忽略）与 `fog_mode_get()`。
   - 三组 `scene_apply` 按 `fog.mode` 分派，并转发高度系数。
3. **UBO**
   - 复用已有 `fog_range` 的 z / w 槽：z = 模式、w = 高度系数；**不改变 UBO 尺寸**，避免测试层重配以外的布局风险。
4. **着色器**
   - `场景.frag` 在雾块内分支：模式 1 走指数平方，模式 0 保持原线性公式；随后乘 `exp(−falloff × max(y, 0))`。
5. **测试**
   - 指数平方：距离饱和、同密度比线性更浓、切回线性逐字节还原、非法参数忽略、场景描述携带。
   - 高度雾：贴地不受影响、抬升物体更通透、非法系数忽略。
6. **展示同步（规则 §4.1）**
   - 展示场景改用指数平方雾（密度 0.022、起雾 6、高度系数 0.012），GUI 能力清单标注双模式。

## 三、验收口径

- 默认（模式 0、系数 0）下既有雾用例逐字节不变。
- 指数平方在相同密度下明显浓于线性（中心亮度至少低 40 级）。
- 高度系数归零后画面逐字节还原；贴地片元亮度抖动 ≤ 2。
- Debug ＋ Release 三树 0 error；全量回归（含四叉树）0 失败。
