## 二、实现要点

1. **零 UBO 扩容**：模式与高度系数复用 `fog_range` 的 z / w（原先闲置），场景 UBO 尺寸与逐帧写入区间不变。
2. **默认零副作用**：模式 0 走原线性公式；高度系数 0 时 `exp(0) = 1`，既有雾用例保持逐字节一致。
3. **模式互斥**：`fog_set` 与 `fog_exp2_set` 都成功时分别把模式置 0 / 1；非法参数整次忽略且不改模式。
4. **校验口径**：指数平方只校验颜色、密度（0..1）与起雾距离（≥ 0）；高度系数接受 0..10，NaN / 负值 / 越界均拒绝。
5. **展示同步（规则 §4.1）**：展示场景使用指数平方雾叠加高度衰减，GUI 清单同步。
