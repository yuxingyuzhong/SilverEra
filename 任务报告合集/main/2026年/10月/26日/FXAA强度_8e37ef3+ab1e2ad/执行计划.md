- 目标：给 FXAA 预设补强度参数（0 = 旁路、1 = 全量），默认行为保持不变。

## 一、分段执行

1. **着色器**：`FXAA.frag` 改读完整推送常量块；强度取 `post_param.z`（0..1），为 0 时原样输出，
   非 0 时四邻域混合量再乘强度。
2. **默认值**：未专设该级参数时 `post_param.z` 取全局泛光强度 1.2 → 归一为 1，故既有 FXAA 行为不变。
3. **展示同步（规则 §4.1）**：展示链第 6 级（FXAA）显式设强度 1；尺寸重建路径同步。
4. **测试**：既有斜边用例改为显式强度 1；新增「强度 0 原样输出」。
5. 双构建、全量回归与文档收口。
