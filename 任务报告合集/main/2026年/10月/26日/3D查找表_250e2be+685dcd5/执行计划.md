# 执行计划 · 3D LUT 色彩查找（第一百四十四轮）

- 轮次：第 144 轮
- 日期：2026-10-26
- 起始代码版次：Renderer `0e340bd`；Test `160caf4`
- 目标：把 3D LUT 色彩查找接入后处理链，支持恒等表 / 自定义分级表与混合强度。

## 一、分段执行

1. **着色器**：新增 `色彩查找.frag`；LUT 以 2D 条带存放（宽 = 边长²、高 = 边长），
   以 `texelFetch` 手工三线性采样（避开共享采样器的重复寻址串层）。
2. **管线**：`Pipeline_Context::post_lut_bind` 把 LUT 视图写入全部后处理描述符集的 set 1 binding 3；
   与场景集 binding 3（材质法线）分属不同描述符集，互不影响。
3. **门面**：新增 `texture_load_lut_identity(handle, edge)`、`post_lut_bind(handle)`、`post_lut_get()`。
4. **色彩空间**：纹理格式为 `R8G8B8A8_SRGB`，恒等表按 sRGB 编码存储，避免叠加一次错误伽马。
5. **测试**：恒等表不改变画面、反色表反转颜色、半量混合、恒等表参数校验、绑定可观测性。
6. **展示同步（规则 §4.1）**：展示链扩为「亮部提取 → 模糊 → 暗角 → 3D LUT → FXAA」，暖调 LUT 全量应用；GUI 清单同步。

## 三、验收口径

- 恒等表与直通路径的逐通道差 ≤ 链容差（4）。
- 反色表在强度 1 下中心变黑、角落变亮；强度 0 时逐级关闭、中心回白；强度 0.5 落中间亮度。
- LUT 边长仅接受 2..64；无效绑定时保持原绑定。
- Debug ＋ Release 三树 0 error；全量回归（含四叉树）0 失败。
