## 二、实现要点

1. **仅深度**：不引入法线 / 位置缓冲；用 `camera_range` 的近远平面把深度换回世界距离，避免透视深度非线性带来的误判。
2. **两圈八方向**：半径以宿像素计（0.5× / 1× 两圈），共 16 次 `texelFetch`；天空邻域与天空中心都直接旁路。
3. **偏置随深度缩放**：`bias = z × (中心深度 × 0.05) + 0.005`，远处自动放宽，抑制深度量化误遮蔽。
4. **参数语义**：x = 强度、y = 半径、z = 偏置、w = 幂次；强度 0 时整段旁路，保证可作「开关」。
5. **描述符**：复用后处理集 binding 2（场景深度）与 set 0（场景 UBO），无需新增管线接口。
