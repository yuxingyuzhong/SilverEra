# 执行计划 · 第 51 轮（逐盏高光光泽度）

> 日期：2026-10-22　分支：main　类型：光照数据化（单方向）

## 一、目标
在逐盏高光缩放（第四十九轮）之外，为点光源 / 聚光灯增加**逐盏高光光泽度**：每盏灯可单独指定光泽度（0 = 跟随全局，1..1000 = 自身值），与 `Light_Data` / `Scene_Data` 同步提供。

## 三、实现方式
- 场景 UBO 尾部新增 `float point_shininess[4]`（std140 步长 16 字节 → 偏移 480 / 496 / 512 / 528），总长 544。
- 着色器：`shininess = point_shininess[index] > 0 ? 自身值 : 全局光泽度`；高光 `pow(ndoth, shininess) × atten × cone × 逐盏缩放`。
- 校验：`shininess == 0`（跟随全局）或 1..1000，其余整次拒绝。

## 四、验收口径
- Renderer Debug ＋ Release、Test Debug 三树零错误零新增警告；
- 新增用例通过（斜视相机下低光泽度明显亮于高光泽度；非法 0.5 整次拒绝）；全量回归零失败（排除四叉树两套件）；校验消息 0。
