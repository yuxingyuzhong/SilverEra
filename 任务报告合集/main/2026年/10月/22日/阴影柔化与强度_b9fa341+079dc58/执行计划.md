> 日期：2026-10-22　分支：main　类型：光照表现（阴影质量，单方向）

## 一、目标
在第五十二轮方向光阴影之上补齐**质量与可控性**：阴影比较改为可配的 **3×3 PCF**（软度 0 = 单点硬边，1 = 九点平均），并新增**阴影强度**（0 = 阴影完全无效、1 = 全遮蔽），两项均数据化并提供门面接口；默认「软度 0 / 强度 1」与第五十二轮逐字节一致。

## 三、实现方式
- **PCF**：`shadow_params.w < 0.5` 走单点采样（既有路径）；否则在阴影图 texel 空间做 3×3 邻域采样并平均（越界钳边）。软度取值 0..1，0 与 1 为两档（不做连续半径，保持实现简单可验证）。
- **强度**：`shadow_params` 之后新增 `shadow_strength`（offset 624），最终系数 `mix(1.0, factor, strength)`；默认 1 与既有行为一致。
- **UBO**：624 → 640（156 → 160 浮点）；`管线.cpp` range 同步；每帧单次整块写入。
- **校验**：软度 ∈ [0,1]、强度 ∈ [0,1]，越界 / 非数告警并保持原值；`Light_Data` / `Scene_Data` 同轮提供字段。

## 四、验收口径
- Renderer Debug ＋ Release、Test Debug 零错误；
- 新增用例通过（强度 0 时中心恢复基线 ±4；强度 1 时中心 <60；强度 0.5 时中心介于两者之间且 100 < 中心 < 基线 − 50）；默认值下第五十二轮阴影用例仍通过；
- 全量回归零失败（排除四叉树两套件）；校验消息 0。
