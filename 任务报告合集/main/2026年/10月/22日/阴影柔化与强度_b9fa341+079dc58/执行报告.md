## 二、实现细节
- **PCF**：`shadow_params.w < 0.5` 走单点 `texelFetch`（第五十二轮行为）；否则在纹素空间取 3×3 邻域（越界钳边）求平均，得到 0 / 1/9 … 1 的连续遮蔽系数。
- **强度**：`shadow_strength ∈ [0,1]`，最终系数 `mix(1, factor, strength)`；0 = 阴影完全无效、1 = 全遮蔽；默认 1 与第五十二轮逐字节一致。
- **UBO 布局（640 字节 = 160 浮点）**：120 逐盏光泽度 → 136 光源空间矩阵 → 152 阴影参数（x 启用 / y 偏置 / z 边长 / w 软度）→ 156 阴影强度；std140 结构体尾部圆整到 16 字节对齐（628 → 640）。
- **校验**：软度 / 强度均要求 `[0,1]`（取反比较使 NaN 判非法），越界告警并保持原值；`shadow_strength()` 未初始化返回 1、`shadow_softness()` 返回 0。
- **数据化优先**：门面接口、`Light_Data` / `Scene_Data` 字段、三组与扁平两入口同轮提供。
