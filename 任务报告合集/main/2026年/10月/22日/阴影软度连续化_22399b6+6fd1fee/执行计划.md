# 执行计划 · 第 56 轮（阴影软度连续化）

> 日期：2026-10-22　分支：main　类型：阴影质量（单方向）

## 一、目标
把阴影软度从「两档（单点 / 3×3）」改为**连续可调**：`softness ∈ [0,1]` 映射到采样半径 `r = round(1 + 2 × softness)` 纹素，按 `(2r+1)²` 邻域平均（r = 1 → 3×3、r = 2 → 5×5、r = 3 → 7×7）；`softness = 0` 仍走单点硬边，与第五十三轮逐字节一致。

| 文件（相对项目根） | 动作 |

| `Application/Renderer/assets/shaders/场景.frag` | 修改：`shadow_compare` 的邻域半径按软度推导，循环为 `-r..r` |
| `Application/Test/src/单元测试/渲染/渲染场景数据测试.cpp` | 修改：新增「阴影软度连续可调」1 例 |

## 三、实现方式
- `r = int(clamp(softness, 0, 1) × 2.0 + 1.0 + 0.5)`（四舍五入到 1..3）；`softness < 0.5` 仍走单点（保持既有两档语义中的硬边档），否则按 r 取邻域。
  - 为避免与既有「软度 0.5 即 3×3」的行为突变，映射改为：`softness <= 0.25 → r = 1`（3×3）、`0.25 < softness <= 0.75 → r = 2`（5×5）、`> 0.75 → r = 3`（7×7）；`softness = 0` 单独走单点。
- 片元计数上限 49 次（7×7），仅在软度 > 0.75 时触发；默认 0 不增加任何开销。
