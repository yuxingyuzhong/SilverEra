## 二、实现细节
- **映射**：`softness <= 0` 走单点（第五十二轮硬边，零额外采样）；`0 < softness ≤ 0.25` → 半径 1（3×3）；`≤ 0.75` → 半径 2（5×5）；`> 0.75` → 半径 3（7×7）。
- **开销**：最坏 49 次 `texelFetch`，仅在软度 > 0.75 时触发；默认软度 0 不增加任何采样。
- **接口不变**：沿用第五十三轮的 `shadow_softness_set` / `shadow_softness` 与 `shadow_params.w`，无需 UBO 或数据字段变化。
