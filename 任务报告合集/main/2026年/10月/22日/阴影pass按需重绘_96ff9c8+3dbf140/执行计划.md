# 执行计划 · 第 55 轮（阴影 pass 按需重绘）

> 日期：2026-10-22　分支：main　类型：性能优化（单方向）

## 一、目标
为阴影 pass 增加**按需重绘**：当「光源空间矩阵 ＋ 参与投影的几何（实例矩阵与项数）＋ 阴影图边长」相对上一帧完全未变时，跳过阴影 pass，直接复用上一帧阴影图；任一因素变化即重绘。静态场景下每帧省一次离屏 pass（含提交与 `frames_wait`）。

## 三、实现方式
- **签名**：FNV-1a 64 位，混入 `light_view_proj` 16 个 float 的位模式、`pending_instances` 全部 float 的位模式、`pending_items` 中投影项数、`shadow_size`。
- **跳过条件**：`shadow_pass_ready && shadow_signature == 当前签名`；跳过时不推进帧槽、不写实例缓冲、不调用 `render_to_target`。
- **失效**：分辨率切换（重建目标）、`shutdown` 时 `shadow_pass_ready = false`；关闭阴影不清（下次开启若几何未变可复用）。
- **观测**：`shadow_pass_count` 累计实际执行次数，便于测试与上层诊断。
