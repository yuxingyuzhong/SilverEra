# 执行计划 · 第 50 轮（方向光与补光的逐光高光缩放）

> 日期：2026-10-22　分支：main　类型：光照数据化（单方向）

## 一、目标
把第四十九轮的逐盏点 / 聚光高光缩放扩展到**方向光与补光**：主方向光与补光各有一个 0..100 的高光缩放（1 = 跟随全局、0 = 该光不产生高光），并与 `Light_Data` / `Scene_Data` 同步提供。

## 二、预修改 / 新增文件
| 文件（相对项目根） | 动作 |
| --- | --- |
| `Application/Renderer/src/render/Scene/场景数据.h` | `Light_Data` / `Scene_Data` 增 `directional_specular` / `fill_specular`（默认 1） |

| `Application/Renderer/src/render/Renderer/core/渲染器.cpp` | 两个 setter、UBO 写入（`camera_pos.w` / `fill_color.w`）、`scene_apply` 与扁平包装透传 |

## 三、实现方式
- 复用两处保留位：`camera_pos.w`（主方向光缩放）、`fill_color.w`（补光缩放）；场景 UBO 仍 480 字节。
- 校验：两处缩放均须落在 0..100；`directional_specular_set` 非法值整次忽略，`light_fill_set` 非法值整次拒绝。
- 着色器：主光 / 补光高光项各乘自身缩放（与全局高光强度相乘后再取 `max`）。

## 四、验收口径
- Renderer Debug ＋ Release、Test Debug 三树零错误零新增警告；
- 新增用例通过（两光各自缩放 0 与 1 亮度差 > 40；非法缩放不改变画面）；全量回归零失败（排除四叉树两套件）；校验消息 0。
