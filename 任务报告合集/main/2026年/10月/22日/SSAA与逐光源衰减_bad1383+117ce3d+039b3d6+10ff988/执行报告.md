## 三、关键实现细节
1. **SSAA 路径**：仅当「倍率 > 1、未设同帧后处理目标、未设离屏目标」时启用；场景 → N 倍目标 → 降采样（N×N 盒式平均）→ 解析目标 → 默认后处理 → 交换链。降采样与默认后处理共用全屏四边形与场景 UBO，采样集下标分别为 0 / 1。
2. **目标生命周期**：倍率或输出尺寸变化时先 `frames_wait` 再销毁旧目标；创建失败置 `ssaa_extent_failed`，本帧回落且不逐帧重试；`shutdown` 仅清句柄（目标随渲染目标模块销毁）。
3. **逐盏衰减**：模式存于聚光参数块 `point_spot_cone.z`（原保留位），UBO 维持 432 字节；着色器 0 = 跟随全局（全局 0/1 映射为 1/2），1 = 线性、2 = 平方反比；`>2` 在门面钳到 2。
4. **兼容性**：默认 `ssaa_factor = 1` 时不进入 SSAA 路径，既有 745 例全部保持通过。
