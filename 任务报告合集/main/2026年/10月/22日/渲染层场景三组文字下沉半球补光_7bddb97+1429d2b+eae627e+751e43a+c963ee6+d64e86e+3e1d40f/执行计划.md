## 三、实现方式
- 三组拆分：`Camera_Data`（位置 / 注视点 / 视场角 / 近远平面 / 正交 / 清屏色）、`Light_Data`（方向光、环境光、点 / 聚光灯组、高光、衰减模式、环境光颜色、半球、补光）、`Fog_Data`（颜色 / 密度 / 区间）；三入参版本承担原校验（相机非法整次拒绝、单条光源非法只跳过）。
- 文字下沉：`Text_Host` 为 7 个函数指针回调（管线确保 / 管线绑定 / 纹理绑定 / 网格创建 / 网格归还 / 绘制登记 / 尺寸查询），门面 `init` 用无捕获 lambda 注入、`this` 作上下文；`Text_Renderer` 持有管线句柄、颜色与（字体, 文本, 布局五项）→ 网格缓存。
- 半球环境光：场景 UBO 新增 `ambient_ground`（rgb = 地面色、w = 混合强度），着色器按 `normal.y * 0.5 + 0.5` 在两组颜色间插值，再按 w 与单一颜色混合。
- 补光：场景 UBO 新增 `fill_dir_intensity` / `fill_color` 两个 vec4，着色器累加漫反射、高光取最大。
