## 二、关键实现细节
1. **三组拆分**
   - 三入参版本承担全部校验：`fov ∈ (0, π)`、`near > 0`、`far > near`、正交模式 `ortho_height > 0`；任一非法即整次拒绝（相机与清屏色都不改）。
   - 点 / 聚光灯逐条追加，单条非法只跳过；数量超 4 只登记前 4 并告警。
   - 扁平版本逐字段装箱（相机 8 项、光照 20 余项、雾 4 项）后转发三入参版本，行为等价。
2. **文字下沉**
   - `Text_Host::user` = `Renderer*`；回调均为无捕获 lambda：`pipeline_ensure`（懒登记 `文字.vert.spv / 文字.frag.spv`，Alpha 档）、`pipeline_bind`（`pipeline_bind_set`）、`texture_bind`（`texture_bind_set`）、`mesh_create`（`mesh.mesh_create`）、`mesh_destroy`（网格模块有效时归还）、`mesh_draw`（门面 `mesh_draw`，文字色走推送常量）、`extent_get`（交换链尺寸）。
   - 缓存键仍为「字体句柄 ＋ 文本 ＋ 布局五项」；字体销毁与 `shutdown` 经 `font_meshes_destroy` / `shutdown` 归还网格。
3. **半球环境光**
   - UBO 尾段新增 `ambient_ground`：`rgb` = 地面色、`w` = 混合强度。
   - 着色器：`up_mix = clamp(normal.y * 0.5 + 0.5, 0, 1)`；`hemisphere = mix(ground, sky, up_mix)`；`ambient = mix(sky, hemisphere, w)`；`w = 0` 时与旧画面逐字节一致。
   - 门面 `ambient_ground_set(ground_color, hemisphere)`：颜色越界整次忽略；强度越界钳到 0 / 1、非数按 0。
4. **补光（第二盏方向光）**
   - UBO 尾段再加两个 vec4：`fill_dir_intensity`（xyz 方向、w 强度）、`fill_color`（rgb）。
   - 着色器：强度 > 0 时累加 `fill_color * intensity * ndotl`，高光 `max` 合并；与主方向光互不影响。
   - 门面 `light_fill_set(direction, color, intensity)`：方向退化、颜色越界、强度为负或非数即整次拒绝。
