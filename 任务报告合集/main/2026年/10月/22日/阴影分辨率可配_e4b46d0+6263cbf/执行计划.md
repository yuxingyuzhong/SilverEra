# 执行计划 · 第 54 轮（阴影分辨率可配）

> 日期：2026-10-22　分支：main　类型：性能优化 / 质量权衡（单方向）

## 一、目标
把阴影图边长从固定 1024 改为**可配 512 / 1024 / 2048**（默认 1024），使上层可在「阴影精度」与「阴影 pass 开销」之间取舍；切换时安全重建阴影目标并重新绑定到各帧槽，非法值整次忽略。

## 三、实现方式
- **取值**：仅接受 512 / 1024 / 2048；其余（含 0、负数、1000）告警并整次忽略。
- **切换流程**：`frame.frames_wait()` 等尽在途帧 → `render_target_destroy(shadow_target)` → `render_target_create(新边长)` → 取颜色视图 → 逐帧槽 `pipeline.shadow_bind(slot, sampler, view)`；任一步失败则保持旧目标可用并告警。
- **片元契约不变**：`shadow_params.z` 写实际边长，`shadow_factor` 的纹素映射与 PCF 邻域自动适配新尺寸。
- **数据化优先**：`Light_Data` / `Scene_Data` 同轮提供 `shadow_resolution`，`scene_apply` 两入口透传。
