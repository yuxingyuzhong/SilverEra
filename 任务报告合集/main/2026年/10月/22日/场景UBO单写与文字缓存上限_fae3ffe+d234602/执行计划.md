# 执行计划 · 第 48 轮（场景 UBO 单次写入 · 文字网格缓存上限）

> 日期：2026-10-22　分支：main　类型：性能优化（2 项）

## 一、目标
1. **场景 UBO 写入合并**：把每帧 7 次分段 `buffer_write`（64 / 64 / 128 / 128 / 32 / 16 / 16 / 16 / 16 字节）合并为 1 次 480 字节整块写入，减少每帧驱动调用次数。
2. **文字网格缓存 LRU 上限**：`Text_Renderer` 的「(字体, 文本, 布局五项) → 网格」缓存增加 64 条上限，超出淘汰最久未用项；被淘汰网格延到「退役帧 ＋ 在途帧数 < 当前帧」时归还，避免销毁本帧绘制项仍引用的网格。

## 三、实现方式
- UBO：按 std140 浮点偏移（0 矩阵、16 光照、32 点光源、64 聚光、96 雾、104 环境光、108 半球、112 补光方向、116 补光颜色）组装 `float[120]` 后单次写入 offset 0 / 480 字节。
- 文字缓存：`MESH_CACHE_MAX = 64`；插入前若已满，找 `last_used` 最小项移入 `retired` 并记录 `retired_tick`；`frame_begin(overlap)` 每帧推进 `frame_clock`，只在 `retired_tick + overlap < frame_clock` 时真正 `mesh_destroy`。
- `font_meshes_destroy` 仍立即归还（卸载属帧间调用）；`shutdown` 先清空缓存再统一归还。
