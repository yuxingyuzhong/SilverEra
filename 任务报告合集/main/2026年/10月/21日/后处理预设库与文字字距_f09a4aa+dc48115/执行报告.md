## 三、关键实现

### 3.1 描边的压暗口径
```glsl
float gx = (l20 + 2.0 * l21 + l22) - (l00 + 2.0 * l01 + l02);
float gy = (l02 + 2.0 * l12 + l22) - (l00 + 2.0 * l10 + l20);
float weight = clamp((abs(gx) + abs(gy)) * 2.0, 0.0, 1.0);
out_color = vec4(source.rgb * (1.0 - weight), 1.0);
```
- 邻域一律 `texelFetch` ＋ 偏移（不受采样器过滤状态影响），越界钳边；
- `weight` 为「压暗权重」：0 保留原色、1 纯黑；增益 2.0 使硬边（白 → 清屏色）被充分压暗。

### 3.2 色调映射的落点
- `aces(1.0) = 2.54 / 3.16 ≈ 0.804`，sRGB 附件编码后约 **232**（本机实测落在 200–246 区间）；
- 输入钳 `[0,1]`，输出恒在 `[0,1]`，不引入曝光 / gamma 参数。

### 3.3 字距与缩进的耦合关系
| 字段 | 计入行宽 | 影响换行判定 | 影响对齐 | 适用行 |
| --- | --- | --- | --- | --- |
| `tracking` | **是** | **是** | **是** | 全部行 |
| `first_line_indent` | 否 | 否 | 否（在算好的起始笔位上**再叠加**） | 仅第 0 行 |

注意：右对齐 + 缩进时首行会整体右移，可能超出 `max_width` —— 属**有意口径**（缩进是排版意图，不应被对齐抵消）。

### 3.4 缓存键
- 由 `(font, text, max_width, line_height, align)` 扩为加 `tracking` / `first_line_indent` 的 **7 元键**；
- 用例「字距增大使墨迹右移」在同一字体与文本下只改 `tracking`，即为该扩展的回归护栏。

## 七、重开发指引

1. **新增后处理预设**：只需在 `assets/shaders/` 加一个 `.frag`（顶点复用 `后处理.vert`），即可用 `pipeline_load` 登记并进链；**不要**为预设加门面 API。
2. **描边类效果**：邻域必须用 `texelFetch` ＋ 偏移（不用 `texture()`），否则会被采样器状态 / 插值干扰；越界一律钳边。
3. **字距 / 缩进**：`tracking` 计入行宽（影响换行与对齐），`first_line_indent` 只在算好起始笔位后叠加；两者都必须进缓存键。
4. **测试**：后处理预设用例以「同场景另一预设帧」为参考做相对断言，避免硬编码边界坐标；文字布局用例以 `text_measure` 自校准，避免硬编码像素宽度。
5. **推送**：本轮 Renderer 远程推送遇网络中断（`Recv failure: Connection was reset`），本地提交 `f09a4aa` 完好，网络恢复后 `git push origin main` 即可。
