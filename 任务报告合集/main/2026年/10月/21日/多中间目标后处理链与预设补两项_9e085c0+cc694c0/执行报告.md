## 三、关键实现

### 3.1 目标轮转（与旧 ping-pong 的等价性）
| 级序 i | 源（采样集下标） | 非末级宿 |
| --- | --- | --- |
| 0 | `targets[0]`（场景目标） | `targets[1]` |
| 1 | `targets[1]` | `targets[0]`（N = 2）/ `targets[2]`（N = 3） |
| 2 | `targets[2]`（N = 3） | `targets[0]`（N = 3） |

- N = 2 时 `i % 2` / `(i+1) % 2` 与原「偶级取场景目标、奇级取第二目标」**逐字等价**，故既有 12 例链用例无需改动即全绿；
- 末级恒以交换链为宿，非末级写完统一转回 `SHADER_READ_ONLY_OPTIMAL`（不变量不变）；
- 每次写入目标前会用「上一级已写完的同一目标」作源，故 WAR 屏障保持 `srcStage = FRAGMENT_SHADER / SHADER_READ`。

### 3.2 采样集下标必须与目标数一致
`post_item.sampler_set = post_set_get(slot, index % targets.size())` —— **不能**再用常量 `POST_SET_PER_SLOT`（4 是容量上限，不是实际目标数）。写集阶段按 `index 0..目标数-1` 一次写满全部帧槽；漏写某下标会导致该级采样到旧图像。

### 3.3 亮部提取的落点（本机实测）
- 白四边形：线性 1.0 → 权重 1 → 保留；
- 清屏色：线性亮度 ≈ 0.054 < 0.5（阈值 − 软膝）→ 权重 0 → **纯黑**；实测末端角落 0/0/0。

### 3.4 对比度 / 饱和度的端点方向（本机实测）
| 预设 | 角落（清屏色，参考帧） | 角落（应用后） | 中心（白四边形） |
| --- | --- | --- | --- |
| 对比度 | 89/63/63 | **0/0/0**（线性 0.05 → (0.05−0.5)×1.5+0.5 < 0 → 钳 0） | 255 保持饱和 |
| 饱和度 | 89/63/63（\|b−r\| = 26） | 98/62/62（\|b−r\| = 36） | 三通道差 ≤ 2 |

**注意**：本机回读通道顺序为「0 = 蓝、2 = 红」，故饱和度用例按 **通道差绝对值** 断言（首跑曾按 `[2]−[0]` 取有符号差得到 −26 而失败，已改为 `std::abs`）。

## 七、重开发指引

1. **新增多级效果**：先在门面 `render_target_present_chain_set` 一次给 N 个同尺寸目标，再 `post_chain_set` 给 N 级管线；级数 > 目标数时按 `i % N` 轮转复用目标。
2. **目标数硬上限 4**：改上限须同步 `POST_SET_PER_SLOT`（描述符池容量与 maxSets 均在此常量上推导），并复核 `PRESENT_TARGET_MAX`。
3. **采样集下标**：始终用 `级序 % 实际目标数`，**不要**用 `POST_SET_PER_SLOT`。
4. **泛光链**：`亮部提取 → 模糊`（可再接 `灰度` 验证第 3 级）即为本层「真泛光雏形」；真正「叠加回原画面」需双源采样（当前每级只有一个 `sampler2D`），属下一轮候选。
5. **测试口径**：涉及回读通道序的断言一律用**通道差绝对值**或「排序后比较」，不写死通道下标语义。
