## 三、关键实现与口径

- **UBO 布局（128 字节，扩后须四处一致）**：`mat4 view_proj` 0..63、`light_param0`（xyz = 方向/光位置，w = 环境光）64..79、`light_param1`（rgb = 颜色，w = 强度）80..95、`light_param2`（x = 模式 0/1、y = 半径、z = 高光强度、w = 光泽度）96..111、`camera_pos` 112..127。
- **模式语义**：`light_param0.xyz` 在方向光模式下是**传播方向**、点光源模式下是**光源世界位置**；门面按 `light_mode` 选择写入哪个字段（本轮实测：漏做该选择会让点光源读到旧方向，画面全黑）。
- **线性衰减**：`atten = clamp(1 − d / radius, 0, 1)`；`radius ≤ 0` 在门面即被拒绝。
- **高光**：`V = normalize(camera_pos − world_pos)`、`H = normalize(L + V)`；强度 0 = 关闭；光泽度钳制 ≥ 1（避免 `pow(0, 0)` 未定义）。
- **默认值不变**：方向光模式、半径 5、高光 0、光泽度 16 —— 既有画面逐通道不变。

**取舍（备查）**：① 每帧**仅一个光源**（方向光或点光源二选一，后设者生效），不支持多光源叠加；② 点光源为**线性**衰减（非物理平方反比）；③ 高光为 Blinn-Phong（非 GGX / PBR）；④ 高光与漫反射共用同一光源，不支持单独高光色；⑤ 场景 UBO 已达 128 字节，再加参数需另开 UBO 或改用推送常量 / 存储缓冲。

## 七、重开发指引

1. **点光源**：`renderer.light_point_set(pos, color, radius, intensity, ambient)`；设置后即切换为点光源模式。
2. **切回方向光**：再调用 `light_set(...)`（显式把 `light_mode` 置 0）。
3. **高光**：`renderer.specular_set(intensity, shininess)`；对两种光源均生效。
4. **排错**：点光源全黑先查 ① 门面是否把 `light_position` 写进 `light_param0`（按模式选择）；② 描述符 `range` 是否 128；③ 测试层 `.spv` 是否最新（改着色器需重配测试层）。
