## 三、关键实现与口径

- **应用顺序**：相机 → 清屏色 → 方向光 → 点光源组 → 聚光灯组 → 高光 → 衰减模式 → **距离雾**。
- **默认不变**：密度 0 → 片元不混合，既有 31 例场景用例与全量 735 例保持通过。
- **容错口径**：雾参数非法时 `fog_set` 整次忽略并告警，同次场景应用的其余字段照常生效。

## 七、重开发指引

1. **数据化开启雾**：填 `fog_color` / `fog_density` / `fog_start` / `fog_end`，`scene_apply` 一次提交。
2. **关闭雾**：`fog_density = 0`（或门面 `fog_clear`）。
3. **排错**：若画面未变，检查密度是否为 0 或区间是否非法（会被整次忽略并告警）。
