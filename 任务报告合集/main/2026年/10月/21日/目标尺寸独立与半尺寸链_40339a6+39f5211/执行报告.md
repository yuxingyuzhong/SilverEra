## 三、关键实现

### 3.1 尺寸映射口径
| 字段 | 含义 |
| --- | --- |
| `size_xy.x / .y` | **源**目标宽 / 高（第 i 级 = `targets[i % N]`） |
| `size_xy.z / .w` | **宿**宽 / 高（非末级 = `targets[(i+1) % N]`；末级 = 交换链） |

片元：`coord = clamp(ivec2(gl_FragCoord.xy * (源/宿)), 0, sourceSize−1)`。
1:1 时比例为 1，`gl_FragCoord` 的中心偏移被 `ivec2` 截断，与原 `texelFetch` 行为**逐字等价**（既有 18 例链用例未改断言即全绿）。

### 3.2 双源片元的第二源
`泛光叠加.frag` 的 binding 1（场景目标）尺寸可与 binding 0 不同，故**各自**用 `textureSize` 计算映射；场景端按 `sceneSize / 宿尺寸`。

### 3.3 校验放宽
- 帧模块：只要求 `targets[i].extent` 非零、交换链范围非零；
- 门面：同样只查非零，零尺寸时告警并本帧回落。

## 七、重开发指引

1. **新增分辨率无关片元**：复制任一后处理片元的推送块与 `source_scale` 两行即可（无需门面接口）。
2. **改推送布局**：同步三处——`管线布局.cpp` 的 `size`、帧模块 `stage_item.push_constant_offset`（80）、片元 `layout(offset = 80)`。
3. **目标尺寸**：门面 `render_target_create` 可直接给半尺寸；链内各级可不同，末级宿恒为交换链（其范围由视口决定）。
