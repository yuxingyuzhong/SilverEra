## 三、关键实现与口径

- **模式下发**：UMO 尺寸保持 **384**；`light_color` 的 `w` 分量此前保留（恒 0），本轮起承载模式值。两处写入点（`init` 初始化块、`frame_render` 每帧块）均已同步。
- **衰减公式**：
  - 线性（默认）：`atten = clamp(1 − d / radius, 0, 1)`，距离达到半径时归零；
  - 平方反比：`atten = 1 / (1 + (d / radius)²)`，半径作为尺度、不设硬截断。
  - 半径 ≤ 1e-6 时两种模式均视为无衰减（保持既有行为）。
- **作用范围**：模式对全部点光源与聚光灯生效（片元循环内统一读取），方向光不受影响。
- **默认零副作用**：默认 0 → 既有光照用例（含第三十四 / 三十五轮的聚光灯与新场景用例）全部保持通过。
- **非法值**：`mode = 2` 返回假且不改记录，画面逐字节不变（用例已断言）。

## 七、重开发指引

1. **切换模式**：`light_attenuation_set(0|1)`，下一帧生效；读取用 `light_attenuation_get()`。
2. **排错**：先确认两处 `light_block` 都写了模式；再确认测试层已重新配置（`.spv` 更新）。
3. **画面判据**：同距离下平方反比在中远距更亮、近距差异小；线性在半径处归零。
