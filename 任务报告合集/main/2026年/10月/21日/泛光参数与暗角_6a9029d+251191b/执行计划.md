## 二、实现方式

- 推送常量布局在既有 `0..95` 之后追加 `96..111`，四段契约（范围 112 / 门面写入长度 / 片元 offset / 帧模块 offset 80 ＋ 8 浮点）必须一致；
- `Frame_Render_Item` 增 `post_params[4]`，门面组装后处理项时逐级写入 `impl->bloom_param`；
- 帧模块链路径把原本的 4 浮点尺寸数组扩为 8 浮点（尺寸 ＋ 泛光参数），偏移仍为 80；
- 默认参数取 0.6 / 0.1 / 1.0，未调用 `bloom_param_set` 时画面与旧版逐字节一致；
- 非法参数（阈值 ≤ 0、软膝 < 0 或 ≥ 阈值、强度 ≤ 0 或不有限）整次忽略并告警。
