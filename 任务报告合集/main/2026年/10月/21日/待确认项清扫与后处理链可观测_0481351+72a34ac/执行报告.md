## 三、关键实现

### 3.1 跳过码点计数的三处递增点
```cpp
//字体加载.cpp · glyphs_ensure（补烘循环内）
if (stbtt_FindGlyphIndex(&info, static_cast<int>(codepoint)) == 0)
{
    logger.warn("字体:: 字体不含码点 {}，已跳过", codepoint);
    ++record.skipped_codepoints;
    record.glyphs[codepoint] = Font_Glyph{};
    continue;
}
```
- 另一处为「字形过宽（`glyph_width + 2 > atlas_width`）」、第三处为「图集高度空间不足」；
- 用 `stbtt_FindGlyphIndex` 而非「位图为空」判「不支持」——**空白字符（空格）返回非 0**，故不会被误计（这是选择该判据的唯一原因）。

### 3.2 计数口径（写入两处注释）
| 项 | 口径 |
| --- | --- |
| 统计对象 | **补烘阶段判定为无法呈现**的码点（字体不含 / 过宽 / 图集满） |
| 去重 | 按码点去重，**同一码点至多计一次**（补烘只做一次，后续绘制直接命中空度量） |
| 不计入 | UTF-8 解码失败的字节、空白字符、正常渲染的码点 |
| 生命周期 | 只增不减；`font_destroy` 经 `record = Font_Record{}` 归零；句柄失效读取返回 0 |

### 3.3 链状态读取
```cpp
uint32_t Renderer::post_chain_get(uint64_t* out, uint32_t capacity) const
{
    if (out == nullptr || impl == nullptr || !impl->initialized)
        return 0;
    uint32_t count = static_cast<uint32_t>(impl->post_chain.size());
    if (count > capacity)
        count = capacity;
    for (uint32_t index = 0; index < count; ++index)
        out[index] = impl->post_chain[index];
    return count;
}
```
- 返回「实际写入数」而非「链总级数」，调用方可据此判断是否被截断；
- **下标即当前级序**：`pipeline_unload` 摘除后级序前移，与设置时原始下标可能不同（已在头文件写明）。

## 七、重开发指引

1. **跳过码点计数**：在 `Font_Record` 增 `uint64_t skipped_codepoints = 0;`；在 `glyphs_ensure` 的「字体不含 / 过宽 / 图集满」三个 `continue` 前各加 `++record.skipped_codepoints;`；新增 `font_skipped_codepoints_get`（句柄无效返回 0）；门面加同名薄包装。
2. **不要**把「位图为空」当作「不支持」——空白字符同样无位图，会误计；必须用 `stbtt_FindGlyphIndex == 0`。
3. **链状态读取**：直接读门面 `Impl::post_chain`，`post_chain_get` 返回 `min(size, capacity)` 并逐级写出；不要返回链总级数。
4. **GPU 链路径用例**：链长 2 需同时设 `render_target_present_set` 与 `render_target_present_secondary_set`，且两个目标范围都须等于交换链；统计口径为每帧「1 场景项 ＋ N 后处理项」。
5. **测试运行**：`EngineTests.exe` 位于 `Application/Test/` 根（不在 `out/build` 下），工作目录必须是 `Application/Test`。
