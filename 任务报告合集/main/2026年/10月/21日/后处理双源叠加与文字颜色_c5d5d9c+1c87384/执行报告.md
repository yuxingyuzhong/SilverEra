## 三、关键实现

### 3.1 双源的数据流
| 位置 | binding 0 | binding 1 |
| --- | --- | --- |
| 场景 pass（`sampler_sets`） | 当前纹理 | 同视图（`texture_bind` 一并写入） |
| 后处理各级（`post_sets[i]`） | `targets[i % N]` | **恒为 `targets[0]`（场景目标）** |

- 第 i 级的源与第二源由门面在同一循环里写入全部帧槽（长命资源一次写满）；
- 因此「泛光叠加」必须放在**链末级**，且 **链长 ≤ 目标数**——否则前面的级会把 `targets[0]` 覆盖掉，binding 1 就不再是场景原画面。

### 3.2 文字颜色
- 推送块固定 80 字节：前 64 字节（矩阵）在文字路径上仅占位（矩阵仍由实例缓冲承载），后 16 字节为 `vec4` 颜色；
- `mesh_draw(handle, transform, color)` 只在 `color != nullptr` 时推送，故场景 / 后处理绘制项保持「不推送」的既有行为；
- 存储用 `std::deque`（元素引用稳定），绘制项持指针，`frame_render` 消费后与 `pending_items` 一并清空。

### 3.3 本机实测
| 断言 | 实测 |
| --- | --- |
| 泛光叠加：中心（222 灰） | 参考 ≈222 → 叠加后趋饱和（≥ 245） |
| 泛光叠加：角落（清屏色） | 与参考帧逐通道差 ≤ 4（暗部不变） |
| 文字颜色：默认白 | 最亮像素三通道差 ≤ 6 |
| 文字颜色：红色 | 最亮像素通道差 ≥ 100，最大通道 ≥ 200 |

## 七、重开发指引

1. **新增双源片元**：声明 `layout(set = 1, binding = 1) uniform sampler2D scene_image;` 即可，无需新增门面接口；放在链末级。
2. **改推送常量**：同步三处——`管线布局.cpp` 的范围大小、`文字.frag` 的 `offset`、`mesh_draw` 的写入长度。
3. **新增带颜色的绘制**：`mesh_draw(handle, transform, color)`；不要绕过 `pending_push_constants` 另建存储（指针生命周期）。
4. **描述符池**：凡增加 `sampler_set` 的描述符数量，必须同步 `pool_sizes[1].descriptorCount` 与 `maxSets`（当前 ×2 已覆盖两个 binding）。
