## 三、关键实现与口径

- **UBO 布局（std140）**：`mat4`（0..63）＋ `light_common`（64..79）＋ `light_dir`（80..95）＋ `light_color`（96..111）＋ `camera_pos`（112..127）＋ `point_pos_radius[4]`（128..191）＋ `point_color_intensity[4]`（192..255）＋ `point_spot_dir[4]`（256..319）＋ `point_spot_cone[4]`（320..383）。两个新数组**各自连续**，写入顺序必须是「4 个方向 ＋ 标志」再「4 组内外锥余弦」。
- **锥形公式**：`to_light` 为片元 → 光源，取反得光源 → 片元方向；`cos_angle = dot(-to_light, spot_dir)`；`cone = smoothstep(cos_outer, cos_inner, cos_angle)`。内角更小 → 余弦更大，故 `smoothstep` 的两个端点顺序为「外锥余弦在下、内锥余弦在上」。
- **衰减叠加顺序**：距离线性衰减 `atten` 与锥形 `cone` 相乘，再乘 `N·L` 与光色 × 强度；高光取各光源最大值，同样乘 `atten × cone`。
- **门面校验**：`inner_deg > 0 && inner_deg < outer_deg && outer_deg <= 90`（取反比较使 NaN 判非法）；方向长度平方须 > `1e-12`；半径 ∈ (0, 1e6]、强度 ∈ [0, 1e6]、环境光 ∈ [0,1]、位置 ∈ [-1e6, 1e6]、颜色 ∈ [0,1]；任一项非法或已满 4 盏 → 告警 + 返回假，既有光源保持不变。
- **默认零副作用**：`is_spot` 默认假、普通点光源入口强制清零，故所有既有光照用例画面逐字节不变（第三十三轮 723 例保持通过）。
- **`Scene_Data` 未扩展**：本轮聚光灯只走门面入口；场景数据化入口仍只承载点光源组（后续若需要，可在下一版次扩展 `Scene_Data`）。

## 七、重开发指引

1. **登记聚光灯**：先 `light_set` 关闭方向光（或保留方向光），再 `light_add_spot`；`direction` 是**光传播方向**（从光源指向被照区域），不是「指向光源」。
2. **调锥**：`inner_deg` 越小光斑越集中；`inner_deg` 必须严格小于 `outer_deg`，两者上限 90°。
3. **排错顺序**：① 确认 `scene_bind` 的 `range = 384`；② 确认两段写入的 offset 为 256 / 320 且数组不交错；③ 确认测试层已重新配置（`.spv` 更新）；④ 确认该槽 `is_spot` 未被后续普通点光源入口清零。
4. **画面判据**：锥内亮度应接近同位置普通点光源；锥外应为 0（只剩背景或环境光）。
