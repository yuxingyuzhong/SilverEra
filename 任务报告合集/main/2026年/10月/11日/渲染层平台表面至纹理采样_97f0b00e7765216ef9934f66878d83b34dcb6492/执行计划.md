## 一、总体口径

1. **一阶段一提交**：每 Phase 完成后立即双树构建验证（Debug `out/build/x64-Debug` 与 Release `out/build/x64-Release`），零错误零警告后再提交渲染层本地仓库；提交信息沿用该仓库既有风格（`渲染层<功能>：...`）。
2. **不改动下层**：只消费 `Engine/EngineCore/out/build/x64-<类型>/lib/EngineCore.lib` 与对应头快照，绝不编译下层源码。
3. **CMakeLists 尽量少改**：`src/` 与 `common/` 走 `GLOB_RECURSE CONFIGURE_DEPENDS` ＋ 目录级 `CMAKE_CONFIGURE_DEPENDS`，新增模块目录**无需**改构建脚本；仅 Phase 6（glslc 接线、`assets/shaders`）与 Phase 8（`external/glm` 私有包含根）必须改 `CMakeLists.txt`。
4. **公共面边界不动**（§4.1）：`PUBLIC` 仍只有「EngineCore 头快照根 ＋ 项目根」；Vulkan / SDL3 / VMA / glm 一律 `PRIVATE`。公共头只出现引擎语义类型，PIMPL 是硬要求。
5. **风格**：`Application/Renderer` 层用 **TAB** 缩进；注释中文、`//` 连续少于三行、三行及以上用 `/* */`、换行注释（不写行尾注释）；大括号换行；单语句 `if/for` 不加代码块；禁用异常、内存分配用 `new(std::nothrow)`；函数 / 变量小写下划线且**名词在前动词在后**（`swapchain_build`、`frame_count_get`）；无参函数声明写 `(void)`；自定义类型首字母大写（`Device_Context`、`Frame_Slot`）；文件名默认中文。
6. **错误处理**：本层对外接口一律 `bool` 返回 ＋ 日志；所有 Vulkan 调用经 `Renderer/core/结果检查.h` 的唯一检查出口 `vk_result_check()`；可接受码（`VK_SUBOPTIMAL_KHR` / `VK_ERROR_OUT_OF_DATE_KHR` / `VK_TIMEOUT`）走 `vk_result_acceptable()` 单列分流。

### Phase 4 —— 平台与表面（`Platform/`，约 5 文件）

新增：`src/render/Platform/{平台上下文.h, 局部命名空间使用.h, core/{平台上下文.cpp, 窗口创建.cpp, 事件泵.cpp, 表面创建.cpp}}`

- 职责（§3.2）：SDL3 生命周期、窗口、事件泵、`VkSurfaceKHR`。
- 依赖方向（§3.3）：`Platform → EngineCore` only；`Device → Platform`（实例扩展清单来自 SDL3）。
- 模块对外头 `engine::Platform_Context`（要点，实现时定稿）：`build(width,height,title,hidden)` / `destroy` / `valid` / `events_pump` / `close_requested` / `resized_consume` / `minimized_query` / `instance_extensions_get(std::vector<const char*>&)` / `surface_build(VkInstance)` / `window_size_get(uint32_t&,uint32_t&)`。
- 口径：`SDL_InitSubSystem(SDL_INIT_VIDEO)`（K18：库内不接管入口点；如 `SDL_Init` 要求先 `SDL_SetMainReady()`，在 Platform 初始化处统一调一次）；`SDL_CreateWindow(title, w, h, SDL_WINDOW_VULKAN [| SDL_WINDOW_HIDDEN])`；`SDL_Vulkan_GetInstanceExtensions`（K14：SDL3 **去掉窗口参数**）；`SDL_Vulkan_CreateSurface`（K15：SDL3 **保留 allocator 参数**）；事件枚举 `SDL_EVENT_QUIT` / `SDL_EVENT_WINDOW_RESIZED` / `SDL_EVENT_WINDOW_MINIMIZED`（K16）；`bool` 取代 `SDL_bool`（K17）。
- 事件泵口径（§5.2 ①）：轮询事件只**置标志**，不立刻重建；`SDL_EVENT_WINDOW_RESIZED` → 待重建；`SDL_EVENT_WINDOW_MINIMIZED` → 挂起。
- 验收判据（§8.3）：**隐藏窗口能创建表面并正常销毁**。

### Phase 5 —— 交换链与帧（`Swapchain/` ＋ `Frame/` ＋ 门面接通，约 10 文件）

新增：
- `src/render/Swapchain/{交换链.h, 局部命名空间使用.h, core/{交换链.cpp, 交换链查询.cpp, 交换链重建.cpp}}`
- `src/render/Frame/{帧上下文.h, 局部命名空间使用.h, core/{帧槽创建.cpp, 命令录制.cpp, 提交呈现.cpp, 延迟销毁.cpp}}`
- 改写 `src/render/Renderer/{渲染器.h, core/渲染器.cpp}` ＋ 新增 `core/{渲染器实现.h, 渲染器配置.h}`（§3.1）

关键口径（必须逐条对照，错一条就画不出或校验层报错）：
- 初始化顺序（§5.1）：`SDL 视频子系统 → 窗口 → 实例扩展 → Device::build → Surface → Memory::build → Swapchain::build → Frame::build`；任一步失败**逆序回退**，不留半初始化。
- 同步原语归属（§5.2 表，K10/K13）：图像可用信号量**每交换链图像**一个；呈现完成信号量与帧栅栏**每帧槽**一个。
- 每帧链路（§5.2）：泵事件 → 退出/挂起/待重建判定 → `vkWaitForFences(f.fence)` → `vkResetFences` → `vkAcquireNextImageKHR`（OUT_OF_DATE/SUBOPTIMAL → 置待重建并返回 true）→ `vkResetCommandPool` → 录制 → `vkQueueSubmit2` → `vkQueuePresentKHR` → `frame_index++`。
- 布局转换（K11/K12）：`UNDEFINED → COLOR_ATTACHMENT_OPTIMAL`（`srcStageMask = COLOR_ATTACHMENT_OUTPUT`、`srcAccessMask = 0`）；`COLOR_ATTACHMENT_OPTIMAL → PRESENT_SRC_KHR`（`dstStageMask = BOTTOM_OF_PIPE`、`dstAccessMask = 0`）。用**动态渲染** `vkCmdBeginRendering` / `vkCmdEndRendering`（核心 ≥ 1.3 或 `VK_KHR_dynamic_rendering`）。
- 交换链口径（§6.2/§6.3，K3~K7）：格式**必须查询后选择**（优先 `B8G8R8A8_SRGB` / `R8G8B8A8_SRGB`，其次 `_UNORM`）＋ 色彩空间 `SRGB_NONLINEAR_KHR`；呈现模式 `MAILBOX`（`vsync=false` 且支持）→ `FIFO` 兜底；图像数 `clamp(minImageCount+1, 下限, maxImageCount)`（`maxImageCount==0` 无上限）；`currentExtent == UINT32_MAX` 时用窗口客户区尺寸；`0×0` 时**挂起**不重建（K7）；重建每帧最多一次（K8，先合并标志）。
- 重建链路（§5.3）：`vkDeviceWaitIdle` → 销毁旧图像视图与交换链（**推入延迟销毁队列**，§6.4）→ 重查能力 → 重建交换链与视图 → 重建「每交换链图像」的 acquire 信号量（数量可能变化）→ 通知 Frame 标记「首帧须等待」。
- 关闭（§5.4，严格逆序）：`Frame::destroy` → `Swapchain::destroy` → `Memory::destroy` → `Device::destroy` → `Platform::destroy`；销毁命令池 / 交换链前必须 `vkDeviceWaitIdle`。
- 门面 API（§4.2）：`渲染器.h` 落定 `renderer_version()`、`Renderer_Config`、`class Renderer`（PIMPL：`class Impl; std::unique_ptr<Impl> impl;`）与 `init` / `shutdown` / `valid` / `frame_render` / `close_requested` / `frame_count` / `extent_width` / `extent_height`。
- 验收判据（§8.3）：**隐藏窗口下 `frame_render` 连续 60 帧不报错；`frame_count()` 与调用次数一致**。
