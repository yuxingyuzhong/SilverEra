## 四、实现要点

### 4.1 `core/结果检查.h`（T1）

- **单一实现点**：全部 `VkResult` 检查只经此头，避免「有的地方查、有的地方不查」（§4.4）。
- 形态：head-only，函数 `inline`；不引入 `.cpp`。
- 日志出口：复用 EngineCore 的 `Log`（`Log::error` 等已借 `std::source_location` 携带调用处，不自造日志、不自造定位）。
- 三个层次分开，不混：

| 函数 | 语义 |
| --- | --- |
| `vk_result_check(VkResult, const char* what)` | **硬错误**：非 `VK_SUCCESS` 即 `Log::error` 并返回 `false` |
| `vk_result_acceptable(VkResult)` | **可接受返回值**：`VK_SUBOPTIMAL_KHR` / `VK_ERROR_OUT_OF_DATE_KHR` / `VK_TIMEOUT`，不算失败、不记 error |
| `vk_result_success(VkResult)` | 纯粹的「是否 `VK_SUCCESS`」判定，用于不需要日志的场合 |

- 消息内容：`VkResult` 名字 ＋ 调用点描述（`what`），便于对着校验层输出定位。

### 4.2 `Device_Context` 生命周期（T2）

- 类型名 `Device_Context`（首字母大写）；方法名 `小写下划线`、动词后置：`build` / `destroy` / `valid` / `instance_get` / `physical_device_get` / `device_get` / `graphics_family_get` / `graphics_queue_get`。
- 不可拷贝、不可移动（持有 GPU 句柄）。
- 状态：`未构建 → 已构建`；`destroy()` **幂等**；析构兜底调用 `destroy()`。
- `build()` **失败即无痕**：任一步失败都把已建对象逆序销毁并返回 `false`，绝不留下「`valid()==false` 但实例还开着」的半初始化状态（§4.2 要点 2）。
- 所有权边界：`Device_Context` 拥有实例 / 调试信使 / 逻辑设备，**销毁职责与创建职责同属本模块**（§3.2）。

### 4.3 实例创建（T3）

- 入参：`const std::vector<const char*>& required_extensions`（Phase 4 由 Platform 填）、`bool enable_validation`。
- 校验层开关：`Renderer_Config::validation` 的口径是「Release 强制关闭」（K21）；本轮以入参传入 + 编译期 `NDEBUG` 兜底（Debug 树默认开、Release 树默认关）。
- 扩展清单：`required_extensions` ∪（校验层开启时 `VK_EXT_debug_utils`），**去重后拼接**。
- `VkApplicationInfo`：`apiVersion` 取 `vkEnumerateInstanceVersion` 的结果（不硬编码，避免驱动只支持 1.2 时报错）。

### 4.4 校验层与调试回调（T4）

- **先查后启**（K19）：`vkEnumerateInstanceLayerProperties` 里找 `VK_LAYER_KHRONOS_validation`；**找不到只 `Log::warn` 降级，不硬失败**。
- 调试信使：`vkCreateDebugUtilsMessengerEXT`（经 `vkGetInstanceProcAddr` 取函数指针，不直接依赖 loader 导出）。
- 回调分流（K20）：`ERROR` → `Log::error`，`WARNING` → `Log::warn`，`VERBOSE`/`INFO` → `Log::info`；回调内不抛异常、不调 Vulkan。

### 4.5 物理设备选择（T5）

- 枚举 `vkEnumeratePhysicalDevices`；为空 → 记 error 返回 false。
- 打分维度：设备类型（独显 > 集显 > 虚拟/CPU）、`VkPhysicalDeviceProperties::deviceName` 输出到日志便于诊断。
- 必要条件：**具备图形队列族**（`VK_QUEUE_GRAPHICS_BIT`）。
- 呈现队列族检测：Phase 2 无表面，**不做**表面支持查询；仅预留 `present_family_get()` 接口，Phase 4 接入后填充（与 §5.1 步骤 ⑤ 之后一致）。

### 4.6 逻辑设备创建（T6）

- 队列族去重后创建（Phase 2 只有图形族；Phase 4 起图形与呈现若同族只建一个、异族建两个，去重逻辑本轮就按「集合去重」写好）。
- `VkDeviceQueueCreateInfo`：优先级数组固定为 `1.0f`。
- 不启用任何设备扩展 / 特性（Phase 2 用不到；动态渲染等留 Phase 5~6 再加）。
