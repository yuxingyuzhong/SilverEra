### `Log_Rules` 关键实现

- 成员：`mutable std::mutex rule_mtx`；`std::optional<std::string> root_key`（**无值＝未设置**，**空串＝整个项目**）；`unordered_map<string,bool> file_rules / dir_rules / level_rules`。
- 接口：`root_set / root_clear / root_is_set / root_get / file_allowed_set / dir_allowed_set / level_allowed_set / clear / output_pass`。
- 路径键规范化：`key_normalize(raw)` 内部固定锚点 `"白银纪元/"`，统一委托 `detail::path_key_normalize(raw, anchor)`（复用 `src/tools/Detail/package/路径操作工具.h`）。
- 求值 `output_pass(key, level)`：① 根目录已设且非整个项目时，`key` 不以 `root_key` 为前缀即越界 → 返回 false；② 文件精确匹配 → 命中即以其为准；③ 目录最长前缀匹配 → 命中即以其为准；④ 级别匹配 → 命中即以其为准；⑤ 全未命中 → 默认允许。

### `Log_Config_Bridge` 关键实现

- 成员：`public: Event_Terminal event_terminal`；`private: int64_t acl_key`（构造时 `event_terminal.key().value()` 生成）；`std::vector<std::string> bound_paths`（记录本模块绑定的输出流路径，供卸载清除）。
- `attach()`：`bind(Port_ID::Evt_Receiver, ...)` 注册接收入口 → `check` 校验 → `event_terminal.attach("Log_Config_Bridge", needed_events, acl_key)`，`needed_events = { Event("","","Log","Load"), Event("","","Log","Unload") }`。
- `event_process(evt)`：`category=="Log" && tag=="Load"` → 依次 `root_apply / streams_apply / files_apply / dirs_apply / levels_apply`；`Log/Unload` → `config_unload()`。
- 各 apply 函数按字段可选处理，字段缺失即跳过；类型不符即报错驳回；条目字段无效即跳过并告警。
- `config_unload()`：`streams_revert()`（按 `bound_paths` 逐条 `stream_clear` 后清空记录）→ `logger.rule_clear()`（清三张表）→ `logger.root_clear()`。

### 绑定门禁 `Log::bind_gate()`

```
根目录已设置 → 放行
否则：
  stream_tree.console_available() 为真 → warn(...) 告警后回落控制台，返回 false
  否则 → error(...) 报错，返回 false
```

### 输出链路

`Log::output()` 合成 `"[TYPE]正文\n"` → `stream_tree.stream_output(file_name, type, msg, rules)`；`stream_output` 定位节点后先 `output_pass_check`（越界＋选择性输出），不通过即 `return` 截断，通过才写入该节点共享输出目标。

## 五、配置文件 JSON 草案（经事件中转站下发）

事件：分类 `Log`，标签 `Load` / `Unload`；`evt->config` 载荷如下（字段均可选）：

```json
{
  "root": "Engine/EngineCore/src",
  "streams": [
    { "path": "Engine/EngineCore/src/tools", "file": "log_tools.txt" }
  ],
  "files": { "Engine/EngineCore/src/core/foo.cpp": false },
  "dirs":  { "Engine/EngineCore/src/core/spatial/": false },
  "levels": { "DEBUG": false }
}
```

- `root`：日志根目录（空串＝整个项目；缺省＝不改根目录）。
- `streams`：逐条 `stream_bind(path, file)`，路径节点绑定文件输出流。
- `files` / `dirs`：白名单（true）／黑名单（false），目录作用于其后代调用处。
- `levels`：级别白/黑名单（键为 INFO/WARN/ERROR/DEBUG）。
- `Log/Unload`：无需字段，复位本模块绑定＋三张许可表＋根目录。
