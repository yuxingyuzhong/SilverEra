## 二、实现细节

### 2.1 逐物体反照率色调

1. `场景.frag` 在 `push_constant` 中以 `layout(offset = 64) vec4 tint` 读取色调（前 64 字节为占位矩阵，与既有 80 字节推送块同布局），最终 `albedo_color = texture(...) * tint`。
2. `mesh_draw` 非文字路径**恒推送** 80 字节块：显式 `color` 形参 ＞ 吸附式色调 ＞ 白色；文字路径保持原逻辑（仅给出颜色时推送），文字渲染不受影响。
3. `mesh_draw_instanced` 同样恒推送白色 / 吸附色调，避免「着色器读取从未设置的推送常量」的未定义取值。
4. 吸附式接口：`material_tint_set(r, g, b, a)`（各分量 [0, 1]，越界 / 非数整次拒绝）、`material_tint_clear`、`material_tint_active`、`material_tint_get`；只影响之后登记的绘制项。
5. `material_load` 对色调四分量做合法性校验，非法按「不覆盖」登记并告警；`material_bind_set` 同步吸附状态（句柄 0 / 无效亦清除）；`init` 复位为白色。

### 2.2 胶囊生成器

1. 环表自北向南：上半球 `rings+1` 环 → 下赤道（圆柱底端，法线纯径向）→ 下半球 `rings` 环；总高 = `height + 2 × radius`。
2. 顶点 `(2 × rings + 2) × (segments + 1)`（含接缝列），UV 的 v 按环序归一化，法线由环的径向 / 纵向系数组合。
3. 索引每格两三角形（与球体同序），保证背面剔除下可见；中段高为 0 时退化为球。
4. 门面 `mesh_capsule_load`：半径 > 0、中段高 ≥ 0（NaN 拒绝）、分段 3..128、纬圈 2..64，非法整次拒绝并置零句柄。
