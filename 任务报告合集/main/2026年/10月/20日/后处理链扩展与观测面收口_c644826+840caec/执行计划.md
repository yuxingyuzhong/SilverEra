## 二、方向 A · 后处理链扩展（≈80 min）

### A.1 现状
- 门面 `post_resources_ensure()`（`渲染器.cpp:35-90`）**硬编码**着色器对 `后处理.vert.spv` / `后处理.frag.spv`，惰性登记**单条**后处理管线（`impl->post_pipeline`），并创建全屏四边形网格。
- 帧模块 `render_to_target_present`（`提交呈现.cpp:288-423`）＋ `command_record_target_present`（`命令录制.cpp:455-695`）只支持**一级**后处理（目标 pass → 单条后处理 pass → 交换链）。
- 管线模块有 `post_sets`（`管线.cpp:141-155`，长度 = frame_overlap）供后处理 pass 采样离屏目标。

### A.2 设计决策（需用户知悉）
1. **「后处理管线按文件名热登记」不新增重复门面**：现有 `pipeline_load(handle, vert, frag, blend)` 已提供完全等价的「按文件名登记具名管线（共享同一管线布局 / 顶点输入）」能力，后处理 pass 的顶点输入（position + uv ＋ 实例 mat4）与之同构。故**沿用 `pipeline_load`**登记后处理管线，不再新增 `post_pipeline_load` 冗余接口（避免同一事实两处实现）。若用户要求独立语义接口，可后续补一层薄包装。
2. **N 级链用「成对 ping-pong 目标」实现**：链长 N ≥ 2 时，场景渲染进目标 A，第 i 级后处理读「源」（i 偶 → A，i 奇 → B）写「宿」（末级 → 交换链，否则 i 偶 → B，i 奇 → A）；恒满足「中间目标帧间保持 `SHADER_READ_ONLY_OPTIMAL`」既有不变量。链长 1 保持原单级语义（A → 交换链）。
3. **后处理描述符集扩为「每帧槽 2 个」**：源只可能是 A 或 B 两种视图，故按 `(帧槽, 奇偶)` 各分配一个 set1（`post_set_get(slot, index)` / `post_texture_bind(slot, sampler, view, index)`，index 默认 0 保持单级路径兼容）。

### A.3 新增 / 修改文件
**新增（Renderer 面向层）**
- `Application/Renderer/assets/shaders/反色.frag`：链式后处理一级 · 反色（`1 - rgb`，alpha 置 1）。
- `Application/Renderer/assets/shaders/亮度阈值.frag`：链式后处理二级 · 二值化（Rec.709 亮度 ≥ 0.5 纯白 / 否则纯黑）。
  （顶点复用既有 `后处理.vert`；`assets/shaders/*.frag` 由 CMake `GLOB CONFIGURE_DEPENDS` 自动纳编。）

**修改（Renderer）**
- `src/render/Pipeline/管线.h` / `core/管线.cpp`：`post_sets` 扩为 `frame_overlap × 2`；`post_set_get` / `post_texture_bind` 增 `index` 参数（默认 0）；描述符池 `maxSets` / `COMBINED_IMAGE_SAMPLER` 容量同步翻倍。
- `src/render/Frame/帧上下文.h` / `core/命令录制.cpp` / `core/提交呈现.cpp`：

  - 门面新增 `render_target_present_secondary_set(uint64_t handle)`（设置 ping-pong 第二目标 B；链长 ≥ 2 时必需，缺失则回落单级路径并告警）。

## 六、风险与注意（沿用既有坑）

1. **着色器拷贝是配置期操作**：新增 `.frag` 源会触发 Renderer 重配并编译新 `.spv`；若 Test 层 `shaders/` 未随之刷新，需手动拷贝 `Application/Renderer/out/build/x64-Debug/shaders/*.spv` 到 `Application/Test/shaders/`。
2. **ping-pong 布局不变量**：每个中间目标写完后必须转回 `SHADER_READ_ONLY_OPTIMAL`；末级呈现收尾须与既有交换链路径同口径（回读则 `TRANSFER_SRC → PRESENT_SRC`，否则 `COLOR_ATTACHMENT → PRESENT_SRC`）。
3. **`vkCmdResetQueryPool` 必须录在渲染通道之外**；GPU 时间戳终点写在 `vkEndCommandBuffer` 之前、收尾布局转换之后。
4. **断言禁用 `std::min` / `std::max`**（层内含链有同名宏），改用 `std::min_element` / 显式比较；绿通道恒为字节下标 1。
5. **销毁 / 更新在途引用资源的统一口径**：卸载走帧延迟队列，描述符写入与管线注销前 `frames_wait()`。
6. 构建命令须先设 `TMP` / `TEMP` 为纯 ASCII 目录 → 进 VS 开发人员环境 → 最后 `chcp 65001`；用例 cwd 必须为 `Application/Test`，并置 `$env:BYJY_RUN_L3='1'`。
7. 校验层消息在 `Application/Test/out/引擎运行日志.txt` 内统计（控制台不打印）。
