## 1. 方向 A：GPU 时间戳与 GPU 侧耗时统计（优先级最高）

### 1.1 目标
补上第 7 轮缺失的 **GPU 侧耗时**口径：帧模块以 `VkQueryPool`（timestamp）量测每帧 GPU 起止时刻，换算毫秒后并入帧统计；门面 `Frame_Stats` 扩 `gpu_frame_ms`。**设备不支持时优雅降级**（字段恒 0、不报错、不影响既有 642 例）。

### 1.2 实现方式

**(1) 能力探测（`Frame/core/帧槽创建.cpp` 的 `build`）**
- `vkGetPhysicalDeviceProperties` → `limits.timestampPeriod`（纳秒 / tick）与 `limits.timestampComputeAndGraphics`；
- `vkGetPhysicalDeviceQueueFamilyProperties` → 图形队列族的 `timestampValidBits`；
- 仅当 `timestampComputeAndGraphics == VK_TRUE && timestampPeriod > 0 && timestampValidBits > 0` 才置 `timestamp_supported = true`。

**(2) 查询池随帧槽创建 / 销毁（`帧上下文.h` ＋ `core/帧槽创建.cpp`）**
- `Frame_Slot` 增 `VkQueryPool timestamp_pool`（`queryCount = 2`：帧始 / 帧末）与 `bool timestamp_written`；
- `frame_slot_create`：能力支持时创建（失败则记日志并置不支持，**不使整体构建失败**）；`frame_slot_destroy` 归还。

**(3) 录制前后写入时间戳（`core/命令录制.cpp` ＋ `core/提交呈现.cpp`）**
- 录制起始处 `vkCmdResetQueryPool(cmd, pool, 0, 2)` 后 `vkCmdWriteTimestamp(cmd, TOP_OF_PIPE, pool, 0)`；
- 录制收尾（交换链路径：呈现前布局转换**之后**；离屏路径：收尾布局转换之后）`vkCmdWriteTimestamp(cmd, BOTTOM_OF_PIPE, pool, 1)`。

**(4) 帧后读回并换算（`core/提交呈现.cpp`）**
- 在每帧开头 `slot_fence_wait(slot)` 之后、录制之前，若该槽 `timestamp_written` 则 `vkGetQueryPoolResults(..., 2, 16 字节, VK_QUERY_RESULT_64_BIT | VK_QUERY_RESULT_WITH_AVAILABILITY_BIT)`；
- 两个查询均 available 时按 `(ts1 − ts0) * timestampPeriod / 1e6` 换算毫秒写入 `last_gpu_frame_ms`（`timestampValidBits < 64` 时先按 `(1<<bits)−1` 掩高位再相减）；
- 录完本帧后置 `slot.timestamp_written = true`。

**(5) 门面**
- `渲染器.h`：`Frame_Stats` 增 `double gpu_frame_ms`；新增 `bool gpu_timestamp_supported(void) const`；
- `渲染器.cpp`：`frame_stats_get` 填 `gpu_frame_ms`；`gpu_timestamp_supported` 转调帧模块 getter。

### 1.3 预修改 / 新增文件
- `Application/Renderer/src/render/Frame/帧上下文.h`、`core/帧槽创建.cpp`、`core/命令录制.cpp`、`core/提交呈现.cpp`
- `Application/Renderer/src/render/Renderer/渲染器.h`、`core/渲染器.cpp`
- Test 层新增 `Application/Test/src/单元测试/渲染/渲染GPU耗时测试.cpp`

### 1.4 风险
- 时间戳查询须按帧槽重置，否则会读到上一帧混淆值（用「帧内 `vkCmdResetQueryPool` ＋ 帧首读上一轮」的环形口径规避）；
- `timestampValidBits < 64` 须掩高位；
- 设备不支持时**必须**降级而非报错。

### 1.5 验收
用例断言「`gpu_timestamp_supported()` 为真时 `gpu_frame_ms > 0`」且帧计数与既有口径一致；不支持则跳过（不失败）。既有 642 例全通过、校验消息保持 0。
