## 三、关键实现

### 3.1 单级路径并入链实现（A1）
```cpp
bool Frame_Context::render_to_target_present(...)
{
    // 单级后处理（源 = 场景目标、宿 = 交换链，不使用第二目标）
    return render_chain_present(swapchain, target, Frame_Render_Target{}, items, item_count,
        &post_item, 1, clear_color, rebuild_needed_out, readback);
}
```
- 一致性保障：`render_chain_present` 中 `post_count == 1` 时奇偶映射退化为「源 = 场景目标、宿 = 交换链」，与收口前 `command_record_target_present` 的布局转换序列逐条相同（场景 `SHADER_READ_ONLY → COLOR_ATTACHMENT → SHADER_READ_ONLY`，交换链 `UNDEFINED → COLOR_ATTACHMENT → TRANSFER_SRC → PRESENT_SRC` 或直接 `→ PRESENT_SRC`）。
- 统计口径不变：薄封装走 `render_chain_present` 的逐级累计（单级即 1 项），与收口前 `total_draw_items += 1` 等价。

### 3.2 目标范围校验（A2）
- 帧模块：硬错误（`return false`），错误串含两侧尺寸，便于定位；
- 门面：分派前预检 → 告警 + `ready = false` → 本帧回落（离屏或交换链路径），**不使整帧失败**；
- 语义：后处理着色器 `texelFetch(gl_FragCoord.xy)` 按 1:1 取源，范围不等必然错位，故不做隐式缩放。

### 3.3 链级数上限（A4）
- 上限落**门面**（`post_chain_set`），帧模块 `render_chain_present` 本身不设上限（只接受 `post_count`）；
- 备选方案被否：在帧模块限制会与「帧模块只做机械录制、策略在门面」的既有分工冲突。
