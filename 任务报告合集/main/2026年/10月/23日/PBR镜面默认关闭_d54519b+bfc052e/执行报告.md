## 二、实现细节

1. **开关**：`pbr_params.x > 0.5` 启用；关闭时完全不进入 GGX 分支，既有 Blinn-Phong 路径逐字节不变。
2. **粗糙度**：`roughness = clamp(sqrt(2 / (max(shininess,1) + 2)) × pbr_roughness, 0.03, 1)`；逐盏光泽度优先，未设时取全局。
3. **GGX**：分布项 `a² / (π·((N·H)²(a²−1)+1)²)`（a = roughness²）、几何项 Smith-Schlick（k = (r+1)²/8）、菲涅尔 Schlick（F0 = 0.04）；
   返回含 `1/(4·N·L·N·V)` 的镜面值，按既有「取各光最大值」合并，阴影 / 衰减 / 锥形 / 逐盏高光缩放乘子保持。
4. **UBO**：960 → **976 字节**（244 浮点）：`pbr_params` 位于浮点 240（字节 960，std140 vec4 对齐，前 12 字节为结构体尾部填充）；
   初始化写入 `{0, 1, 0, 0}`（关闭 / 缩放 1），每帧按需写入缓存扩为 244 浮点。
5. **门面**：`pbr_roughness_set` 合法 0.05..4，越界 / 非数整次忽略并 `warn`；`pbr_enable_set` 未初始化静默返回。
