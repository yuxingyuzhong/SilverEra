# 执行计划 · 第 64 轮（PBR-lite：GGX 镜面，默认关闭）

> 日期：2026-10-23　分支：main　类型：光照质量（单方向）

## 一、目标

在既有 Blinn-Phong 高光之外提供 **PBR-lite 镜面**（GGX 法线分布 ＋ Smith-Schlick 几何 ＋ Schlick 菲涅尔，F0 = 0.04），
默认**关闭**（关闭时走原 Blinn-Phong 路径，画面逐字节不变）；粗糙度由逐盏光泽度换算，并可乘全局缩放。

## 三、实现方式

1. `pbr_params.x > 0.5` 启用；`.y` 为粗糙度缩放（默认 1，合法 0.05..4）。
2. 逐盏粗糙度 = `clamp(sqrt(2 / (shininess + 2)) × 缩放, 0.03, 1)`；未设逐盏光泽度时取全局光泽度。
3. GGX 镜面以与既有高光相同的「取各光最大值」方式合并；阴影 / 衰减 / 锥形 / 逐盏高光缩放乘子保持。
4. 关闭时完全不进入 PBR 分支 → 既有画面逐字节不变。

## 四、验收口径

- 灰纹理、法线与视线对齐、光泽度 64：关闭时中心饱和（≥240），开启后中心落到 120–230（能量重新分配）；
- 粗糙度缩放 4 时中心低于缩放 1（高光更散）；非法缩放整次忽略；
- 场景 / 效果套件全过；全量回归零失败（排除四叉树两套件）；渲染层 Debug ＋ Release 构建通过。
