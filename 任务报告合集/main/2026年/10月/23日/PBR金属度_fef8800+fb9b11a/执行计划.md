# 执行计划 · 第 65 轮（PBR 金属度与能量守恒）

> 日期：2026-10-23　分支：main　类型：光照质量（PBR-lite 续）

## 一、目标

在第六十四轮的 PBR-lite 基础上补 **金属度**：`pbr_params.z`（0..1）控制
菲涅尔 F0 从 0.04（介电）向反照率色插值，并把漫反射按 `1 − metallic` 缩（能量守恒）；
镜面由标量升级为 RGB（金属反射带反照率颜色）。默认金属度 0，既有画面逐字节不变。

**UBO / 管线范围不变**（`pbr_params` 的第 3 分量即金属度，块仍 976 字节）。

## 三、实现方式

1. `F0 = mix(vec3(0.04), 反照率, metallic)`；菲涅尔 Schlick 用该 F0（RGB）。
2. 漫反射权重：PBR 开启时 `1 − metallic`，关闭时 1（保证默认逐字节不变）。
3. 金属度合法 0..1，越界 / 非数整次忽略；默认 0。

## 四、验收口径

- 中灰纹理、关闭镜面（高光强度 0）：金属度 0 → 中心约 128；0.5 → 约 64；1 → 约 0（单调压暗）；
- 非法金属度（-0.1 / 1.5）整次忽略；PBR 关闭时金属度不生效（画面与默认一致）；
- 场景 / 效果套件全过；全量回归零失败（排除四叉树两套件）；渲染层 Debug ＋ Release 构建通过。
