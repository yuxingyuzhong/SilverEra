## 二、实现细节

1. **球体**：`(stacks+1) × (slices+1)` 顶点（末列与首列重合以保留 UV 接缝）；纬度 `phi = π·v`、经度 `2π·u`；
   法线 = 归一化位置；每格两三角形 `(a, a+1, b) / (a+1, b+1, b)`。
2. **圆柱**：侧面两圈（底 / 顶）＋ 上下端盖（中心顶点 ＋ 扇形）；侧法线径向、端盖法线 ±Y；
   顶面扇形逆序、底面顺序，保证与 `frontFace = COUNTER_CLOCKWISE` 一致。
3. **门面**：球体 `radius > 0`、`slices 3..128`、`stacks 2..64`；圆柱 `radius / height > 0`、`segments 3..128`；
   非法整次拒绝（句柄置 0、`warn`）。
4. **分段兜底**：生成器内部对 < 下限的分段数兜底（门面层已先拒绝，兜底仅防御）。
