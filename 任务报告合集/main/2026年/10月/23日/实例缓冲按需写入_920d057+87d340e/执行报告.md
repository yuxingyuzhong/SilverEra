## 二、实现细节

1. **缓存**：逐帧槽保存上次写入的实例矩阵（`instance_capacity × 16` 浮点）与实例数；帧槽数或容量变化时整块重建缓存。
2. **比较单元**：一个实例 = 16 浮点 = 64 字节（模型矩阵）；连续变化实例合并为一段，偏移 = 实例序号 × 64。
3. **超出上次缓存数的实例**：一律视为变化并写入；首次访问帧槽整块写入本帧全部实例。
4. **与阴影 pass 的交互**：阴影 pass 绕过缓存直接整块写该槽实例缓冲；写后立即把该槽标记为「缓存失效」，使主 pass 复用时完整重建，避免按旧缓存跳过必要更新（**正确性关键**）。
5. **计数**：`instance_upload_bytes` 累计主 pass 与阴影 pass 的实际写入字节，未初始化返回 0。
6. **画面不变**：写入内容与整块写逐字节一致。
