# 执行计划 · 第 63 轮（文字行距可调）

> 日期：2026-10-23　分支：main　类型：文字排版能力（单方向）

## 一、目标

为 `Text_Layout` 增加**行距倍数** `line_spacing`（默认 1.0，合法区间 (0, 8]），使多行文字的纵向步进可调；
默认值下既有画面逐字节不变。

## 二、预修改 / 新增文件

| 文件（相对项目根） | 动作 |
| --- | --- |
| `Application/Renderer/src/render/Text/文字布局数据.h` | 修改：新增 `float line_spacing = 1.0f` 及注释 |
| `Application/Renderer/src/render/Text/core/文字几何.cpp` | 修改：解析倍数（越界 / 非数按 1）；`line_top = 行号 × line_height × line_spacing` |
| `Application/Renderer/src/render/Text/core/文字渲染.cpp` | 修改：网格缓存键增 `line_spacing`（布局六项） |
| `Application/Test/src/单元测试/渲染/渲染文字布局测试.cpp` | 修改：新增「行距倍数拉伸行间步进」1 例 |

## 三、实现方式

1. 倍数仅影响行间纵向步进，不参与换行判定、行宽与对齐计算。
2. 合法区间 (0, 8]；0、负数、非数、> 8 一律按 1 处理（保证既有布局不变）。
3. 文字网格缓存按 `max_width / line_height / align / tracking / first_line_indent / line_spacing` 六项比对。

## 四、验收口径

- `line_spacing = 2` 时第二行墨迹整体下移一个行高（第二个行高区间无墨迹、第三个区间有墨迹）；
- 非法值（0 / -1）画面与默认布局逐字节一致；
- 文字布局套件全过；全量回归零失败（排除四叉树两套件）；渲染层 Debug ＋ Release 构建通过。
