## 一、背景与目标

当前 PBR-lite 的粗糙度 / 金属度是**全局**参数（场景 UBO `pbr_params.y` / `.z`），同一帧内所有物体只能共用一套 PBR 参数，无法表达「同一场景里金属球 ＋ 粗糙桌面」。

本轮把它推进为**逐物体材质**：

- 材质参数随实例属性下发（实例步长 64 → 80 字节），不改场景 UBO 布局、不改 `scene_apply` 语义；
- 未指定材质的绘制项（默认路径）与旧版**逐字节一致**；
- 首版同时提供门面方法与 `Material_Data` 字段（数据化优先）。

## 二、方案

### 2.1 实例属性扩展（64 → 80 字节）

| 偏移 | 内容 |
| --- | --- |
| 0..63 | 模型矩阵 4 列 vec4（既有，列主序） |
| 64..79 | 材质 `vec4`：x = 粗糙度缩放、y = 金属度、z = 覆盖标志（> 0.5 生效）、w = 保留 |

- 覆盖标志为 0 时，片元着色器回落全局 `pbr_params.y` / `.z`，故默认画面不变。
- 不采用推送常量：推送常量块已用满 112 字节（矩阵占位 64 ＋ 颜色 16 ＋ 后处理尺寸 16 ＋ 泛光 16），且每阶段仅允许一个块。
- 不采用场景 UBO：逐物体参数进 UBO 会让每帧上传量随物体数增长，且与「按需写入」的 16 字节单元口径冲突。

### 2.2 门面与数据面

- `Material_Data` 新增：`bool pbr_override = false;`、`float pbr_roughness = 1.0f;`、`float pbr_metallic = 0.0f;`
- 门面新增吸附式（sticky）状态，与 `texture_bind_set` / `pipeline_bind_set` 同构：
  - `bool material_pbr_set(float roughness, float metallic);`（合法域：粗糙度 (0.05, 4]、金属度 [0, 1]，越界 / 非数拒绝并返回假）
  - `void material_pbr_clear(void);`
  - `float material_pbr_roughness(void) const;` / `float material_pbr_metallic(void) const;` / `bool material_pbr_active(void) const;`（观测用）
- `material_load` 记录三个字段；`material_bind_set` 按记录设置 / 清除吸附状态（句柄 0 或无效 → 清除并回落默认）。

### 2.3 着色器

- `场景.vert`：新增 `layout(location = 7) in vec4 in_material;`，以 `flat` 形式传给片元。
- `场景.frag`：
  - `pbr_roughness(shininess)` 增加缩放入参：`roughness = sqrt(2/(shininess+2)) * scale`；
  - `pbr_f0(albedo)` 增加金属度入参；
  - `diffuse_weight` 用逐物体金属度；
  - 逐物体标志有效时覆盖全局，否则沿用 `pbr_params`。
