## 一、交付内容

1. **根因修复**：交换链深度图像此前只有 `DEPTH_STENCIL_ATTACHMENT` 用途，缺少 `SAMPLED` → 深度拷贝着色器采样得到 0，金字塔全 0 会导致全量误剔。单采样与 MSAA 深度图像均补 `VK_IMAGE_USAGE_SAMPLED_BIT`。
2. 两个生成着色器改用 `imageSize()` 取覆盖范围，移除推送常量块依赖，消除「推送 / 绑定错位导致低频静默截断」风险。
3. `实例压缩.comp` 增绑定 4（金字塔完整链，`sampler2D`）与 `Params_Block.hi_z = (宽, 高, 级数, 启用)`；视锥判定通过后按 255 轮 CPU 参考逐式执行遮挡测试（跨近平面 / 视图外判可见，覆盖纹素取最大远面深度，bias 0.002）。
4. `HiZ_Context` 增完整链视图与采样器访问器；每槽创建 / 销毁完整链视图。
5. 门面 `gpu_instance_compact_ex`：`hiz_enable` ＋ 资源 ＋ 最近生成槽有效时才写入 `hi_z.w = 1` 并绑定金字塔；首帧 / 关闭时 `hi_z.w = 0`，着色器跳过遮挡分支，行为与引入前一致。
6. `last_hiz_slot` 在场景退场生成成功后更新（剔除读取「上一帧」金字塔）。

## 三、关键设计口径

- **上一帧金字塔**：生成与剔除不在同一阶段（生成在场景退场、剔除在下一帧登记实例时），故绑定 `last_hiz_slot` 的金字塔；首帧 `history_valid = false` 自动跳过。
- **保守性**：与 255 轮 CPU 参考同口径（跨近平面 / 视图外不剔、覆盖纹素取最大、bias 0.002）；像素正确性依赖「深度金字塔存最远面」。
- **默认关闭**：`hi_z.w = 0` 时不访问金字塔绑定（着色器分支短路），未绑定时不会读取；画面与统计逐字节不变（GPU 驱动既有用例全部通过）。
- **深度采样用途**：交换链深度补 `SAMPLED` 是必要的资源前提；该标志只影响资源创建，不改变渲染路径。
