# 执行计划 · 第 265 轮　光源数据快照

- 日期：2026-10-31
- 目标：为阶段 D（Cluster 光照）打数据底座——把主方向光 / 补光 / 逐盏点光与聚光统一为
  Vulkan-free 的 `Light_Record`，并暴露门面快照接口，供 266 轮 SSBO 上传与后续分簇使用。

## 分段

### A 数据头（约 10 分钟）

1. 新建 `Scene/光源数据.h`：`Light_Type`、容量常量（1024 / 旧路径 8 / 每记录 80 字节）、
   `Light_Record`（pos_radius / color_intensity / direction / cone / shininess / type / flags / reserved）。
2. 提供 `light_effective_count(count, cluster_enabled)`：关闭 Cluster 截断到 8，开启按 1024 截断。

### B 门面与实现（约 15 分钟）

1. `渲染器.h` 引入光源数据头，新增 `light_record_count()` / `light_records_get(out, capacity)`。
2. `渲染器.cpp` 实现快照：索引 0 主方向光、索引 1 补光（强度 0 时 flags=0）、其后逐盏点 / 聚光；
   容量外只计数不写入。

### C 用例（约 10 分钟）

1. `渲染光照查询测试.cpp` 追加 `光源记录快照`：未初始化 0 / 初始 2 条 / 加点光聚光后 4 条 /
   字段与锥角余弦 / 容量截断 / 空指针 / `light_effective_count` 三态。

### D 文档（约 8 分钟）

报告、汇总、能力汇总、导航增量、两份历史、源码统计、工作站推送。
