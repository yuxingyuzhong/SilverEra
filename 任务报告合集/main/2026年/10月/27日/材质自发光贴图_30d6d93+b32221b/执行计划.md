# 执行计划 · 材质自发光贴图（第一百六十八轮）

- 代码版次：Renderer `12e2b63 → 30d6d93`；Test `8e2b5c3 → b32221b`
- 日期：2026-10-27
- 目标：给材质增加「自发光颜色贴图」，把此前只有标量强度的自发光做成可贴图化，且未配置贴图时画面逐字节不变。

## 一、现状与约束

1. 材质已有 `emissive`（标量强度，合法域 [0, 8]）经实例属性第 4 分量下发，片元侧表达式为
   `emissive_rgb = albedo_color.rgb * clamp(in_material.w, 0, 8)`。
2. 场景采样器集 set 1 已用满 binding 0..5（当前纹理 / 场景目标 / 深度 / 法线 / 粗糙度 / 天空盒），
   新增自发光贴图须占用 binding 6，并同步扩描述符布局与描述符池容量。
3. 默认白纹理采样恒为 (1,1,1)，故「乘贴图」写法在未配置贴图时与引入前逐字节一致。

## 三、分段执行

1. 数据结构与着色器先行（字段 + binding 6 + 自发光乘子），保证默认路径行为不变。
2. 描述符布局 / 池容量 / 绑定接口同步扩容；门面在登记、绑定、初始化三处写 binding 6。
3. 用例验证：白贴图与无贴图逐字节一致；纯红贴图使中心像素通道极差显著增大。
4. 三树构建 → 全量回归（含四叉树）→ 收口文档。

## 四、风险与口径

- 新 binding 未写入时采样属未定义行为，故本轮在**初始化阶段**即把默认白纹理写入 binding 3 / 4 / 6（顺带补齐此前只在材质路径写入的隐患）。
- 回读通道序不固定，颜色断言一律用「通道最大 − 最小」的极差，不绑定具体下标。
