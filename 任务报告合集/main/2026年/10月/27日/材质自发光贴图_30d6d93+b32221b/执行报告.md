## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| 数据面 | `Material_Data::emissive_texture`，0 = 无贴图；与既有 `emissive` 标量相乘，不改变标量语义 |
| 着色器 | 贴图乘子对 `in_material.w == 0` 无影响（表达式恒 0），故默认画面逐字节不变 |
| 绑定面 | 走 `material_bind_set` 的材质路径；单独 `texture_bind_set` 时回落白纹理，避免上一材质贴图残留 |
| 初始化 | 此前 binding 3 / 4 只在材质路径与 `texture_bind_set` 回落时写入；本轮在初始化即写 3 / 4 / 6，消除「首帧未写描述符」隐患 |
| 池容量 | 采样器类描述符由 6 倍改 7 倍，避免池耗尽导致描述符集分配失败 |
