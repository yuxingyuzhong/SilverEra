# 执行计划 · 材质深度写入开关（第一百七十三轮）

- 代码版次：Renderer `fd5a542 → b6e6f45`；Test `d2bfe06 → 3f21664`
- 日期：2026-10-27
- 目标：材质增加「深度写入」开关（默认写深度），透明叠加等场景可由上层显式关闭。

## 一、现状与约束

1. `pipeline_register` 已支持 `depth_write`，`Impl::pipeline_load_ex`（第 172 轮抽出）只需透传该参数。
2. 材质共享管线缓存键需扩一位：bit2 = 关闭深度写入；表长按 档位 × 8。
3. 关闭深度写入不改深度测试（仍 LESS），仅禁止写深度。

## 二、拟修改文件（相对项目根）

| 文件 | 计划改动 |
| --- | --- |
| `Application/Renderer/src/render/Pipeline/材质数据.h` | 新增 `bool depth_write = true;` |
| `Application/Renderer/src/render/Renderer/core/渲染器实现.h` | `Material_Record` 新增 `depth_write`；缓存注释改为八组合；`pipeline_load_ex` 增加 `depth_write = true` 参数 |
| `Application/Renderer/src/render/Renderer/core/渲染器.cpp` | `pipeline_load_ex` 透传 `depth_write`；`material_load` 记录该值、触发条件加入 `!depth_write`、组合键扩为 × 8 |
| `Application/Test/src/单元测试/Renderer/渲染材质测试.cpp` | 新增「关闭深度写入使后绘制者覆盖」 |

## 三、分段执行

1. 数据字段与内部管线登记参数透传。
2. 材质登记组合键扩位（bit2）。
3. 用例：近红面 + 远灰面同帧绘制；近面写深度时远面被遮挡，近面关闭深度写入时远面覆盖。
4. 三树构建 → 全量回归（含四叉树）→ 收口文档。

## 四、风险与口径

- 同帧内不同纹理无法共存（set1 为帧槽共享，后绑定覆盖前绑定），故用例改用「单一白纹理 + 逐物体色调」区分两层。
- 关闭深度写入只影响写使能，不改变深度测试与比较算子。
