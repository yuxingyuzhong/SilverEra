# 执行计划 · 材质贴图 UV 变换（第一百七十一轮）

- 代码版次：Renderer `29de7db → f865c0a`；Test `3c63e81 → 7537dda`
- 日期：2026-10-27
- 目标：给材质增加「贴图 UV 缩放与偏移」，全部材质贴图共用同一变换，默认恒等、画面逐字节不变。

## 一、现状与约束

1. 推送常量块已占 offset 0..95（占位矩阵 ＋ 色调 ＋ 贴图参数/描边参数），管线布局上限 112 字节，尚余 offset 96..111。
2. 门面推送数组为 `std::array<float, 24>`（96 字节），须扩为 28（112 字节），三处推送点同步。
3. 场景片元的全部材质采样（反照率 / 法线 / 粗糙度 / 自发光 / 遮蔽 / 金属度）统一改用变换后 UV；
   `material_roughness_scale` / `material_metallic` 改为按 UV 入参采样。
4. 默认 scale (1,1)、offset (0,0) → 乘 1 加 0，逐字节不变。

## 三、分段执行

1. 数据面与着色器（含两个按 UV 采样的函数改签名）。
2. 门面推送数组扩容与三处写入（文字路径保持恒等，天空盒路径填零）。
3. 用例验证：显式默认 UV 与默认逐字节一致；缩放 0.5 与偏移 0.25 均显著改变中心采样。
4. 三树构建 → 全量回归（含四叉树）→ 收口文档。

## 四、风险与口径

- 推送常量必须整块推送（着色器静态声明 offset 96 的 vec4），故天空盒 / 文字路径也推 112 字节（填零/恒等）。
- 采样位置断言依赖纹理过滤与 mip 选择；选择 4×4 纹理与 64×36 视口使 LOD = 0。
