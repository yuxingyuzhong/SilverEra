## 二、实现要点

| 位置 | 说明 |
| --- | --- |
| UV 变换 | 全部材质贴图共用：反照率、法线、粗糙度、自发光、遮蔽、金属度；文字不使用材质贴图，保持恒等 |
| 推送常量 | `offset 96` 的 vec4：xy = 缩放、zw = 偏移；三处推送点均写满 28 浮点（112 字节 = 管线布局上限） |
| 合法化 | 非有限缩放按 1、非有限偏移按 0 登记，避免把 NaN/Inf 送进着色器 |
| 兜底 | `material_bind_set(0)` 与无效句柄分支同时复位 UV，语义与色调 / 自发光一致 |
