## 二、分段执行

1. **相机**：`view_proj` 变换 8 角点；六个裁剪面（左 / 右 / 下 / 上 / 近 / 远）中任一面全部角点在外即判不可见，否则判可见（保守，不误剔）。
2. **网格**：校验句柄 / 数据 / 区间 / 每个索引 < 顶点数；写 `index_offset + 4 × first_index` 起、`4 × count` 字节。
3. **门面**：`camera_aabb_visible` 为纯查询；`mesh_update_indices` 先等尽在途帧。
4. **用例**：相机五个方位（内 / 背后 / 远外 / 横向外 / 远内）+ 空入参；网格退化索引（面积归零）→ 恢复 → 与基线一致 + 四类拒绝。

## 三、风险与口径

- `aabb_visible` 的「可见」为保守结果（盒体跨平面时仍判可见），与剔除口径一致。
- 索引更新不改变索引数量与顶点数据，故不影响包围盒与网格计数。
- 不涉及着色器 / 描述符 / UBO，既有画面路径不受影响。
