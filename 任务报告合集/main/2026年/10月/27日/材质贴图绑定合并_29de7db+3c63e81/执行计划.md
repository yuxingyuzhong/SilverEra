# 执行计划 · 材质贴图绑定合并（第一百七十轮）

- 代码版次：Renderer `9aef01c → 29de7db`；Test `7ffa298 → 3c63e81`
- 日期：2026-10-27
- 目标（优化轮）：把材质五张贴图（法线 / 粗糙度 / 自发光 / 遮蔽 / 金属度）的绑定从 3 次 `vkUpdateDescriptorSets`（2 + 1 + 2 项）合并为 1 次（5 项），并收敛绑定的对内接口。

## 一、现状

- 设置 `material_bind_set` 时，门面依次调用 `material_texture_bind`（binding 3/4）、`material_emissive_bind`（binding 6）、`material_ao_metallic_bind`（binding 7/8），每帧槽共 3 次描述符集更新。
- 初始化与 `texture_bind_set` 回落路径亦然。
- 纹理模块全部纹理共用同一 `shared_sampler`，故五张贴图可用同一采样器写入。
