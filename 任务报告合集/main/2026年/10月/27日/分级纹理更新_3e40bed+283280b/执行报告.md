## 二、实现要点

1. **级尺寸换算**：`level_width = (width >> level) > 0 ? width >> level : 1`，高度同理；越界判定与容量计算全部按该级尺寸。
2. **只重建下游**：`texture_update_region_level` 更新成功后，仅当 `level + 1 < mip_levels` 才调用 `image_generate_mips_from(record.image, level, level_width, level_height, record.mip_levels)`。
3. **增量语义**：上游级保持原样，因此更新后不一定满足严格降采样关系；这是「只刷新受影响区域」的预期代价，已在头文件注释中写明。
4. **读回口径**：`texture_readback_level` 输出该级整幅像素，容量不足 / 级号越界 / 句柄无效 / 未初始化均返回假且尺寸出参归 0。
5. **兼容**：原 `texture_update_region` / `texture_readback` 签名与行为不变，内部委托 level 0。
