# 执行计划 · 材质遮蔽与金属度贴图（第一百六十九轮）

- 目标：给材质补齐「环境光遮蔽贴图」与「金属度贴图」，两者默认白纹理，未配置时画面逐字节不变。

## 一、现状与约束

1. set 1 采样器 binding 0..6 已占用（当前纹理 / 场景目标 / 深度 / 法线 / 粗糙度 / 天空盒 / 自发光）。
2. 环境光遮蔽在片元中**只乘环境光基底与天空 IBL 漫反射**，不衰减方向光 / 点光源直接照度（物理语义正确）。
3. 金属度贴图乘到既有 `material_metallic()` 的输出上（该函数只在 PBR 开启时参与着色），结果钳回 0..1。
4. 默认白纹理（采样值 1）使两条路径均退化为原表达式，逐字节不变。
