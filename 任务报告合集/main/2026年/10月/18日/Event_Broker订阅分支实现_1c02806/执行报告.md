## 三、变更详情（可供重开发）

### 位置

`process()` 内 `if (evt->category == "Subscribed_Events")` 块中，
既有 `if (suscriber_key == config["acl_key"])` 之后的 `if (evt->tag == "Add")`
与 `else if (evt->tag == "Remove")` 两个分支（编辑后位于第 230–324 行）。

编辑前该两分支为空块（`{ }`）；入口处的既有校验（`config["object"]` 的
`detail::field_check<string>`、`mapping` 查表存在性、`config["acl_key"]` 的
`detail::field_check<string>`、密钥比对与违规驳回）**原样保留，未改动**。

### Add 分支（订阅事件添加）

1. `!detail::field_check<nlohmann::json>(config, "subscribed_events")` 或
   `!config["subscribed_events"].is_array()` → `logger.warn("Event_Broker::订阅事件清单缺失或非数组\n已略过该事件")` 并 `return`。
2. 逐元素：`!field_check<string>(项,"category") || !field_check<string>(项,"tag")` → `warn` 后 `continue`（不牵连其余项）。
3. 以 `Event_Identity identity(项["category"], 项["tag"])` 取 `acl_set[identity]`，
   以 `uint64_t` 下标线性查重，未授权则 `acl_keys.push_back(suscriber_key)`。
4. 全部处理完毕 `logger.info("事件中转站订阅事件已登记")`。

### Remove 分支（订阅事件移除）

1. 清单存在性与数组性校验同 Add（失败 `warn` + `return`）。
2. 逐元素标识完整性校验同 Add（失败 `warn` + `continue`）。
3. `acl_set.find(identity)`；未命中（该标识无任何订阅者）→ `warn` + `continue`。
4. 命中后在该标识的密钥列表中线性定位 `suscriber_key`，命中即 `erase` 并 `break`；未授权则不改动。
5. 全部处理完毕 `logger.info("事件中转站订阅事件已注销")`。

### 未改动（明确留白）

`process()` 其余部分一律未动，包括：`if (!evt)` 只告警未 `return`（既有疏漏）、
`Subscriber/Check`、`Subscriber/Detach` 分支，以及 `receive` / `attach` 全量。

## 四、新增行为契约

| 事件 | 前置条件（既有代码保证） | 行为 | 失败分支 |
| --- | --- | --- | --- |
| `Subscribed_Events/Add` | `object` 已登记于 `mapping`；`acl_key` 字段为字符串且与 `mapping[object]` 相等 | 逐项向 `acl_set[(category,tag)]` 追加本订阅者密钥（查重后追加） | 清单缺失/非数组 → `warn` + `return`；项标识不完整 → `warn` + `continue` |
| `Subscribed_Events/Remove` | 同上 | 逐项自 `acl_set[(category,tag)]` 移除本订阅者密钥 | 清单缺失/非数组 → `warn` + `return`；项标识不完整 → `warn` + `continue`；标识未登记 → `warn` + `continue` |

载荷样例（`config`）：

```json
{
  "object": "输入模块",
  "acl_key": "<密钥字符串>",
  "subscribed_events": [
    { "category": "输入", "tag": "按键" },
    { "category": "输入", "tag": "All" }
  ]
}
```

## 五、取舍

- `(分类, "All")` **允许**经 `Add` 登记，作为「整分类满订」入口，与 `receive` 满订广播口径一致。
- `Remove` 后若列表清空，**不删除** `acl_set` 的键（与既有 `Detach` 分支口径一致），
  以免改变 `receive` 中「事件标识未注册 → 丢弃」的判定语义。
- 字段校验复用项目既有 `detail::field_check<T>`：该工具头在本版已由 `事件中转器.h` 引入
  （`#include "Engine/EngineCore/src/tools/Detail/package/数据校验工具.h"`），本次**未新增任何 include**。
- 未使用 `std::find`，改以与 `Detach` 分支同构的 `uint64_t` 下标线性扫描，避免改动 `局部命名空间使用.h`。
