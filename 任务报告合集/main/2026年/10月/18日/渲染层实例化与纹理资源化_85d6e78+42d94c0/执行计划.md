## 二、P1 · 实例化绘制（优先，可独立交付）

### 2.1 目标
同一网格用 N 个模型矩阵**一次绘制调用**画出：`vkCmdDrawIndexed(indexCount, instanceCount = N)`；CPU 侧不再为每个实例重绑缓冲 / 重推常量。

### 2.2 预修改 / 新增文件（相对工作区）

| 文件 | 变更 |
| --- | --- |
| `Application/Renderer/assets/shaders/场景.vert` | 顶点阶段增**实例输入**：`binding 1`（步进 = 1 实例）承载 4 × `vec4`（列主序 mat4 的 4 列）：`in_instance_model[0..3]`，`location 3/4/5/6`；位置计算改为 `view_proj * instance_model * vec4(in_position, 1)`；**非实例路径保持可用**（实例数 = 1 时由实例缓冲承载同一个矩阵，推送常量仍保留兼容不删） |

### 2.3 验收用例（复用像素回读范式）
| 用例 | 断言 |
| --- | --- |
| `未初始化实例化绘制失败` | 未 `init` 调 `mesh_draw_instanced` → 假 |
| `实例数为零或句柄无效被拒` | `count == 0` / 无效句柄 → 假，且帧仍正常推进 |
| `N 个实例各自可见` | 同一小四边形以 3 个平移矩阵实例化 → 回读中**三处位置均出现纹理色**，三处之间的空白仍为清屏色 |
| `实例数为 1 与逐次绘制等价` | 同一变换分别走 `mesh_draw` 与 `mesh_draw_instanced(count = 1)` → 两次回读中心像素一致（容差内） |

## 六、风险与申报

1. **着色器改动需重编 `.spv`**（P1）：构建管线已自动处理，但需确认 `shaders` 目录产物同步（Test 层由 CMake 从渲染层构建树拷贝）。
2. **实例路径与非实例路径共存**：管线顶点输入一旦声明实例步进绑定，**必须**给该 binding 绑有效缓冲（否则校验层报错）。故设计上「实例数 = 1」也走实例缓冲（用单位/给定矩阵填充），而非「不绑」；报告中须写明该不变量。
3. **外部库引入**：stb 为单头库，需避免多编译单元重复定义 `STB_IMAGE_IMPLEMENTATION`；并遵守《外部库引入约束》（库内拷贝、相对路径、不投影）。
4. **mip 生成的布局转换**（P3）：`vkCmdBlitImage` 要求源/目标布局正确，且使用 `TRANSFER` 队列能力；须复用既有「上传命令池 + 栅栏」路径（第 2 轮已做的上传池复用正好可复用）。
5. **外部问题汇总**：本轮不预期新增外部问题；仍按既有口径维护工作站根 `渲染层外部问题汇总.md` 与 `渲染层下轮方向.md`。
