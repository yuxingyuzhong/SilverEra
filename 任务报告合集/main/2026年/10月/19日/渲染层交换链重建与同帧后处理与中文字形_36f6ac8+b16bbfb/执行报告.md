## 二、关键实现要点（重开发所需）

1. **无停顿交换链重建**：`rebuild` 不再 `vkDeviceWaitIdle`。旧交换链与附属资源经 `swapchain_resources_extract` **整体移出**到 `Swapchain_Old_Resources`（同时复位 `format / extent / color_transfer_src / depth_initialized`，其中 `depth_initialized` 必须复位，否则新深度图像会漏掉首帧前布局转换）；以旧链作 `oldSwapchain` 建新链；**失败时** `swapchain_resources_destroy()`（清半成品）＋ `restore()` ＋ 恢复五项派生状态，保证旧链仍可用。
2. **延迟销毁延迟量**：门面 `swapchain_rebuild_deferred` 压入 `Deferred_Entry{ resources = old }`，延迟 = `frame.in_flight_count_get() + 1`（= 在途帧数 + 1）。释放判据在 `deferred_flush`（每次 render 末尾），故第 `overlap+1` 帧后释放；此时旧图像所用帧槽已被 `slot_fence_wait` 等待过，GPU 工作已完成。
3. **关闭期必须强制释放**：`deferred_flush` 只按帧号释放，关闭时残留条目会泄漏（**曾实测触发 VMA `Unfreed dedicated allocations found!` 断言**）。故 `Frame_Context::destroy` 在 `vkDeviceWaitIdle` 后、内存模块销毁前调用 `deferred_release_all`。
4. **同帧多 pass 的描述符集前提**：场景 pass 用 `sampler_set_get(slot)` 采样场景纹理，后处理 pass 用 `post_set_get(slot)` 采样离屏目标 —— 二者**同布局但独立分配**，否则同一集无法在一次命令缓冲内承载两种绑定。后处理项 `descriptor_set_count = 2`（set0 = 场景 UBO，后处理着色器不引用但布局要求绑定）。
5. **后处理取像素口径**：片元用 `texelFetch(source, clamp(ivec2(gl_FragCoord.xy), 0, size-1), 0)`，与顶点朝向 / uv 无关；**要求目标范围与交换链范围一致**（1:1）。
6. **后处理顶点属性告警**：共享管线布局的顶点输入恒定声明实例矩阵（location 3..6），故 `后处理.vert` 必须真正声明并**应用**（乘单位矩阵）这些属性，否则触发 `VK_...Vertex attribute at location N not consumed` 校验告警。
7. **惰性字形补烘**：`Font_Record` 保留字体文件字节（每次补烘重新 `stbtt_InitFont`）与完整图集像素；`glyphs_ensure` 行式打包追加（越界换行、图集空间不足则跳过并记日志），确有像素写入时**重建图集纹理**并把旧句柄移入 `retired_atlas_textures`（**不可立即销毁** —— 可能仍被在途帧描述符集引用），统一在 `font_destroy` 归还。
8. **图集尺寸一经确定不再变化**（加载时即留一倍余量、下限 256），故已烘焙字形 uv 恒稳定 —— 这是「文字网格缓存」跨补烘仍正确的前提。
9. **mip 布局缺陷根因**：原实现每轮把「源级」转入 TRANSFER_SRC 后只恢复「目标级」，故 `0 .. mip_levels-2` 级遗留 TRANSFER_SRC；末级仅作目标级本已可读，不得纳入恢复屏障。
