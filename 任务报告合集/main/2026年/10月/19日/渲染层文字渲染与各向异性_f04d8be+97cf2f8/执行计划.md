## 二、方向 A · 文字渲染

### A.1 目标
渲染层首次具备**文字绘制能力**：以 `stb_truetype` 从 TTF 光栅化字形，打包为**字形图集**（RGBA8，白 RGB ＋ 覆盖率 A），经**专用文字管线**（复用第 4 轮多管线工厂，Alpha 混合档）把字符串以像素坐标画到当前渲染目标。

### A.2 设计要点
1. **管线复用既有布局**：文字管线与场景管线**共享同一管线布局与描述符集布局**（第 4 轮不变量）。文字顶点着色器只做 `gl_Position = model * vec4(in_position, 1)`——`model` 由**实例缓冲**承载（即「像素坐标 → NDC」的仿射矩阵，含文本位置偏移与 Y 轴翻转），不再经 `scene.view_proj`（set0 不参与）；片元着色器采样 set1 图集纹理。
2. **几何为像素空间**：Mesh 顶点 `position` = 字形在「文本原点（左上）」像素坐标系中的矩形角点，`uv` = 图集 uv；顶点格式与既有 `Vertex`（position vec3 ＋ uv vec2）**完全一致**，故复用网格模块与实例路径。
3. **门面 `text_draw` 是既有 API 的薄封装**：登记/复用文字管线（Alpha 档）→ `pipeline_bind_set` → `texture_bind_set(图集纹理)` → 按 `(字体句柄, 文本)` 缓存网格 → `mesh_draw(网格, 像素→NDC 矩阵)`。**不新增绘制链路**。
4. **字形图集走既有纹理模块**（`texture_create_from_memory` RGBA8），故 `text_draw` 采样即复用既有 set1 通路。
5. **懒登记文字管线**：首次 `text_draw` 时才加载 `文字.vert.spv` / `文字.frag.spv` 并登记（避免 `init` 增加着色器依赖，保持既有着色器校验用例口径不变）。
6. **编码**：字符串按 UTF-8 解码；图集仅含 ASCII 32–126，超出码点跳过（在报告中写明）。

## 四、方向 C · 交换链重建延迟销毁启用

### C.1 目标
交换链重建不再 `vkDeviceWaitIdle`（整帧停顿），改为把**旧交换链 / 旧图像视图 / 旧信号量**按帧号压入帧模块既有的延迟销毁队列，在「在途帧均已越过重建点」后再释放。

### C.2 设计要点
1. 帧模块 `Deferred_Entry` 已具备 `swapchain / image_views / semaphores / release_frame` 字段与 `deferred_push` / `deferred_flush` 实现（**在场未启用**）；本轮把它**开放**给交换链模块使用。
2. 交换链 `rebuild`：先按新尺寸把新交换链建好（`swapchain_create` 使用 `oldSwapchain` 或等新链就绪后再交旧链），把旧链 / 旧视图 / 旧信号量**移交**延迟队列，**不再**在 `swapchain_resources_destroy` 中立即销毁。
3. **释放时机**：`release_frame = 当前帧计数 + 在途帧数 + 1`；`deferred_flush` 在每帧推进后调用（既有路径）。
4. **构建期失败路径仍立即销毁**（首次 build 失败时队列尚未建立），保持既有收敛语义。

## 六、风险与申报

1. **方向 A 的库替代**：见第零节（stb_truetype 替代 freetype），须在《执行报告》与项目导航中显式登记。
2. **字形图集采样边界**：共享采样器默认 `Repeat` 寻址，图集边缘可能渗色；本轮在**字形间留 1px padding** 规避，若仍有渗色则用 `Clamp_To_Edge` 状态绘制文字（在报告中写明）。
3. **文字管线与场景管线共享布局**：文字顶点着色器不使用 set0，但门面仍绑定 set0 ＋ set1 两组描述符集（与既有 `descriptor_set_count = 2` 一致），不得让文字项绑不同数量。
4. **方向 C 时序敏感**：延迟销毁与在途帧错配会崩溃或花屏；须以**校验层全开**实跑并如实记录，任何不稳定结论都要写明。
5. **方向 B 能力依赖**：`samplerAnisotropy` 若不支持须优雅降级（只告警，不改绘制行为）。
6. **EngineCore 在途修复**：按用户指示**不提交**；导航与报告中继续按「EngineCore 哈希仍为 `1c02806`（工作区含用户未提交修复）」口径记录。
