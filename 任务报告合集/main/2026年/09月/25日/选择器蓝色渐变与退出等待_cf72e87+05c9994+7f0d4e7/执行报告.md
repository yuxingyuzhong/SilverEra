## 四、实施过程与关键决策

1. **基线**：改前 279 用例 / 20 套件、24 例 DISABLED。
2. **渐变方案选型**：没有用 ImGui 的 `ImGuiCol_WindowBg` 单色，而是走背景绘制列表 + `AddRectFilledMultiColor`（ImGui 没有原生多段渐变，用两段矩形拼接实现三段色）。代价是必须把窗口底色 alpha 归零。
3. **等待逻辑的边界**：把判断条件写成 `(命令行带过滤 && !显式选择器) || 选择模式 == "off"`，与主程序既有的"跳过选择阶段"条件保持一致——两处口径如果分叉，就会出现"弹了窗却不停"或"没弹窗却停住"的错配。
4. **提交拆分**：按「配色 / 行为 / 用例跟进」三笔，便于单独回退；提交信息用 `git commit -F <UTF-8 文件>`，路径用 `git add --pathspec-from-file=<UTF-8 文件>`（cmd 直接传中文路径会被吞）。
5. **不改构建**：本次没动 `CMakeLists.txt`，新增的两个源码文件由既有 `file(GLOB_RECURSE ...)` 收集规则自动纳入。
