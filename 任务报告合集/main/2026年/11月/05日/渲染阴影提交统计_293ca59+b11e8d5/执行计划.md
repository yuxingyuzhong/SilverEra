# 执行计划 · 第 665 轮（深研方向八 C2 基线：阴影提交计数）

> 目标：把「阴影重绘实际提交的命令缓冲次数」数据化，为 C2（单次提交合并）提供可断言的基线。
> 口径：只增诊断字段，不改提交路径；默认画面与 662 逐字节一致。

## 段 A · 渲染核心

| 项 | 内容 |
| --- | --- |
| `Frame_Stats` | 新增 `shadow_submits`（最近一次阴影重绘的提交次数） |
| `Impl` | `last_shadow_submits`，重绘段入口清零 |
| 计数点 | 方向光每片 `render_to_target` 成功后 ＋1；聚光每瓦片成功后 ＋1（现口径 = 片数） |

## 段 B · 用例

在 `渲染阴影诊断测试.cpp` 追加 1 例：单级 → `shadow_submits == 1`；双级 → `== 2`；两档均与 `shadow_passes` 相等。
