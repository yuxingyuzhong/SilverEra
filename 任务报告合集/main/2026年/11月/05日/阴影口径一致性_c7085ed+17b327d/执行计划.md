# 执行计划 · 第 662 轮（深研方向八 D2 阴影口径一致性）

> 目标：为 D2「Blinn / PBR / toon 三套模型共用同一阴影因子与偏置口径」建立回归套件，锁定三模型阴影边界逐像素一致。
> 本轮为用例轮（渲染核心零改动）；C 阶段（提交合并 / 聚光 atlas）风险高，顺延至下一窗口。

## 段 A · 用例设计

| 用例 | 口径 |
| --- | --- |
| 三模型阴影边界一致 | 同一相机 / 几何（全屏接收面 ＋ z = -9 遮挡面），分别以 Blinn / PBR / toon 渲染；以各自「无阴影帧」中心亮度的一半为阈值提取遮蔽掩码，三份掩码逐像素一致 |
| 阴影强度同比例 | `shadow_strength = 0.5` 时，三模型中心亮度与各自无阴影亮度的比值均约 0.5（±0.03） |
| 关闭阴影无遮蔽 | `shadow_enable_set(false)` 时三模型掩码均为空（阴影因子恒 1） |
