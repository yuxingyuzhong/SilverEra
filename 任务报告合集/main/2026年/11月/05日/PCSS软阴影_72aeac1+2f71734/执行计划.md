# 执行计划 · 第 657 轮（深研方向八 B2：PCSS 软阴影）

> 轮次：第 657 轮（2026-11-05）
> 目标：PCSS（blocker search ＋ 可变半径 PCF），默认关闭、关闭逐字节不变
> 依据：`深研预研_PCSS软阴影.md`（第 650 轮）；实施中发现无需 UBO 迁移 —— `toon_specular_params` 的 y/z/w 空闲

## 一、实现

1. **着色器**（`assets/shaders/场景.frag`）
   - 抽出 `shadow_depth_read`（比较与阻塞物搜索共用）；
   - 16 点 Vogel 盘 `PCSS_DISK`；
   - `shadow_sample_core` 在硬边 / 软度分支之前插入 PCSS 分支：阻塞物搜索（16 点、半径 = 搜索尺度）→
     半影 = `clamp((片元深度 − 平均遮挡深度) × 搜索尺度, 1, 上限)` → 可变半径 PCF（16 点）；
   - 参数复用 `toon_specular_params.y/z/w`（启用 / 搜索尺度 / 半径上限），**不动 UBO 布局**。
2. **数据**：`Light_Data.shadow_pcss / shadow_pcss_search / shadow_pcss_max`（默认 0 / 24 / 8）＋ `Scene_Data` 透传。
3. **门面**：`shadow_pcss_set(enabled, search, max_radius)`（search 钳 1..32、max 钳 1..16，非有限值整次忽略；不重建阴影图）。
4. **诊断**：`Frame_Stats.shadow_pcss`。
5. **着色器参数上传**：`scene_block[293..295]`（每帧随场景 UBO 差异上传）。

## 二、验收

| 项 | 口径 |
| --- | --- |
| 关闭 | 默认与显式关闭两帧逐字节一致；旧渲染套件全过 |
| 开启 | 同场景硬 / 软两帧差异字节 > 0（半影软化生效） |
| 门面 | 越界参数被钳制且可开启；关闭后诊断归 0 |
