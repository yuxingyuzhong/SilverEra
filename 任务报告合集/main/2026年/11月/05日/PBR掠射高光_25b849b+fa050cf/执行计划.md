# 执行计划 · 第 672 轮（深研方向八 D1 第一步：PBR 掠射高光能量修正）

> 窗口：2026-11-05 17:09 宣布 → 常规窗口，终点 **21:30**。
> 目标：修正 PBR-lite 镜面项缺少入射余弦（`NoL`）导致掠射角镜面过亮的问题；
> 新增独立开关（默认关闭），PBR 开启且开关开启时镜面按 `NoL` 归一；关闭时逐字节不变。

| UBO | 场景缓冲尾部追加 `vec4 lighting_extra`（x = 能量模式开关）；`SCENE_BLOCK_FLOATS` 456 → 460 |

## 段 B · 着色器

| 项 | 内容 |
| --- | --- |
| 镜面 | `ggx_specular` 保持；能量模式下方向光 / 补光 / 点光 / 聚光的镜面统一乘 `NoL`（等价于 `D·G·F/(4·NoV)`） |
| 默认 | `lighting_extra.x = 0` 时乘子为 1，既有 PBR / Blinn / toon 路径逐字节不变 |
| 边界 | 背光（`NoL ≤ 0`）镜面本就为 0，乘 `NoL` 不改变；点光路径在 `accumulate_point_light` 内统一处理 |
