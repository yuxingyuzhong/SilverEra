# 执行计划 · 第 648 轮（深研方向八 · A2 数据化）

> 轮次：第 648 轮（2026-11-05）
> 目标：逐盏聚光灯阴影开关（数据化 ＋ 门面）
> 约束：默认全开 → 与 644 / 647 逐字节一致；只影响该盏是否投影，不改着色器与 UBO

## 一、实现

1. `Light_Data.spot_shadow_on[8]`（1 = 参与阴影（默认）、0 = 不投影）；`Scene_Data` 同步并透传。
2. `Impl::spot_shadow_light_enabled[8]`（默认全真）；`scene_apply` 按 `light.spot_shadow_on` 写入。
3. 帧内候选选择（⑤a 聚光矩阵段）：多盏路径与单盏路径都跳过被关闭的槽位；由此瓦片数、槽位映射、聚光 pass 数一并下降。
4. 门面 `spot_shadow_light_set(index, enabled)`：越界返回假；值变化时置 `shadow_pass_ready = false`（旧图不再可信）。
