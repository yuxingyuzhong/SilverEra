## 段 A · 着色器

| 项 | 内容 |
| --- | --- |
| 文件 | `assets/shaders/接触阴影.frag`（顶点复用 `后处理.vert.spv`） |
| 输入 | set1 binding 0 = 源画面、binding 2 = 场景深度；set0 binding 0 = 场景 UBO（与体积雾同前缀） |
| 参数 | `post_param.x` = 强度（0 = 关闭）、`y` = 最大步进距离（世界单位）、`z` = 步数缩放（0.25..2）、`w` = 深度偏置 |
| 算法 | 由深度反投影出世界坐标，沿 `-light_dir` 等距步进；把采样点投影回屏幕取深度，若深度图表面更近则计一次遮挡；按 `强度 × 遮挡比例` 叠向 `post_color.rgb` |
| 边界 | 天空像素 / 方向光强度 0 / 强度 0 一律原样输出；越界采样点跳过 |
