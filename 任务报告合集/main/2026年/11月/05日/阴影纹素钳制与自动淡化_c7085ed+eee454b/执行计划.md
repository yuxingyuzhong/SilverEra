# 执行计划 · 第 661 轮（深研方向八 B1 剩余课题）

> 目标：完成 B1 的两个遗留项 ——「超大阴影半径下的纹素尺寸钳制」与「级联切换带默认软化建议」。
> 口径：默认关闭（`0` / `false`），旧配置逐字节不变；门面方法与 `Light_Data` / `Scene_Data` 字段同时提供（数据化优先）。

---

## 段 A · 数据与门面

| 项 | 内容 |
| --- | --- |
| `Light_Data` / `Scene_Data` | 新增 `shadow_texel_max`（float，世界单位 / 纹素；0 = 关闭）与 `shadow_cascade_blend_auto`（int，0 = 关闭） |
| 门面 | `shadow_texel_max_set(float)` / `shadow_texel_max()`；`shadow_cascade_blend_auto_set(bool)` / `shadow_cascade_blend_auto()` |
| 诊断 | `Frame_Stats` 新增 `shadow_texel_world`（生效纹素世界尺寸，多级取最大片）与 `cascade_blend_applied`（实际写入 UBO 的淡化比例） |
| 校验 | `shadow_texel_max` 取有限值且 ≥ 0，上限 64；非法（负数 / NaN / inf）忽略并告警 |

验收：默认（`shadow_texel_max = 0`、`shadow_cascade_blend_auto = 0`）下 UBO 290 / 矩阵与 660 逐字节一致。

## 段 B · 钳制与自动建议

| 项 | 内容 |
| --- | --- |
| 纹素钳制 | 每片半径 `r` 先按 `r ≤ texel_max × 分片边长 / 2` 收紧，再计算光源机位 / 深度 / 正交投影 / 纹素对齐；分片边长 = `shadow_size / 级联数`（单级 = `shadow_size`） |
| 自动淡化 | 仅在 `shadow_cascade_blend_auto` 开启、显式比例 = 0、级联数 ≥ 2 时生效：`4 / 分片边长` 钳到 `[0.005, 0.1]`（等价于切换带半宽 ≥ 2 纹素） |
| UBO | 290 写「生效比例」（关闭时等于显式值）；矩阵与阴影重绘标志仅在钳制改变时失效 |

验收：钳制后 `Frame_Stats.shadow_texel_world ≤ shadow_texel_max`；自动开启后 `cascade_blend_applied > 0`，关闭为 0。

## 段 C · 用例（新增 `渲染阴影纹素钳制测试.cpp`）

1. 默认口径：`shadow_texel_max = 0` 与显式 0 画面逐字节一致。
2. 钳制生效：半宽 48 / 512² 下 `shadow_texel_world` 从 0.1875 收到 0.05；关闭时回到 0.1875。
3. 自动淡化：2 级 / 1024² → `cascade_blend_applied = 4 / 512 = 0.0078`；显式 0.05 时保持 0.05；自动关闭时为 0。
4. 扁平入口透传：`Scene_Data` 两个字段经 `scene_apply` 生效。
