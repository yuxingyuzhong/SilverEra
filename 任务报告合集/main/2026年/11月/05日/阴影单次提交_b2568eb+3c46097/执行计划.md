## 段 A · Frame 模块拆分（行为不变）

| 项 | 内容 |
| --- | --- |
| 拆分 | `command_record_target` 拆为 `command_record_target_begin` / `command_record_target_pass` / `command_record_target_end`，原函数按「begin + pass + end」组合，对外行为逐字节不变 |
| 参数 | `command_record_target` 增三个布尔（重置查询池 / 写起点时间戳 / 写终点时间戳，默认全真），供批量路径只写一次起终点 |

验收：单 pass 路径构建通过；场景套件与 668 一致。

## 段 B · 批量入口

| 项 | 内容 |
| --- | --- |
| 新 API | `Frame_Context::render_to_targets_batch(targets[], pass_matrices[], pass_count, items, item_count, clear_flags[], shadow_pass)` |
| 语义 | 一次帧槽准备（栅栏 / 查询读回 / 池重置）；单命令缓冲顺序录制 N 段（逐段矩阵、逐段清屏标志）；段间插入颜色 / 深度内存屏障；一次 `vkQueueSubmit2`；`frame_recorded` 跨段累加 |
| 约束 | 仅阴影路径（无回读、无 UI / 后处理回调）；失败即返回假，上层回落旧路径 |

## 段 C · 渲染器接入

| 项 | 内容 |
| --- | --- |
| 数据 / 门面 | `Light_Data.shadow_batch_submit`（int，0 = 关闭（默认））＋ `Scene_Data` 透传 ＋ `shadow_batch_submit_set` / `shadow_batch_submit` |
| 组织 | 阴影重绘时先收集全部目标（级联片 + 聚光瓦片）、矩阵与清屏标志；开启且段数 > 1 时走批量，否则逐 pass 旧路径 |
| 统计 | 批量成功时 `last_shadow_submits = 1`；`shadow_passes / spot_shadow_passes / shadow_resolution` 语义不变 |
