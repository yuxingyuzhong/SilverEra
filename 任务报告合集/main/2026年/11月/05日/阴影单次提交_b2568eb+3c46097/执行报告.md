## 一、交付内容

| 项 | 内容 |
| --- | --- |
| Frame 批量入口 | `Frame_Context::render_to_targets_batch(targets, pass_matrices, pass_count, items, item_count, clear_color, clear_flags, shadow_pass)`：一次帧槽准备（栅栏等待 / 时间戳读回 / 栅栏重置 / 命令池重置）→ 逐段录制 → **一次 `vkQueueSubmit2`** 提交全部；首段复用帧槽主缓冲，其余段从同池分配 |
| 逐段语义 | 每段写入本段矩阵（`push_constants`）、按 `clear_flags` 决定清屏 / 保留；后续段开头插入颜色 ＋ 深度内存屏障（切片共用同图时的跨命令缓冲依赖） |
| 时间戳 | 首段重置查询池并写起点、末段写终点，中间段不写（阴影池仍为 2 查询） |
| 录制拆分 | `command_record_target` 增 `reset_query / write_begin_timestamp / write_end_timestamp / leading_barrier` 四个布尔（默认全真 / 假），原有单 pass 调用方零改动、命令序列逐字节一致 |
| 渲染器接入 | `Light_Data.shadow_batch_submit`（0 = 关闭）＋ `Scene_Data` 透传 ＋ 门面 `shadow_batch_submit_set / shadow_batch_submit`；重绘段先统计段数（级联 ＋ 有效瓦片），> 1 且开启时收集目标 / 矩阵 / 清屏标志并批量提交，否则逐段旧路径 |
| 诊断 | 批量成功时 `Frame_Stats.shadow_submits = 1`；`shadow_passes / spot_shadow_passes / shadow_resolution` 语义不变 |
