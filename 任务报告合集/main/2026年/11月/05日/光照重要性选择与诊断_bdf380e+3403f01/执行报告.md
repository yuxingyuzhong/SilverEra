## 三、口径与算法

1. **预算**：`budget = (Light_Data.light_budget > 0 && < 路径上限) ? 该值 : 路径上限`（旧前向 8 盏 / 簇路径 1024）。
2. **候选集合**：点光（声明序 0..n-1）在前、聚光在后，各组最多 8 条（与 `Light_Data` 数组容量一致）。
3. **评分**（仅 `light_select_mode = 1` 且候选数 > 预算时计算）：
   - 距离权重 `radius /(radius ＋ distance)`（distance = 相机到光源，非法半径按 0 分）；
   - 锥角可见性：点光恒 1；聚光 `clamp((cos − outer)/(inner − outer), 0, 1)`，cos = 光传播方向与「光源 → 相机」方向的夹角余弦；
   - `score = intensity × 距离权重 × 锥角可见性`（非法强度 / 非有限值按 0）。
4. **选择**：逐个取最高分（同分取声明序号较小者）→ 命中集合；登记仍按声明顺序（点光段在前、聚光段在后），故 644 轮「聚光瓦片按槽位映射」不受影响。
5. **默认口径**：`light_select_mode = 0` ＋ `light_budget = 0` → 前 8 个候选（点光优先）逐条登记，与 644 逐字节一致。
