| 项 | 内容 |
| --- | --- |
| 种子 | 复用 `post_color.a`（0 = 关闭抖动（默认）、> 0 = 时域种子；接触阴影阶段该分量空闲） |

| 结构 | 遮挡循环抽为 `contact_occlusion(..., phase)`，两次调用共用同一参数 |
