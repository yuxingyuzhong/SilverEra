> 约束：纯观测字段，画面零改动；默认值 0；不新增着色器 / UBO 字段

## 一、实现

1. `Impl` 增 `last_shadow_passes` / `last_spot_shadow_passes`（每帧入口清零，重绘路径重新累计）。
2. 阴影 pass 循环内累计：方向光级联 pass（`directional_cascade_total`）＋ 聚光瓦片 pass（逐瓦片成功提交计数）。
3. `Frame_Stats` 增 `shadow_passes / spot_shadow_passes / shadow_resolution`（边长取当前阴影目标配置；未建立为 0）。
4. 复用帧（签名一致跳过重绘）→ `shadow_passes = 0`（与 `shadow_reuses` 语义互补）。
