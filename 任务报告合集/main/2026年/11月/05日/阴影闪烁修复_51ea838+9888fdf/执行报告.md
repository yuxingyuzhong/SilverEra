## 一、修复 A：级联阴影视锥纹素对齐

`渲染器.cpp` ⑤a（双 / 三级级联分支，`cascade_count >= 2`）：

- 原实现以**相机世界位置**为包围球中心构造阴影视锥，相机每帧微动 → 视锥逐帧整体平移（CSM swimming），
  阴影边缘高频抖动；无任何纹素对齐。
- 现于 `vp = proj * light_view` 之后，把光源空间裁剪坐标的平移量吸附到本片纹素网格：
  `tile_pixels = shadow_size / cascade_total`，`texel_ndc = 2 / tile_pixels`，
  `vp[3][0] = floor(vp[3][0] / texel_ndc) * texel_ndc`、`vp[3][1]` 同理；Z 不吸附。
- 单级级联（默认）仍固定于世界原点，画面逐字节不变。

## 二、修复 B：聚光灯阴影瓦片按光源槽位固定

`渲染器.cpp` ⑤a 聚光灯分片 + `scene_apply` + `spot_shadow_all_set`：

- 旧口径把「当前有效聚光灯」按声明顺序压缩成瓦片 0..N-1；外部游戏若每帧按相机可见性重排 / 过滤光源，
  瓦片与灯的对应关系整体前移 → 阴影跳变。
- 现改为：**光源槽位都能落进 8 瓦片时，瓦片号 = 光源槽位**（`spot_shadow_slot_tiles[slot] = slot`），
  光源增减 / 重排不再影响其它灯的瓦片；**总光源超过 8 槽**（如 8 聚光 ＋ 3 点光 = 11 盏）时回落旧的
  「按声明顺序压缩」口径，与既有 8 瓦片用例（探针 `spot_shadow_tiles == 8`）一致。
- 瓦片按需创建同步改为「槽位模式下建到最靠后的聚光灯槽位 +1，压缩模式下建到聚光灯数量」，至少 1 张占位。

## 三、修复 C：阴影按需重绘签名只混参与投影项

`渲染器.cpp` 匿名命名空间 `shadow_signature_build`：

- 旧实现混入 `pending_instances` **全部实例**的浮点位模式；文字 / 粒子等不投影项每帧变化也会使签名变化，
  导致每帧整张阴影重绘，把细微差异放大成闪烁观感。
- 现改为遍历 `pending_items`，只对 `cast_shadow` 项按 `instance_offset / INSTANCE_STRIDE_BYTES` 定位连续实例区间并混入矩阵；
  光源矩阵、投影项数、阴影图边长、级联数混入方式不变。调用点改为直接传 `pending_items` / `pending_instances`。

## 四、文档：内部多线程 ≠ 对外线程安全

`渲染器.h` 类注释补充：

- 公开 API（`init` / `shutdown` / `frame_render` / `mesh_draw` / `scene_apply` / 查询与 setter）仍须同一线程；
- 「多线程渲染」指内部并行：按 `render_threads` 启动的工作线程只做实例剔除 / 实例差异扫描，
  并把场景 / 阴影 pass 命令录进**次级命令缓冲**，最终由调用线程在主缓冲 `vkCmdExecuteCommands` 汇总提交；
  Vulkan 对象创建、提交、呈现全部在调用线程；工作线程不对外暴露。

## 六、给外部接入方的使用要点

1. 同一线程调用；每帧只调用一次 `frame_render`，不要与渲染器共用队列自行提交。
2. `scene_apply` 会按 `Light_Data` 的 `shadow_enabled` / `spot_shadow_enabled` **重置阴影开关**，每次重新应用后需显式开启。
3. 级联模式下相机微动已不再重采样；若仍觉得边缘跳变，可设 `shadow_cascade_blend_set(0.1~0.3)` 软化级联切换带。
4. 聚光灯跟随相机时建议开启 `spot_shadow_bias_auto_set(true)`，按锥远平面归一化偏置，减少掠射自阴影噪点。
