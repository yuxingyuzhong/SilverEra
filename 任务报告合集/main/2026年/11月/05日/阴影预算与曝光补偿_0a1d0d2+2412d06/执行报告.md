## 一、659 · 阴影分辨率预算（B3）

| 项 | 内容 |
| --- | --- |
| 数据 / 门面 | `Light_Data.shadow_budget_bytes`（0 = 关闭）＋ `Scene_Data` 透传；`shadow_budget_set`（>1 GiB 截断） |
| 换算 | 单位数 = 方向光级联数（≤ 3）＋ 聚光瓦片数（多盏取盏数、单盏取 1）；`边长 = floor(√(预算 /(单位数 × 4)))`，向下取 256 倍数、钳 256..4096，再吸附受支持档（512 / 1024 / 2048），与请求分辨率取较小 |
| 默认 | 0 → 不干预（与 658 逐字节一致） |
| 用例 | 关闭不干预；单级 512² × 4 → 512、1024² × 4 → 1024；双级预算翻倍 → 仍 512；极小预算 → 512 档；扁平入口透传 |

## 二、660 · 曝光补偿（A3）

| 项 | 内容 |
| --- | --- |
| 数据 / 门面 | `Light_Data.exposure`（EV，默认 0，钳 [-4, 4]）＋ `Scene_Data` 透传；`exposure_set` / `exposure_get` |
| 着色器 | `shadow_strength` 后新增 `float exposure`（std140 占 237，`pbr_params` 仍对齐 240，**布局未变**）；`final_rgb *= exp2(exposure)` 后统一钳制输出 |
| 默认 | EV 0 → `exp2(0) = 1` 乘性恒等（渲染套件 723 / 723 逐字节不变） |
| 用例 | 默认与显式 0 逐字节一致；+1 EV 变亮 / −1 EV 变暗（中心亮度单调）；钳制 ±4；NaN 忽略；扁平透传 |
