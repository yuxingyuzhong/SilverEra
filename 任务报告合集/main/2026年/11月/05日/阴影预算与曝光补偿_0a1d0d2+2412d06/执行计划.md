## 659 · 阴影分辨率预算（B3）

1. `Light_Data.shadow_budget_bytes`（0 = 关闭）＋ `Scene_Data` 透传；门面 `shadow_budget_set`。
2. 换算：单位数 = 方向光级联数 ＋ 聚光瓦片数；`边长 = floor(√(预算 / (单位数 × 4)))`，
   向下取 256 倍数、钳 256..4096，再吸附到受支持档（512 / 1024 / 2048）；与请求分辨率取较小值。
3. 用例：预算关闭不干预 / 折算与多单位分摊 / 极小预算取最低档 / 扁平透传。

## 660 · 曝光补偿（A3）

1. `Light_Data.exposure`（EV，默认 0，钳 [-4, 4]）＋ `Scene_Data` 透传；门面 `exposure_set / exposure_get`。
2. 着色器：`shadow_strength` 后新增 `float exposure`（std140 占 237，`pbr_params` 仍对齐 240，**布局不变**）；
   最终颜色乘 `2^EV`，EV 0 乘性恒等。
3. 用例：默认与显式 0 逐字节一致 / ±1 EV 亮度单调 / 钳制与 NaN 忽略 / 扁平透传。
