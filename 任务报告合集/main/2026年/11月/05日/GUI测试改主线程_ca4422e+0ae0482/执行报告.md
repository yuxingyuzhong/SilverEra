## 一、问题与修复

| 项 | 内容 |
| --- | --- |
| 现象 | 图形界面里运行测试弹出 `Assertion failed … SDL_PumpEventsInternal (SDL_events.c:1500): 'SDL_IsMainThread_REAL()'`，对话框阻塞该轮 |
| 根因 | `Test_Runner` 在工作线程执行 gtest；渲染用例创建 SDL 窗口并逐帧 `SDL_PollEvent`（[事件泵.cpp](file:///d:/代码存储/代码仓库/白银纪元/Engine/EngineSystem/src/core/Renderer/src/render/Platform/core/事件泵.cpp)），SDL3 要求事件泵在主线程 |
| 修复 | **测试改由界面主循环在进程主线程执行**：删除工作线程，新增 `Test_Runner::poll_on_caller()`，主循环每帧调用一次 |
