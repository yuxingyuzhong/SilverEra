# 执行计划 · 第 670 轮（深研方向八 C1：聚光阴影图集）

> 窗口：2026-11-05 17:09 宣布 → 常规窗口，终点 **21:30**。
> 目标：把 8 张独立聚光阴影图合并为单张 4×2 图集（每瓦片 `shadow_resolution` 见方），
> 图集开启时聚光阴影 pass 从「逐张独立目标」改为「单目标子视口分块」；默认关闭，开关两态画面与阴影图逐字节一致。
> 依据：`渲染层下轮方向.md` 的 C1 设计基线（669 轮收口时登记）。

---

## 段 A · 数据与门面

| 项 | 内容 |
| --- | --- |
| 数据 | `Light_Data.spot_shadow_atlas`（int，0 = 关闭（默认）、1 = 启用图集） |
| 透传 | `Scene_Data.spot_shadow_atlas` ＋ `scene_apply(Scene_Data)` 拆组转发 |
| 门面 | `spot_shadow_atlas_set(bool)` / `spot_shadow_atlas()` 只读查询 |
| 着色 | 图集开关写入场景 UBO `spot_shadow_params.x`（该分量此前未被着色器读取） |

验收：默认 0 时 UBO 其余字段与行为不变。

## 段 B · 渲染器资源

| 项 | 内容 |
| --- | --- |
| 目标 | 新建 `spot_shadow_atlas_target`：宽 4S、高 2S、RGBA8、单采样；瓦片 `(col, row) = (tile % 4, tile / 4)` |
| 惰性 | 仅开关由 0 → 1 时创建；关闭即销毁；创建失败仅告警并回落 8 张独立图 |
| 绑定 | 开启：binding 9 的 8 个数组元素全部写入图集视图；关闭：恢复逐瓦片视图（缺瓦片回落默认白纹理） |
| 分辨率切换 | `shadow_resolution_set` 成功后若图集请求仍有效则按新边长重建图集并重绑；失败回落独立图 |
| 销毁 | `shutdown` 中图集目标先于逐瓦片目标销毁 |

## 段 C · 渲染路径

| 项 | 内容 |
| --- | --- |
| 分块 | 图集开启时每瓦片目标为同一图集，`viewport_rect.offset = (col·S, row·S)`、`extent = (S, S)` |
| 清屏 | 首个有效瓦片清整张图（颜色 ＋ 深度），其余瓦片保留（与级联多片同口径） |
| 批量 | 669 的 `render_to_targets_batch` 原样承载子视口段；逐段清屏标志仅在首瓦片为真 |
| 统计 | `shadow_passes` / `spot_shadow_passes` / `shadow_submits` 口径不变（图集仍按瓦片计 pass） |

## 段 D · 着色器

| 项 | 内容 |
| --- | --- |
| 原点 | `spot_shadow_params.x > 0.5` 时瓦片像素原点 = `(col·S, row·S)`，否则 `(0,0)` |
| 采样 | `shadow_sample_core` 增 `ivec2 texel_origin` 入参；纹素坐标与 PCSS / 软度邻域钳边改为瓦片局部范围 |
| 不变性 | 方向光路径与图集关闭路径原点为 0，结果逐字节一致 |

## 段 E · 用例与验证

| 用例 | 断言 |
| --- | --- |
| 开关一致 | 多盏聚光场景：图集关 → 开，画面逐字节一致 |
| 瓦片有效 | 图集开启后 8 个瓦片仍按槽位映射生效（逐盏遮挡差异与关闭时相同） |
| 统计不变 | 开关两态 `spot_shadow_passes` / `shadow_passes` 相同 |
| 回归 | 场景套件 ＋ 关卡套件 ＋ 全量（1395 例基线） |
