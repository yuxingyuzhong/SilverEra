## 一、用户指令①：单级级联固定原点（已修复）

| 项 | 内容 |
| --- | --- |
| 旧行为 | `cascade_count == 1` 时光源机位固定 `-light_dir × 20`、正交视锥以**世界原点**为中心、半宽 `shadow_half_extent`、近远 1 / 60 |
| 后果 | 相机离开原点超过半宽后阴影整片丢失；回到原点又出现（外部工程移植时表现为「阴影跟相机无关」/「阴影消失」） |
| 新行为 | 与多级同一拟合口径：**球心 = 相机位置、半径 = `shadow_half_extent`**，`eye = center − light × (半径 ＋ 近平面)`，深度跨度 = `2 × 半径 ＋ 2 × 近平面`；**同口径纹素对齐**（X / Y 吸附，Z 不动） |
| 保留 | 单级远区矩阵仍为零；`cascade_depth_span[0..2]` 统一取本片跨度（着色器按级联数取用） |
| `shadow_far` | 单级路径不再使用（此前仅用于固定的 60 远平面）；字段保留以兼容既有门面，多级不受影响 |

验证（`渲染级联阴影测试.cpp` 重写「双级远端覆盖」为四组对照）：
- 默认机位、物体 z = −5 → 单级遮蔽（中心亮度 < 60）；
- 相机与物体同移到 x = 40 → **单级仍遮蔽**（证明跟随相机；旧实现会变亮）；
- 相机回默认、物体 z = −20（距相机约 23 > 半径 12）→ 单级受光（≥ 150）；
- 切双级（远区半径 36）→ 远端被遮蔽（< 60）。
