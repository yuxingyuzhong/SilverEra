## 一、交付内容

1. 新增计算着色器 `Particle发射.comp`：
   - `binding 0`：目标状态缓冲（只写新槽）；`binding 1`：控制缓冲（`[0]` 环形写指针、`[1]` 活跃计数、`[2..]` 活跃位图，每 32 粒子一字）；
   - 每线程 `atomicAdd` 环形指针取唯一槽位（`index = slot % capacity`）；
   - 形状（点 / 盒 / 球壳，盒与球壳使用 `extents[0]` 为半径）、速度区间、寿命区间、主方向 ＋ 0.3 随机扰动；
   - 随机数用 LCG（常数与 CPU 参考一致，仅要求分布同口径）；
   - 写入状态后 `atomicOr` 置位图、`atomicAdd` 活跃计数加一。
2. 门面新增常驻发射：
   - `particle_resident_set/enabled、_get`（计算不可用 / 未开启粒子时拒绝；开启时回读一次计数缓存）；
   - `particle_gpu_emit(count)`：回读计数 → 计算剩余容量 → 绑定 0/1/2/3 → 调度 → 再回读计数并结算实际发射数；
   - `particle_active_count` 在常驻模式下返回 GPU 回读计数，关闭常驻回到 CPU 镜像。
3. 计算资源扩展：`particle_gpu_ensure` 创建控制缓冲（`8 + ceil(容量/32)×4` 字节，零值初值）并加载发射管线；
   `particle_gpu_bytes` 计入控制缓冲；销毁与关闭流程同步释放。
4. 用例 `Renderer_Particle_Test` ＋1（`常驻GPU发射`）：
   - 常驻关闭时 GPU 发射为 0；开启后三次发射（10 / 10 / 64）后活跃 64（池满截断 44）；
   - 出生统计同步 64；关闭常驻回到 CPU 镜像活跃 0；
   - 计算不可用设备拒绝常驻与 GPU 发射。
