## 一、交付内容

1. 数据结构扩展（`粒子数据.h`）：
   - `enum class Force_Type`：`Attractor = 0`（引力 / 斥力点）、`Vortex = 1`（涡流）、`Wind = 2`（风场）；
   - `Particle_Force_Field`（40 字节：`position[3]`、`radius`、`strength`、`direction[3]`、`type`、`padding`），
     与 GPU std430 **float 数组**布局逐字段一致（避免 vec3 的 16 字节对齐差异）；
   - `Particle_Params` 追加 `force_count` 与 `forces[8]`；常量 `PARTICLE_FORCE_MAX = 8`、`PARTICLE_FORCE_STRIDE = 40`。
2. 参数校验（`粒子参数合法` 扩展）：力场数 ≤ 8、类型 ≤ 2、各数值有限、半径非负、涡流 / 风场方向长度非零。
3. CPU 参考（`Particle_System::step`）：顺序固定为「重力 → 力场（按配置顺序）→ 阻尼 → 位置积分」：
   - 风场：`v += normalize(direction) × strength × dt`；
   - 引力点：半径内 `v -= normalize(p − center) × strength × (1 − d/r) × dt`（负强度即斥力）；
   - 涡流：半径内 `v += normalize(cross(axis, p − center)) × strength × (1 − d/r) × dt`；
   - 半径外 / 退化方向 / 退化切向一律跳过。
4. GPU 推进（`Particle推进.comp`）：新增 binding 2 力场 SSBO（`Force_Field` 为 float 数组结构），
   推送常量 `params.z` 为力场数；公式与判空顺序与 CPU 完全一致。
5. 计算资源：`particle_gpu_ensure` 追加固定 8 × 40 字节力场缓冲（零值初值），`particle_gpu_step` 每步上传前
   `force_count` 项并绑定 binding 2；自检 `probe` 绑定零力场；销毁与关闭流程同步释放。
