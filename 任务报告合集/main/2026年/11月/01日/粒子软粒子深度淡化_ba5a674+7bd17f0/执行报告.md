## 一、交付内容

1. `Particle_Params` 增 `soft_depth_range`（0 = 关闭；[0,1] 校验）。档位含义：`clamp((场景深度 − 粒子深度)/档位, 0, 1)` 的淡出宽度（NDC 深度差口径）。
2. 逐项采样集支持场景深度：
   - `Pipeline_Context::Draw_Set_Views` 增 `depth` / `depth_sampler`，批量写入时 binding 2 用它们（未提供回落反照率视图＋本项采样器，旧行为不变）；
   - `Frame_Render_Item` 增 `draw_depth` / `draw_depth_sampler`，帧填装阶段透传给批量写入。
3. 三条绘制路径绑定 HiZ 历史：
   - 门面 `particle_depth_source(slot, view, sampler)`：档位 > 0 且 HiZ 启用 ＋ 资源有效 ＋ 该槽历史就绪时输出历史视图 / 最近邻采样器；
   - CPU 参考（单次 + 逐桶）与 GPU 直接 / GPU 间接均在登记项上挂 `draw_depth`，推送块 `offset 112` 写档位（未就绪时写 0）；
   - 粒子片元静态声明 `set1 binding 2`，故所有粒子项都落一条专属采样集（未绑定纹理时以默认白纹理补齐，避免共享集未写该绑定）。
4. `粒子.frag`：档位 > 0 时 `texelFetch(scene_depth, gl_FragCoord)` 取历史深度，`out_alpha *= clamp((scene_d − gl_FragCoord.z)/档位, 0, 1)`。
5. 用例 `粒子软粒子深度淡化`：交换链路径（HiZ 只在交换链场景退场生成；离屏目标不生成），黑墙在粒子后方 0.02，档位关 → 开，蓝通道累加 **6784 → 1960**（−71%）。
