## 一、交付内容

1. 新增着色器 `粒子.vert` / `粒子.frag`：
   - 顶点沿用场景顶点布局（位置 + UV）与实例模型矩阵（location 3..6），只做世界变换；
   - 片元为程序化圆盘（UV → 局部半径，`smoothstep(1.0, 0.65)` 软边），暖黄色输出，不采样任何纹理。
2. 门面新增 `particle_draw(float size)`：
   - 按相机世界位置逐活跃粒子构造「右 / 上基向量 × 半尺寸 ＋ 中心」列主序模型矩阵（billboard 基在 CPU 侧构造）；
   - 临时切换到粒子管线，复用 `mesh_draw_instanced` 的实例缓冲与剔除链路，登记**一个**绘制项后恢复调用前管线；
   - 粒子项不参与阴影视图投影（登记后清 `cast_shadow`）。
3. 惰性资源：单位四边形网格（`mesh_plane_load` 1×1）＋ Alpha 混合粒子管线（与场景管线共享布局）；关闭流程先归还网格再销毁帧 / 网格上下文。
4. 用例 `Renderer_Particle_Test` ＋1（`粒子billboard定位`）：
   - 64×64 离屏目标、相机 (0,0,3) 注视原点、清屏色黑；
   - 原点单粒子（`size = 0.5`）绘制后中心像素红色分量 > 40、边角 < 8；
   - `size ≤ 0` 拒绝；关闭粒子后 `particle_draw` 为假且 `particle_gpu_available` 为假。
