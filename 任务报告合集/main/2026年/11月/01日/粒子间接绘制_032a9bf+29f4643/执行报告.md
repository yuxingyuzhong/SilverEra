## 一、交付内容

1. **着色器** `Particle间接.comp`（local_size_x = 1）：读紧凑计数（binding 0）→ 写 5 个 uint32 间接命令（binding 1）：
   `index_count` 取推送常量 `params.x`、`instance_count` = 紧凑计数、`first_index / vertex_offset / first_instance` 恒 0。
2. **计算缓冲创建扩展**：`Renderer::Impl::compute_buffer_create_usage(...)`（主机可见 STORAGE ＋ TRANSFER_SRC ＋ 追加用法），
   粒子间接命令缓冲按**帧槽**各建一份（20 字节，`STORAGE | INDIRECT`），初值零。
3. **帧模块**：`Frame_Render_Item` 增 `gpu_indirect` / `indirect_command_buffer` / `indirect_command_offset`；
   录制时此类项以单条 `vkCmdDrawIndexedIndirect(cmd, buffer, offset, 1, 20)` 下达，实例数取自命令；
   跳过条件增「间接项须有命令缓冲」；间接合批路径与静态合批天然跳过（`instance_input` 恒假）。
4. **可见性屏障**：`命令录制.cpp` 新增 `indirect_command_sync`，在交换链 / 离屏 / 链三条录制路径的**动态渲染之外**、
   批量存在 `gpu_indirect` 项时下发 `COMPUTE_SHADER(SHADER_WRITE) → DRAW_INDIRECT(INDIRECT_COMMAND_READ)` 内存屏障；
   无此类项时不插入（既有路径逐字节不变）。
5. **门面**：`particle_indirect_draw(float size)`（常驻专用）：等待本帧槽 → 紧凑 → 绑定计数 / 该槽命令缓冲 → 单线程调度 →
   逐帧槽刷新粒子专用 set0 → 登记 1 个「无实例属性 ＋ 粒子集 ＋ GPU 间接」绘制项；
   `particle_indirect_command_get(command_out[5])` 回读命令（诊断 / 测试）。
6. `particle_gpu_ensure` 增建命令缓冲与 `Particle间接.comp.spv` 管线；`particle_gpu_destroy` 逐槽卸载并复位标记。
7. **用例**：
   - `粒子间接绘制`：未开常驻拒绝；256 实例 → 命令 `{6, 256, 0, 0, 0}` → 出帧 `drawn_instances = 256`、可见 39 px（与 `粒子GPU绘制` 同口径）。
   - `百万粒子间接命令基线`：1 048 576 全活跃，三次生成取末次 **1.746 ms**（统计紧凑 1.415 ms），命令实例数 = 1 048 576。

## 二、关键设计取舍

- **按帧槽命令缓冲**：间接命令在 GPU 执行时读取，若全帧共用一个缓冲，下一帧写入会覆盖在途帧仍在读的内容；
  改为每槽一份并在写入前 `slot_wait`，只等待相关槽（不做全帧 stall）。
- **跨提交可见性**：命令由 `compute_dispatch` 的前置提交写入（携带 `ComputeToHost` 屏障并等围栏），
  本帧提交以 `indirect_command_sync` 建立「计算写 → 间接命令读」的可见性，避免依赖驱动隐式行为。
- 命令 `index_count` 由四边形网格记录给出（6），与门面登记的 `index_count` 同源。
