## 一、交付内容

1. 新增计算着色器 `assets/shaders/Particle推进.comp`（local_size 64）：
   - `Particle_State` 按 std430 布局与 Host 侧逐字段一致（position[3] → velocity[3] → age → lifetime，共 32 字节）；
   - binding 0 只读上一步状态、binding 1 只写下一步状态；
   - 运算顺序与 CPU 参考完全相同：`v += g·dt → v *= damping → p += v·dt → age += dt`，`age ≥ lifetime` 时把 lifetime 置 0；
   - 未登记槽位（lifetime ≤ 0）原样写回。
2. 门面新增 GPU 资源管理（私有 `particle_gpu_ensure` / `particle_gpu_destroy`，公共 `particle_gpu_available` / `particle_gpu_probe`）：
   - 按粒子池容量创建双缓冲（容量 × 32 字节，主机可见 SSBO，零值初值）；
   - 惰性加载 `Particle推进.comp.spv`；容量变化时先释放旧资源再按新容量重建；
   - 失败路径整体回收，句柄复位为 0。
3. `particle_supported` 口径改为「已初始化且计算路径可用」（第三百一十一轮接入计算路径）。
4. `particle_capacity_set` 同步释放旧尺寸 GPU 资源；关闭流程在计算缓冲 / 管线表清空后复位粒子资源句柄（避免悬挂句柄与延迟队列泄漏）。
5. 自检 `particle_gpu_probe`：上传当前 CPU 状态 → 零步调度（dt = 0、阻尼 = 1，恒等变换）→ 回读后缓冲，按活跃标记逐索引比对 32 字节，
   覆盖「描述符绑定 → 推送常量 → 调度 → 写回 → 读回」整条通路；非活跃槽位不参与比对（回收不改写状态内容）。
