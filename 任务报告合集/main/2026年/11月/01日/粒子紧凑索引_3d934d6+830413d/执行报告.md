## 一、交付内容

1. 新增着色器 `Particle紧凑.comp`（local 64）：
   - binding 0 = 控制缓冲（只读位图，`[2..]` 每 32 粒子一字）、binding 1 = 紧凑索引（只写）、binding 2 = 紧凑计数（原子）；
   - 推送常量 `uvec4 {容量, 位图字数, 0, 0}`；线程判活后 `atomicAdd(count,1)` 取位写索引。
2. 资源：`particle_index_buffer`（`容量 × 4 B`）、`particle_compact_count_buffer`（4 B），
   创建 / 释放 / `particle_gpu_bytes` 三处同步（字节 = 双缓冲 ＋ 力场 ＋ 控制 ＋ `容量×4 + 4`）。
3. 门面：
   - `bool particle_gpu_compact(void)`：清零计数 → 绑定 0/1/2 → 按容量调度 → 回读计数（越界钳制）；
   - `uint32_t particle_compact_count_get(void) const`：未开常驻返回 0；
   - `uint32_t particle_compact_indices_get(uint32_t*, uint32_t)`：诊断 / 测试回读。
4. 用例 `常驻紧凑索引`：未开常驻被拒；96 活跃 → 计数 96 且等于活跃数；索引互异且恰好覆盖 0..95；
   推进至全死后计数归零。**实测定案：紧凑顺序不保证池索引升序**（原子取位由并发决定），注释与用例均按此口径。
