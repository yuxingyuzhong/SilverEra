## 一、交付内容

1. `Particle_Params`（`粒子数据.h`）末尾新增 `float edge_softness;`（结构 400 → 404 B，仅 CPU 侧与推送块）。
   语义：0 = 保持第三百一十四轮的 0.65 内半径；0..1 时内半径 = 1 − 宽度，越大边缘越柔。
2. `particle_params_valid`：`edge_softness` 须落在 [0, 1]（复用 `unit_interval`，含非有限拒绝）。
3. 门面 `particle_color_push_fill` 改名 `particle_style_push_fill`（`渲染器.h` / `渲染器.cpp`，3 处调用同步），
   在写颜色后追加 `push[25] = edge_softness`（推送块 offset 96.y）；CPU 占位块的 UV 缩放 y 分量不再可能被误读。
4. `粒子.frag`：`particle_style.y` 读软边宽度；> 0 时 `inner = 1 − softness`，否则回落 0.65；`particle_style.x` 继续承担颜色启用标志。
5. 用例：`粒子软边可配`（单枚边长 1.6 纯蓝粒子，`edge_softness = 0` 与 `0.95` 各出一帧，整幅蓝色通道累加 34208 → 22200，约 0.65 倍）；
   `粒子数据测试/模拟参数校验` 补宽度越界 / 非有限 / 合法三例。
