## 一、交付内容

1. **展廊第九区预配置**：粒子容量 `4096 → 65 536`、发射器单次上限 `64 → 256`；
   `update` 区内每帧 `particle_gpu_emit(256)` ＋ `particle_gpu_step_resident(0.08)`（回落路径同为 256）。
2. **绘制路径分档**（`frame_draw`）：
   - 非常驻 → `particle_draw`（CPU 参考）；
   - 常驻且容量 ≥ 16384 → `particle_indirect_draw`（GPU 写实例数、单条 `vkCmdDrawIndexedIndirect`）；
   - 常驻且容量 < 16384 → `particle_gpu_draw`（直接 GPU 绘制）。
   展区标题同步为「⑨ 粒子喷泉（GPU 间接绘制 / 力场 / 碰撞）」。
3. **用例**：`展廊粒子GPU绘制接入` 增「间接命令实例数 = 活跃数（192）」断言（证明场景实际命中间接路径）；
   `展廊粒子喷泉接入` / `展廊粒子常驻接入` 的容量断言同步为 65 536。
4. 背景：第 345 轮的发射种子与 billboard 缩放修正使展廊喷泉的粒子分布恢复为真实球壳（此前全部叠在同一点）。

## 二、设计取舍

- 分档阈值 16384 取「间接路径在主机侧更省（单条命令）而直接路径在小规模更省（无命令缓冲）」的经验值；
  两路径共用同一 `粒子GPU.vert` 管线与粒子专用 set0，切换只影响帧项登记方式。
- 发射 256 / 帧在 60 fps 下稳态约 2.7 万粒子（寿命 1.4–2.2 s），远低于 65 536 容量，留出突发余量。
