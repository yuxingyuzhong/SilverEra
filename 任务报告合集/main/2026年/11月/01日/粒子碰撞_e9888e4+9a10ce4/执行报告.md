## 一、交付内容

1. `Particle_Params` 追加碰撞球 `sphere_center[3]` / `sphere_radius`（半径 ≤ 0 = 关闭）；参数校验补球心有限性与半径非负。
2. CPU 参考（`Particle_System::step`）：位置积分后依次处理
   - 地面平面：`y < floor_y` 时钳到地面；法向速度 `vy < 0` 时取反并按 `restitution` 衰减；切向（x / z）按 `friction` 衰减；
   - 球体：进入球面（球心距 < 半径）时沿法向推出到球面；法向速度为负时做「法向回弹 ＋ 切向摩擦」合成。
3. GPU 推进（`Particle推进.comp`）：
   - 推送常量扩为 16 浮点（4 个 vec4：重力与步长 / 阻尼容量力场数 / 碰撞球 / 地面与材质）；
   - 碰撞代码与 CPU 完全同序（先地面、再球体），法向 / 切向公式逐项一致。
4. 用例 `Renderer_Particle_Test` ＋3：
   - `碰撞地面`：重力下落 30 步，最低点 ≥ 地面 − 1e-4（无穿透）且出现法向速度由负转正的反弹；
   - `碰撞球体`：−Z 撞向原点半径 0.5 的球，全程最小球心距 ≥ 0.5 − 1e-4，撞后 z 速度反向；
   - `碰撞GPU对照`：地面 ＋ 球体 ＋ 重力，CPU / GPU 二十步逐粒子位置 / 速度 1e-5。
