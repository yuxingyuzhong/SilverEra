## 一、交付内容

1. `particle_indirect_draw` 的「紧凑」与「写间接命令」改为**同一次一次性提交**内的两次调度：
   `20 B 命令缓冲` 与紧凑计数缓冲的写入前准备沿用；`single_submit` 内依次
   「调度紧凑 → `ComputeToCompute` 屏障 → 调度写命令 → `ComputeToHost` 屏障」，只等一次围栏。
2. **关键实现细节**：Vulkan 描述符集内容在**提交时**读取、而非录制时快照，同一次提交内切绑定必须换集；
   故两次调度使用不同的计算描述符集槽——槽 0 = 紧凑（控制 / 索引 / 计数），槽 1 = 写命令（计数 / 命令缓冲），
   两个集的绑定都在提交前写好，录制时只 `slot_set`。调用结束后恢复原槽。
3. 紧凑耗时统计 `particle_compact_ms` 口径同步：间接路径下该值含「写命令」耗时（字段注释已更新）。
4. `particle_gpu_compact` 保持不变（其它调用方 / 用例仍可单独紧凑）。
