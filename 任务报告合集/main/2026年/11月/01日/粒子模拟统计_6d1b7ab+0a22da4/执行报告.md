## 一、交付内容

1. `Frame_Stats` 追加粒子统计字段：
   - `particle_active`（当前活跃；未开启为 0）、`particle_born_total` / `particle_died_total`（自 init 累计）；
   - `particle_sim_ms`（最近一次步进的主机侧耗时；CPU 参考或 GPU 同步链）；
   - `particle_gpu_ms`（最近一次 GPU 调度的设备耗时；设备不支持计算时间戳时恒 −1）。
2. 门面埋点：
   - `particle_emit` 把实际发射数累加到出生；
   - `particle_step` 用高精度时钟量测主机侧耗时，并累加死亡；
   - `particle_gpu_step` 量测整条同步链主机耗时、累加死亡，并取计算统计的设备耗时（不支持时间戳则 −1）；
   - `frame_stats_get` 汇总以上字段（关闭粒子时活跃与累计均为 0）。
3. 用例 `Renderer_Particle_Test` ＋1（`粒子模拟统计`）：
   - CPU 路径：发射 16、十二步全回收，断言 `活跃 0 / 出生 16 / 死亡 16` 与守恒关系 `出生 − 死亡 = 活跃`，`sim_ms ≥ 0`；
   - GPU 路径：同样发射与十二步，统计自洽；支持时间戳时 `gpu_ms ≥ 0`，否则为 −1。
