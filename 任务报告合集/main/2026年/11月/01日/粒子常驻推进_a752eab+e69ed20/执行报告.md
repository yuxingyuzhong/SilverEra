## 一、交付内容

1. 新增计算着色器 `Particle常驻推进.comp`：
   - 与 `Particle推进.comp` 同序（重力 → 力场 → 阻尼 → 积分 → 碰撞 → 年龄），
     差异为状态常驻显存（读 front / 写 back）与死亡处理；
   - `binding 3` 为控制缓冲：死亡时 `atomicAnd` 清位图位，仅当原位曾被置位时
     `atomicAdd(control[1], 0xFFFFFFFFu)` 等量减一（GLSL 无 `atomicSub`）。
2. 门面新增 `particle_gpu_step_resident(float dt)`：
   - 回读推进前计数 → 上传力场 → 绑定 0/1/2/3 → 调度（`capacity` 元素）→ **交换前后缓冲** →
     回读推进后计数；
   - 死亡数 = 前计数 − 后计数，写入 `particle_gpu_died_last` / `particle_died_total`；
   - 主机侧与设备耗时写入 `particle_sim_ms` / `particle_gpu_ms`。
3. 常驻保护：`particle_gpu_step`（同步链）与 `particle_gpu_probe` 在常驻模式下返回假，避免覆盖常驻状态。
4. 用例 `Renderer_Particle_Test` ＋1（`常驻推进与死亡压缩`）：
   - 常驻发射 32（寿命 0.5–0.6）→ 十二步 0.05 s 后活跃 0、死亡累计 32（与统计一致）；
   - 再次发射 8 沿用环形指针；常驻下同步链推进 / 自检被拒，关闭常驻后自检恢复；
   - 常驻单步主机耗时 **0.168 ms**（远低于 1 ms 目标）。
