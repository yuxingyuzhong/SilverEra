## 一、缺陷与修正

**缺陷**：`Particle发射.comp` 在环回绕时若落到仍活跃的槽位，会重复累加 `control[1]`（活跃计数），
使「活跃计数」大于位图基数；后续死亡按位清理并减计数，误差长期残留（影响 `particle_active_count`、
`Frame_Stats.particle_active` 与紧凑索引数）。

**修正**（4 行）：

```glsl
uint old_word = atomicOr(control[2 + word], 1u << bit);
if ((old_word & (1u << bit)) == 0u)
	atomicAdd(control[1], 1u);
```

即「计数 = 位图基数」成为不变量：置位前原位为 0 才加一，覆盖已活跃槽位不改变计数。

## 二、用例 `紧凑索引环形回绕`

- 容量 128、寿命 0.5–0.7 s，满池发射 128 → 推进 11 × 0.05 s（存活 96 左右）；
- 环形指针位于 128 → 再发射 128（实际预算 = 剩余容量，落点 0..N 与活跃位重叠）；
- 断言：活跃数 **≤ 128**（旧实现会越过容量）、紧凑计数 = 活跃数、索引互异且全部 `< 128`。
