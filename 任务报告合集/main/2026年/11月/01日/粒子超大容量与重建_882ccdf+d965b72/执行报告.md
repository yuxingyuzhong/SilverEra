## 一、交付内容

1. 新增门面观测 `uint64_t particle_gpu_bytes(void) const`：
   - 双缓冲字节数 = 容量 × 32 × 2；力场缓冲 = 8 × 40 B；资源未创建时为 0。
2. 容量重建口径修正（`particle_capacity_set`）：
   - 仅当容量**真实变化**时才 `frames_wait()`（等尽在途帧）并释放旧尺寸 GPU 资源；
   - 同值重复设置改为空操作（不重建、资源字节不变）；
   - 超上限自动钳到 1 048 576。
3. 地面碰撞改为显式开关 `Particle_Params::ground_enabled`（默认 0 = 关闭）：
   - 修正第三百一十九轮引入的隐性回归——默认参数下自由落体会被 `floor_y = 0` 钳住；
   - CPU 与 GPU 同口径（推送常量 `surface.w`）；球体碰撞不受该开关影响。
4. 用例 `Renderer_Particle_Test` ＋1（`超大容量与重建`）：
   - 容量上限 1 048 576 时资源可用、`particle_gpu_bytes` = 64 MB ＋ 320 B、零步自检通过；
   - 同值重复设置字节不变；超上限钳制；收缩到 64 后字节 = 4 KB ＋ 320 B 且自检仍通过。
