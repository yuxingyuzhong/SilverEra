## 一、交付内容

1. 门面新增 `particle_gpu_step(float dt)`：
   - 校验路径可用（计算可用 ＋ 粒子已开启 ＋ 资源就绪）与步长（有限且 > 0）；
   - 上传 CPU 镜像 → 绑定前 / 后缓冲（binding 0 / 1）→ 以推送常量 `{g.x, g.y, g.z, dt, damping, capacity, 0, 0}` 调度 → 回读覆盖 CPU 镜像；
   - 每步均以上一步结果作为上传源，等价于 CPU / GPU 交替的固定步长推进。
2. 门面新增 `particle_state_get(uint32_t, Particle_State&) const`：未开启 / 越界 / 非活跃返回假，供对照与后续观测使用。
3. 用例 `Renderer_Particle_Test` ＋1（`GPU推进单步对照`）：
   - 同种子（默认 LCG 12345）、同发射器、同参数的两套渲染器各发射 32 个；
   - 重力 `(0, -2, 0)`、阻尼 `0.9`、步长 `0.05`，CPU 参考与 GPU 推进各连跑 10 步；
   - 逐活跃索引比对位置 / 速度 / 年龄 / 寿命，阈值 1e-5；并验证 `dt = 0 / 负值 / NaN` 一律拒绝。
