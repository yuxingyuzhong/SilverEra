## 一、发现并修复的缺陷

`Application/Renderer/src/render/Pipeline/core/管线.cpp` 的 `Pipeline_Context::spot_shadow_bind`：

```cpp
if (..., index >= 4)   // 第五百零七轮遗留的硬上限
```

8 瓦片扩容时该处未同步，导致分辨率切换路径在重绑瓦片 4..7 时返回假，
`shadow_resolution_set` 按失败回滚，分辨率停留在 1024（新用例首跑即暴露：
`shadow_resolution()` 仍为 1024）。

修复：改为 `index >= 8`，并同步注释（第五百一十三轮扩为 8 元素）。

## 二、测试层改动

1. 抽出 `write_eight_spot_level()`：单一大地面（24×10）＋ 8 个遮挡体，共 9 个绘制项，
   且无其它前向灯（保证 8 盏聚光全部登记）；
2. 新增 `关卡八盏聚光分辨率切换`：8 盏全部投影，1024 → 512 → 1024；
   断言分辨率回读正确、切回后画面逐字节一致（往返差异 **0**）；
3. 新增 `八盏聚光运行期开关`：单盏 → 运行期切 8 盏 → 切回；
   八盏与单盏差异 **865 像素**，切回差异 **0**；
4. 原八盏阴影 / 开销用例改用共用关卡函数，绘制项断言 16 → 9。
