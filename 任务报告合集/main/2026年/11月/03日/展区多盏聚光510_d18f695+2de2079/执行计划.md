# 执行计划 · 第 510 轮　展区多盏聚光灯阴影演示

- 起点哈希：Renderer `d18f695`、Test `447b037`（终点 Test `2de2079`）
- 外部库变更：无

## 一、目标

按 `深研预研_展区聚光灯阴影.md` 方案 3，把多盏聚光灯阴影接进展区（光照与阴影区 ③），让参观者直接看到「四根立柱各自投下独立阴影」。

## 二、内容

1. `场景光照.cpp`：把原来的**单盏**聚光灯（14, 9, −10）改为**四盏**，分别位于四根立柱正上方（x = 11.4 / 13.1 / 14.8 / 16.5，z = −10）；
2. 开启 `光照.spot_shadow_enabled = 1` 与 `光照.spot_shadow_all = 1`（四盏各自瓦片）；
3. 单盏强度 1.3 → 0.45、radius 26 → 9、外锥 38° → 34°，避免四盏叠加过曝且光池边界清晰；
4. 方向光阴影保持开启（与聚光阴影并存）。

## 三、验收

1. 展区探针 720 样本失败 0（覆盖与亮度阈值不回退）；
2. 全量回归不回退；
3. 展区静态画面中四根立柱各有独立阴影（由四瓦片各自投影保证）。
