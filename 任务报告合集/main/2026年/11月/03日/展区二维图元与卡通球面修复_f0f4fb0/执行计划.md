# 执行计划 · 展区显示修复（程序化网格展区 ＋ 卡通展区）

- 触发：用户反馈「程序化网格展区里有一些程序化网格只显示出平面图形」「卡通显示展区也疑似有问题」
- 代码版次：Renderer `10f1693`（不改）；Test `92270ec` → 本轮提交
- 影响范围：展示层（`Application/Test/src/主调/能力展示/`），不涉及渲染层与公共接口

## 一、定位结论

1. **展区①（01 程序化网格）**：用户确认扁的是 **平面 / 圆盘 / 三角**。
   三者天生无厚度：环位上统一朝 +Z，绕行时侧看只剩一条薄片，背面又被剔除，故"只显示平面图形"。
2. **展区⑦（07 逐物体卡通）**：球面出现「深蓝大块 ＋ 浅色硬边楔形」，观感像缺面/破裂。
   逐层排查排除：4× MSAA、卡通高光阈值、加法光晕、外扩描边、材质绑定，
   最终确认来自 **甲球单档二值化（toon_steps = 1）**：整球被切成明暗两块、边界是一刀切，
   暗面在蓝色环境光下呈深蓝，亮面为暖色楔块 → 看起来像被削掉一角。

## 二、修复方案

1. 展区①：新增 `资源.双面材质`（`double_sided = true`，关闭背面剔除）；
   平面 / 圆盘 / 三角改用「法线朝环外」的 `绕Y变换`（偏航 = π/2 − 环位角）并绑定双面材质，
   任意绕行角度都能看到完整面；色调仍由逐项 `material_tint_set` 下发。
2. 展区⑦：甲球色阶 `1 → 3`（保留色阶风格，去掉单刀切边界）；
   三球材质 `toon_shadow_tint` 由默认 (1,1,1) 调为 (0.66, 0.70, 0.88)，暗部不过分发黑。

## 三、验收

- 展区①：近景巡查图中平面/圆盘/三角呈完整面，其余七种图元不变；
- 展区⑦：球面明暗过渡分档仍明显，但不再出现单块硬边楔形；
- `Renderer_Showcase_Probe_Test` 4 例 / 720 样本全部通过；
- 全量回归 1350 例通过。
