## 一、交付

新建 `深研预研_聚光灯阴影上限.md`，共四节：

1. **现状事实**：4 张瓦片（0 常驻、1..3 按需）＋ set 1 `binding 9` 四元素 ＋ UBO 384 浮点 ＋ 槽位映射 8 项；
   明确指出「槽位已支持 8 盏，限制只来自瓦片数 4」；
2. **候选方案**：
   - 方案 1：独立瓦片 4 → 8（8 处改动清单：数据结构 / UBO 448 浮点 / 签名 128 / 布局 count 8 / 池 13→17 / 着色器 8 分支 / 建瓦片与释放循环）；
   - 方案 2：`sampler2DArray` 分层（省绑定但需数组目标链路，8 盏内不划算）；
   - 方案 3：单纹理图集（省显存但每瓦片分辨率下降、需子视口目标）；
   - 方案 4：超容量「照明但不投影」兜底；
3. **结论**：8 盏采用方案 1；9–16 盏优先图集；超容量按方案 4 降级，禁止静默裁照明；
4. **实施顺序与验收口径**：五步（数据结构 → 布局 → 着色器 → 瓦片 4..7 → 接入与用例）。
