# 执行计划 · 第 564 轮　材质实例 PBR 覆盖

- 起点哈希：Renderer `20a8e6f`、Test `d0ec91b`
- 外部库变更：无

## 一、目标

方向七候选 1 的 PBR 部分：实例级覆盖粗糙度 / 金属度；语义定为「覆盖即启用 PBR」
（等价模板材质执行 `material_pbr_set`，需场景 `light pbr` 开启才可见）。

## 二、内容

1. `Level_Material` 与 `Material_Instance_Data` 增 `use_pbr / pbr_roughness / pbr_metallic`；
2. 关卡语法 `material … pbr <粗糙度> <金属度>`（顺序在 toon 之后；粗糙度 (0.05,4]、金属度 [0,1]）；
3. 装配复制 ＋ `material_instance_validate` 校验 ＋ 绘制时覆盖 `material_pbr_*` 状态；
4. 用例：往返 / 六种非法（下界 / 上界 / 金属度 / 缺字段 / 重复 / 顺序）/ PBR 生效。

## 三、验收

1 三树零错误；2 关卡 73 / 73；3 PBR 生效差异 > 20 像素。
