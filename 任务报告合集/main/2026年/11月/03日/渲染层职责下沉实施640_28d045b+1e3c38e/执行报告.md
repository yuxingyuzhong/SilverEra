## 一、渲染层最终边界

保留（渲染层应有）：
- 纯数据消费：`Camera_Data / Light_Data / Fog_Data ＋ scene_apply`，`Scene_Data` 兼容入口。
- 资源门面：`mesh_load_obj / mesh_load / mesh_load_sections / material_load_mtl / material_load / texture_* / mesh_unload / material_unload`。
- 绘制登记：`mesh_draw / mesh_draw_range / mesh_draw_sections / mesh_draw_instanced`、文字/UI/后处理。
- 绘制清单契约：`Asset_Scene / Asset_Object / Material_Instance_Data`（句柄由应用层注入，渲染层逐项登记）。
- 格式适配：OBJ / MTL 解析（`obj_mesh_load / mtl_materials_load`）与纹理解码（与 `Mesh_Data / Material_Data` 紧耦合）。
- 粒子：GPU 双缓冲上传、billboard 绘制、深度分桶、混合/深度写入、软粒子深度采样、紧凑与间接绘制、常驻 GPU 推进、发射器/参数配置。

迁出（不再属于渲染层）：
- 关卡文本读写、材质实例 CRUD、T·R·S 变换 → EngineSystem `src/scene/Level/`。
- 场景清单解析 → EngineSystem `src/scene/Manifest/`。
- 场景装配/绘制门面（`level_save/load/unload`、`scene_load/unload/draw`、内部 `asset_scene_build`）→ 应用层 `关卡装配桥` / `scene_bundle_load`。
- 资源缓存与异步（路径键、引用计数、`std::async`）→ 应用层 `资产缓存桥`。
- CPU 粒子模拟（池、发射器、力场、碰撞、生命周期）与数据/校验 → EngineCore `src/core/effect/`；模拟调用 → 应用层 `Particle_Host`。

## 四、行为等价要点

- 关卡文本：`%.9g` 输出、字段顺序、错误口径、失败清空守卫、材质实例上限 256、点光/聚光 8 盏 —— 全部逐行移植。
- 装配顺序：网格 → 材质库 → 实例表 → place 装配；失败按「材质 → 网格」整体回退；实例模板未命中 / `material_instance_validate` 失败同样整体回退。
- 相机校验：`fov ∈ (0, π)`、`near > 0`、`far > near`、正交时 `ortho_height > 0`；失败清空关卡。
- 粒子：池/发射/力场/碰撞/LCG 逐行移植；GPU 同步推进回读后置活跃标记（空闲栈记账改由应用层负责），`gpu_step` 死亡计数与统计保持。
- 运输统计：CPU 模拟的出生/死亡通过 `particle_stats_add` 上报，帧统计 `particle_active` 按绑定活跃标记统计（常驻模式取 GPU 活跃计数）。

## 六、残留说明（明确边界）

- 粒子常驻 GPU 推进（`Particle发射.comp` / `Particle推进.comp` 及其调度）仍由渲染层执行：上层无 GPU 执行能力（层间契约禁止 EngineSystem 依赖渲染层），渲染层定位为「GPU 执行机制」，语义输入（发射器/参数）与状态输出（活跃标记/状态数组）均已归应用层/EngineCore。
- `Scene_Data`（扁平兼容入口）保留在渲染层，供既有调用方；新代码建议使用三组数据 ＋ `scene_apply`。
- `Asset_Scene / Asset_Object / Material_Instance_Data` 作为「绘制清单契约」保留：不含场景管理逻辑，只描述本次要登记哪些绘制项。

## 七、重开发提示（若需从旧版重做）

1. 先建 EngineCore `core/effect`（类型/校验/池），再建 EngineSystem `scene/Level` 与 `scene/Manifest`（逐行移植旧渲染层实现，仅替换日志前缀与路径工具）。
2. 渲染层删除顺序：先删实现（`Level/`、`场景清单加载.cpp`、`Particle/`、`渲染器.cpp` 内装配/缓存/CPU 粒子段），再删公共头声明；`Asset_Scene` 等绘制契约保留。
3. 应用层桥接顺序：`关卡装配桥`（装配/回退/绘制）→ `资产缓存桥`（缓存/异步）→ `粒子模拟`（宿主 + 绑定 + 统计上报）。
4. 用例迁移顺序：系统层新用例 → 关卡用例 → 资产用例 → 粒子用例 → 展示层。
