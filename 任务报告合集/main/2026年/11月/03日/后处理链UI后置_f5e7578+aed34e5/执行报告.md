## 二、实现要点

1. **时序**：`场景 pass → 1..N 级后处理 →（末级结束）→ UI 通道 → 回读 / 呈现转换`；
   UI 通道沿用 `ui_pass_record`（同布局依赖屏障 ＋ `loadOp = LOAD` ＋ 单采样、仅颜色附件），
   故交换链上已后处理好的画面被保留，UI 直接叠在其上。
2. **零回调不改画面**：`ui_callback` 默认空，链路径整段跳过，既有全部后处理用例逐字节不变。
3. **回读口径**：回读发生在 UI 之后，故回读帧包含 UI（与直通路径一致）。
4. **MSAA**：末级可能写多重采样附件并解析到交换链单采样视图；UI 通道仍绘制在单采样视图上，顺序正确。
