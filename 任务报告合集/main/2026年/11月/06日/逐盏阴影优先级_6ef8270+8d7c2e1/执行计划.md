# 执行计划 · 第 709 轮（逐盏聚光阴影优先级 · A2 收尾之二）

> 方向八 A2 收尾：可投影聚光灯超过 8 盏时按优先级取前 8；槽位映射扩到 32 槽，高槽位聚光灯也可投影

| 段 | 内容 | 验收 |
| --- | --- | --- |
| A | 数据：`Light_Data` / `Scene_Data` 新增 `spot_shadow_priority[32]`（默认 0） | 默认全 0 |
| B | 选择：≤8 盏且槽位均在 0..7 时保持「瓦片号 = 槽位」；否则按优先级降序、同分槽位升序取前 8 再按槽位升序分配瓦片 | 默认优先级下与旧口径一致 |
| C | UBO：槽位映射扩到 32 槽（956..979），块 980 浮点（3920 字节）；描述符范围同步 | 构建零错误 |
| D | 着色器：`spot_slot_tile` 访问器读 0..7 ＋ 8..31 两段，`spot_shadow_factor` 支持 32 槽 | 高槽位聚光灯可投影 |
| E | 门面 ＋ 关卡文本：`spot_shadow_priority_set`、`light spot_shadow_priority <槽位 0..31> <值>` | 关卡套件全过 |
| F | 用例：10 盏聚光（提升槽位 8/9 优先级）画面出现差异；越界 / 非法拒绝 | 场景套件全过 |
