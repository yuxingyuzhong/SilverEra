## 二、语义

1. **解除 v1 互斥**：方向光阴影与聚光阴影各自独立，任一/两者开启均可；
2. 聚光阴影开关 + 序号统一编码在 `spot_shadow_params.w`（序号 + 1，0 = 关闭 → 着色器早退）；
3. `cascade_params.x` 只表示方向光阴影是否启用（0 = 着色器 `shadow_factor` 让位），不再兼作聚光模式标记；
4. 第二遍阴影 pass 与方向光同管线、同实例缓冲；签名含聚光矩阵，静态场景仍可复用；
5. 聚光阴影单独开启时不再强制方向光阴影（`scene_apply` 借用管线登记后恢复原开关）。
