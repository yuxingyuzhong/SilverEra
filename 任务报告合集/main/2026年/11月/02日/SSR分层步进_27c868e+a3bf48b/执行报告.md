## 一、实现（`屏幕空间反射.frag`）

| 项 | 内容 |
| --- | --- |
| 粗步进 | 仍按 `post_param.w` 决定步数（8..48）；每步推进 `step_size` 并记录上界 `previous_t` |
| 穿越检测 | 当探针处「表面视深 ≤ 射线视深」即判定穿越（此前只在厚度内才算命中，跨过即漏检） |
| 二分细化 | 在 `[previous_t, current_t]` 内二分 6 次，取最后一次「已穿越」的 `high_t` 作为命中点 |
| 厚度口径 | 细化点仍按「射线视深 − 表面视深 ≤ thickness」判定；不符则把本点作为新下界继续粗步进 |
| 天空 / 越屏 | 细化点落天空 → 抬高下界；越屏 → 跳出细化，以当前上界为准 |

收益：粗步长跨过的远距离反射不再漏检（旧算法要求「同一步内差值 ≤ 厚度」，长距离时几乎不可能命中）。
