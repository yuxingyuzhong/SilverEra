## 一、目标

前两阶段解决了「单个网格 / 单个材质库」，但整套展品仍要逐条手写加载代码。
本轮加入**场景清单**：一份文本描述「用到哪些 OBJ / MTL、每个对象摆在哪」，一次装载整套资产。

## 二、清单格式

```
# 注释
mesh  <网格ID> <OBJ 路径>
mtl   <材质ID> <MTL 路径>
place <网格ID> [材质ID] <x> <y> <z> <sx> <sy> <sz>
```

- 路径相对**清单文件所在目录**；
- `place` 的材质列可省略（下一个标记若能解析为数字，即视为坐标起点）；
- 不支持旋转（有意从简：摆放用位置 ＋ 缩放，旋转留给后续阶段）。

## 四、实现要点

1. **纯解析与资源创建分离**：`scene_manifest_parse` 只做语法与静态引用检查（不碰文件系统以外的资源）；
   门面 `scene_load` 负责调用 `mesh_load_obj` / `material_load_mtl` 并装配 `Asset_Object`。
2. **去重加载**：清单里同一网格 / 材质库只建一次资源，多个 `place` 复用同一句柄（`Asset_Scene.meshes/materials` 也各只记一份）。
3. **失败整体回退**：任一网格或材质库创建失败 → 卸载本次已建的全部网格与材质、清空输出并返回假。
4. **失败清空契约**：`scene_manifest_parse` 内部用一个小守卫（析构时清空），保证任何提前返回都满足「失败时输出为空」。
5. **对象字段**：`Asset_Object { mesh, materials, position[3], scale[3] }`；`materials` 按 OBJ 段序号对齐，可直接喂给 `mesh_draw_sections`。
