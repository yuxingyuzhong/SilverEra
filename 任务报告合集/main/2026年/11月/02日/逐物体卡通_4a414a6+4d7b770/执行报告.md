## 二、实现细节（复开发必读）

1. **通道选择**：卡通用实例属性而非推送常量——推送块已满 144 字节（EXT-04），且卡通参数天然是「逐物体」语义，与 PBR 的既有范式一致。
2. **覆盖标志必须独立**：色阶 0（关闭）与边缘光 0（关闭）都是合法值，不能像 PBR 那样用「参数为 0 即不覆盖」；故用 `w > 0.5` 显式标志，三项整体覆盖。
3. **布局传播是单点改动**：`INSTANCE_STRIDE_BYTES` 被合批相邻判定、阴影签名、实例缓冲容量、每帧上传字节数共同引用；实测仅测试里的手写断言需同步（80 → 96）。
4. **顶点属性按位集裁剪**：`图形管线.cpp` 的 `add_attribute` 只在 SPIR-V 声明的 location 命中时添加；阴影 / 文字 / 后处理着色器未声明 location 8，故不受影响。
5. **回落路径齐全**：`material_bind_set(0)` 与「无效句柄回落」两个分支、以及 `init` 的重置块均清零 `material_toon_*`，保证默认画面逐字节不变。
6. **非法参数**：`toon_steps ∈ [0, 8]`、`toon_rim ∈ [0, 1]`、`toon_specular ∈ [0, 1]`，任一非有限或越界 → `record.toon_override = false`（整组不覆盖）并告警。
