## 一、目标

让同一路径只创建一次 GPU 资源：首次加载登记、重复请求只加引用计数、释放归零才真正卸载。既有加载入口行为不变。

## 三、实现要点

1. **键归一化**：`类型前缀 + ':' + 路径`，分隔符 `'\\' → '/'`、ASCII 字母转小写（非 ASCII 字节原样保留）。
2. **首次 / 命中**：首次走既有 `mesh_load_obj` / `texture_load_file`，成功后登记 `refs = 1`；命中仅 `refs += 1` 并返回同一句柄；**失败不入缓存**。
3. **释放**：`mesh_release` / `texture_release` 按句柄线性查表（条目数很小）→ `refs > 1` 只减计数、归零时删条目并真正卸载；
   未登记句柄按「非共享资源」直接卸载（兼容与 `mesh_unload` 混用）。
4. **生命周期**：`shutdown` 先清两张表再销毁各模块（模块销毁本身已释放资源，表只保留路径键，避免悬空）。
5. **诊断**：`asset_cache_count()` 返回两表条目之和。

## 五、踩坑记录

- 测试里手写 OBJ 时面写作 `f 1/1/1`（引用第 1 个 `vt`），但文件没有 `vt` 行 → 加载器按「索引越界」正确拒绝，表现为共享加载返回假。
  正确写法是 `f 1//1`（`v//vn`）。这条也说明加载器的越界校验是生效的。
