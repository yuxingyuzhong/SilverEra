# 执行计划 · 第 474 轮　聚光灯阴影（方案 A 实现）

- 起点哈希：Renderer `722305a`、Test `7d9ee68`
- 外部库变更：**无**

## 一、目标

按预研方案 A 落地聚光灯阴影：

1. `Light_Data.spot_shadow_enabled`（默认 0）＋ `scene_apply` 透传并懒登记阴影管线；
2. 阴影矩阵：第 1 盏聚光透视（半锥角 = 外锥角、近 0.1、远 = 半径），覆盖 `light_view_proj`；
3. UBO：`shadow_params.x` 兼容聚光开关；`cascade_params.x = 0` 标识聚光模式；
4. 着色器 `spot_shadow_factor` ＋ 聚光两条路径乘阴影；方向光阴影在聚光模式让位；
5. 用例：地面 ＋ 遮挡体，开启前后差异 > 200 像素；关卡 32 / 32。

## 二、验收口径

| 项 | 口径 |
| --- | --- |
| 默认关闭 | 开关为 0 时矩阵 / UBO / 着色器分支不变（全量守护） |
| 生效 | 聚光从上方照地面，遮挡体投影可见（差异 > 200 像素） |
| 构建 | 三树零错误（含着色器编译） |
