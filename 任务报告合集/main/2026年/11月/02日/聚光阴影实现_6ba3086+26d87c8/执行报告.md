## 二、语义

1. 聚光灯阴影**复用**方向光阴影目标（RGBA8 1024²）、阴影 pass、偏置 / 软度 / 分辨率与强度；
2. 矩阵：第 1 盏聚光透视（半锥角 = 外锥角、近 0.1、远 = 半径），写入 `light_view_proj`；
3. 模式信号：`cascade_params.x = 0`；`shadow_factor` 在此模式返回 1（方向光阴影让位），
   `spot_shadow_factor` 调 `shadow_sample(0, 1, ...)` 后按 `shadow_strength` 插值；
4. 默认关闭：`spot_shadow_enabled = 0` 时不改变矩阵 / UBO / 着色器分支（全量守护）。
