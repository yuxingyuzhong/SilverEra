## 三、实现要点

1. **数据复用**：`Level_Data` 直接持有 `Camera_Data` / `Light_Data` / `Fog_Data`，不另立平行字段体系；
   `asset_lines` 保存 `mesh` / `mtl` / `place` 原文（去首尾空白），装载阶段交给场景清单链路。
2. **浮点往返**：统一 `%.9g` 写出。二进制 32 位浮点的 9 位有效数字可唯一还原，故「写 → 读」逐位相等
   （测试用 `memcmp` 逐字段验证，不用近似比较）。
3. **严格解析**：未知段 / 未知键 / 字段数不符 / 非有限值 / 开关非 0-1 / 光源超过 8 盏 / 资产行缺字段 → 拒绝；
   失败时用清空守卫把输出复位（与方向五清单解析同口径）。
4. **多段混合字段**（阴影 / PBR / 卡通 / 点光 / 聚光）用 `floats_read_n`（只读固定个数）与整数解析交替进行，
   最后再读收尾浮点；单字段用 `floats_read`（额外校验「不得有多余字段」）。
5. **写出顺序固定**，未使用的点光 / 聚光槽位不写出（读取后结构回落默认值，语义等价）。
