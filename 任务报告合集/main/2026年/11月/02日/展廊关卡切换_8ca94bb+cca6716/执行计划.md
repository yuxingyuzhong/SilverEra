## 三、语义

1. 关卡文本写在 `out/关卡展示/`（`面板.obj` ＋ `面板.mtl` ＋ `关卡甲.level` / `关卡乙.level`）。
2. 切换：卸载旧关卡全部资产 → 装载另一套（失败时打印日志并保持空场景，不崩溃）。
3. 绘制：`level_transform_build` 逐对象构造矩阵，`mesh_draw_sections` 逐段绑材质。
4. `apply_scene = false`：不覆盖展示层的相机 / 光照 / 雾（这是展示接入的关键）。
