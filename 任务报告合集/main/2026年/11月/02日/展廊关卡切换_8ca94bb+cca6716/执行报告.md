## 三、实现要点

1. **只借资产**：新增 `apply_scene` 开关；展示场景传 `false`，避免关卡文件的默认相机 / 光照 / 雾覆盖展廊全局设置。
2. **关卡文本**：`面板.obj`（XY 四边形，`usemtl 面板材质`）＋ `面板.mtl`；关卡甲三块正立面板、关卡乙四块倾斜面板
   （含 45° / −45° / 30° / −30° 旋转），布局与旋转差异明显。
3. **切换**：每 5 秒 `level_unload` → `level_load`（另一套）；失败打印日志并保持空场景，不崩溃。
4. **绘制**：`level_transform_build` + `mesh_draw_sections`（逐段绑材质）。
5. **已知取舍**：计划写「按键切换」，实现改为**定时切换**（5 秒），避免在展示层引入输入通道；在报告中留痕。
