## 三、关键技术结论（复开发必读）

1. **关卡文本**：浮点一律 `%.9g`；混合字段（阴影 / PBR / 卡通 / 点光 / 聚光）必须「定长浮点 ＋ 整数」分段读取，
   不能一次性吞入后续整数字段（436 轮踩坑）。
2. **失败不改场景**：`level_load` 顺序＝读文本 → 相机校验 → 资产装配 → 应用三组；`apply_scene = false` 供展示只借资产。
3. **装配共用**：`scene_load` 与 `level_load` 共用 `asset_scene_build`，回退逻辑只有一份。
4. **transform**：M = T·R·S，R = Rz·Ry·Rx（度），列主序；零旋转与 `nullptr` 画面一致。
5. **画布一致性**：关卡链路与手工构造帧逐字节 0 差异（430 轮用例长期守护）。
6. **路径编码**：加载入参 UTF-8 → `path_from_utf8`；测试写盘用宽字符；不要用窄 `ofstream` 写中文名（会落盘成乱码名，428 轮教训）。
7. **源文件清单**：Renderer GLOB 增删文件后，`源文件列表.cmake` 会被 CMake 自动改写，**必须提交**（447 轮补入库）；Test 侧同理（427 轮）。
