## 二、语义与口径

- **实例表**：按声明顺序建「实例名 → `Material_Instance_Data`」；模板句柄按**模板材质名**在全部材质库中查找，未命中即整体回退；
- **对象装配**：`place` 材质列先查实例（命中则 `materials = {模板句柄}`、`material_instances = {数据}`），未命中再按材质库 ID 取整组句柄；
- **兼容**：清单文件版（`scene_load`）传空实例声明与空实例名表，行为与旧版一致；
- **拒绝**：`place` 引用未声明实例 → 清单解析阶段拒绝；模板名未命中 → 装配阶段回退并清空输出。
