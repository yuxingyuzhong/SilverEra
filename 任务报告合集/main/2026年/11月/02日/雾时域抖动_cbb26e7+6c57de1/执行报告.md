## 三、实现细节（复开发必读）

1. **参数通道**：`post_extra.x` 仍是雾基准高度（第 404 轮语义不变）；
   `post_extra.y` = 抖动种子（0 = 关闭）；`post_extra.z` = 空间降噪强度（0..1）。
   门面 `post_stage_extra_set(stage, x, y, z, w)` 无需改动（第 401 轮已支持四参）。
2. **抖动相位**：交错梯度噪声 `fract(52.9829189 * fract(dot(coord + 5.588238 * seed, vec2(0.06711056, 0.00583715))))`，
   收进 `(0.02, 0.98)` 避开步边界；同帧空间铺开、跨帧不重复。
3. **降噪**：仅抖动开启时生效，用互补相位 `1 − phase` 再走一遍 `fog_optical`，按强度 `mix(单相位, 两相位均值)`。
   代价为雾段二次步进（步数不变），关闭强度时不进入该分支。
4. **逐字节一致口径**：种子 ≤ 0 时直接走 `phase = 0.5`，与引入抖动前完全同路径（用例实测最大通道差 0）。
5. **着色器产物链路**：spv 由 Renderer 构建树的 `RendererShaders` 目标编译，Test 在**配置期**从该目录拷贝到
   `Application/Test/shaders`。**改着色器后必须先构建 `RendererShaders`、再重配 Test**，否则用例跑的是旧 spv。
