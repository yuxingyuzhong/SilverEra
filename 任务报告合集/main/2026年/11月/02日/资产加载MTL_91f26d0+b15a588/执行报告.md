## 三、实现要点

1. **解析范围**：`newmtl` / `Kd` / `Ks` / `Ke` / `Ns` / `d` / `Tr` / `map_Kd` / `map_Bump`（`bump`、`norm`、`map_bump` 视同）；其余行忽略。
2. **数值钳制**：颜色与不透明度钳到 [0,1]；`Ns` 钳到 [0,1000]；非有限值归 0。
3. **贴图路径**：`map_*` 支持 `-bm 1.0 tex.png` 这类选项，取最后一个非选项标记为路径；路径原样保留（相对目录由门面解析）。
4. **字段换算（门面）**：
   - `tint = Kd`，`tint.w = d`；
   - `pbr_roughness = √(2 / (Ns + 2))`，下限 0.06（材质层合法域是 (0.05, 4]，恰为 0.05 会被判非法）；
   - `pbr_metallic = 0`（OBJ 材质库无金属度语义）；
   - `emissive = Ke 亮度`（钳到 [0,1]）；
   - `d < 0.999` → `alpha_cutoff = 0.5`（材质层无整体透明度字段，用裁剪近似）。
5. **贴图**：`map_Kd` → `texture_load_file` → `data.texture`；`map_Bump` → `data.normal_texture` ＋ `normal_strength = 1.0`；
   相对路径按「MTL 所在目录 ＋ UTF-8 窄路径」前缀拼接（不做宽窄转换）。贴图解码失败只告警，不阻断材质创建。
6. **失败回退**：任一 `material_load` 失败 → 卸载本次已建材质与纹理、清空输出并返回假。
7. **编码边界（重要）**：门面传给 `texture_load_file` 的是窄字符串，其内部 `ifstream` 走系统代码页，
   故 **中文目录下的贴图在非 UTF-8 代码页会定位失败**；MTL 用例因此放在 `out/asset_test/`（纯 ASCII）。这是已知限制，后续若做「中文资产目录」需给纹理模块补宽路径入口。

## 四、验收实测

| 用例 | 结果 |
| --- | --- |
| MTL完整字段解析 | 2 个材质；首项 Kd=(0.5,0.25,0.125)、Ks=(1,0.5,0)、Ns=96、d=0.5、map_Kd=tex.bmp、map_Bump=nrm.bmp；次项全缺省 |
| MTL缺省值与Tr换算 | Tr 0.25 → d 0.75；Kd 越界钳制（2→1、−1→0）；Ns 5000→1000 |

| MTL端到端创建材质 | 白色 4×4 BMP ＋ 两个材质（一个带 map_Kd、一个 d=0.6）→ 2 个非零句柄；卸载无残留 |
