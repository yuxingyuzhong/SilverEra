## 二、实现要点

1. **三档并存**：三个卡通材质分别 `toon_steps = 1 / 3 / 0`、`toon_rim = 0 / 0.6 / 1.0`，均带 `tint_override` 保留原配色（否则球变白）。
   绘制时逐球 `material_bind_set`，结束后 `material_bind_set(0)`；区内的**全局**风格化参数（`toon_set` / 暗部色调 / 卡通高光 / 外扩描边）仍由「相机进入本区」驱动，两者叠加。
2. **多材质面板**：`资源.平面`（6 索引 / 两个三角形）在 `mesh_draw_sections(..., 2)` 下按 3 对齐均分，两个三角形各得一段材质（红 / 蓝），直观展示「一个物体多种材质」。
3. **资源所有权**：5 个材质在 `资源构建` 失败即整体返回 false；`资源释放` 逐个卸载并清零，幂等。
4. **标题可读性**：新标题仍为「两位数 ＋ 短名」纯中文，字体无缺字（巡查用例断言 `font_skipped_codepoints == 0`）。
