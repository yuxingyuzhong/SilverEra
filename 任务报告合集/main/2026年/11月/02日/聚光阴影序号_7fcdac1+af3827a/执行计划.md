# 执行计划 · 第 479 轮　聚光灯阴影序号选择

- 起点哈希：Renderer `66ff20e`、Test `d2c9c69`
- 外部库变更：**无**

## 一、背景

474 轮的方案 A 固定「第 1 盏聚光灯」投影，且着色器对**每一盏聚光灯**都套同一张阴影图：
多盏聚光时第 2、3 盏会被第 1 盏的阴影错误遮蔽。本轮修正该缺陷并开放序号选择。

## 二、目标

1. `Light_Data` 新增 `int spot_shadow_index = 0`（0..7，指向已登记的聚光灯槽位）；
2. `Impl` 同步；`scene_apply` 越界告警并保持原值；门面新增 `spot_shadow_index_set`；
3. 阴影矩阵分支改用 `point_lights[spot_shadow_index]`（该槽必须是聚光灯，否则按「无聚光阴影」处理）；
4. UBO `spot_shadow_params.w` = 序号；着色器 `spot_shadow_factor(..., int light_index)` 只在
   `light_index == 序号` 时采样，其余聚光灯不套阴影（修复多盏误遮蔽）；
5. 用例 2：两盏聚光各照一块地面 → 序号 0 与序号 1 的画面明显不同；序号越界 → 无聚光阴影。

## 三、验收口径

| 项 | 口径 |
| --- | --- |
| 兼容 | 默认序号 0 时与 478 轮画面逐字节一致（全量守护） |
| 多盏 | 两盏聚光 ＋ 两块遮挡：序号 0 / 1 两图差异 > 100 像素 |
| 越界 | 序号 ≥ 有效聚光灯数 → 无聚光阴影 |
| 构建 | 三树零错误（含着色器） |
| 回归 | 关卡 40 / 40、资产 20 / 20 |
