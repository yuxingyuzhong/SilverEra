## 一、目标

把「单盏聚光灯阴影」扩为「最多 4 盏各自独立阴影」，按 `深研预研_聚光灯阴影多盏.md` 方案 1 落地。

## 二、设计（相对预研的调整）

预研原计划用「单张 1024² 图集 2×2 ＋ 视口分片」，但 `Frame_Context::render_to_target` **不支持自定义视口 / 剪刀**，
故改为「4 张独立 1024² 目标 ＋ binding 9 描述符数组（descriptorCount = 4）」：

| 项 | 设计 |
| --- | --- |
| 目标 | `spot_shadow_targets[4]`，与方向光阴影同参数 |
| 描述符 | set 1 `binding 9` 仍为一条，`descriptorCount = 4`；着色器声明 `sampler2D spot_shadow_map[4]` |
| UBO | `SCENE_BLOCK_FLOATS` 324 → 384（1536 B）：304..367 四份矩阵、368..371 四份跨度、372..379 槽位→瓦片映射 |
| 关卡 | 新增独立行 `light spot_shadow_all <0|1>`；开启时前 4 盏聚光灯依次占瓦片 0..3 |
| 兼容 | 未开启 `spot_shadow_all` 时行为与现状完全一致（单盏 → 瓦片 0） |
| 着色器 | `spot_shadow_factor` 先查槽位映射，按瓦片取矩阵 / 跨度 / 阴影图；四分支显式采样避免采样器动态索引限制 |
