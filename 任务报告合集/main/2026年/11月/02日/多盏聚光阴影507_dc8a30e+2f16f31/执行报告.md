## 一、实现口径（相对预研的调整）

预研方案 1 原定「单张图集 2×2 ＋ 视口分片」，但 `Frame_Context::render_to_target` **不支持自定义视口 / 剪刀**，
故改为 **4 张独立 1024² 阴影图 ＋ binding 9 描述符数组**（同一 binding 的 4 个数组元素）：

| 项 | 落地 |
| --- | --- |
| 目标 | `spot_shadow_targets[4]`，与方向光阴影同参数 |
| 描述符 | set 1 `binding 9`，`descriptorCount = 4`；着色器 `sampler2D spot_shadow_map[4]` |
| UBO | `SCENE_BLOCK_FLOATS` 324 → **384（1536 B）**：304..367 四份矩阵、368..371 四份跨度、372..379 槽位→瓦片 |
| 权限 | 单盏：`spot_shadow_index` 所选槽位 → 瓦片 0（与旧行为一致）；多盏：`spot_shadow_all` 开启后前 4 盏按声明顺序占瓦片 0..3 |
| 关卡 | 新增独立行 `light spot_shadow_all <0|1>`（缺省 0），写出恒写 |

## 四、说明与限制

- **按需创建**：瓦片 0 初始化即建；瓦片 1..3 仅在 `spot_shadow_all` 首次开启时创建，避免未使用多盏时的显存与初始化开销（资源计数默认仍为 2 / 3 / 2）。
- 内存：开启多盏后 4 张 1024² RGBA8 ＋ 深度 ≈ 32 MB；`shadow_resolution_set` 会一并重建已存在的瓦片。
- `spot_shadow_all` 只取**前 4 盏**聚光灯；第 5 盏及以后不投影（与上限一致）。
- 单盏路径保持 `spot_shadow_index` 语义，既有 46 例行为不变。
- 构建环境注意：MSVC 的 `TEMP/TMP` 若指向含中文用户名路径会触发 `cl D8050`；构建时临时指向 `C:\Temp` 即可。
