# 执行计划 · 第 476 轮　聚光灯阴影独立质量参数

- 起点哈希：Renderer `c233577`、Test `63cbb31`
- 外部库变更：**无**

## 一、背景

474 轮的方案 A 让聚光阴影沿用方向光阴影的 `shadow_bias / shadow_softness / shadow_strength`。
但两者投影不同（正交 vs 透视），透视深度精度沿距离剧烈变化，硬边 / 强遮蔽的观感也不一致，
故需要一组**独立**的聚光阴影参数。

## 二、目标

1. `Light_Data` 新增 `spot_shadow_bias`（0..0.05，默认 0.010）/ `spot_shadow_softness`（0..1，默认 0）/ `spot_shadow_strength`（0..1，默认 1）；
2. 门面新增 `spot_shadow_params_set` / `spot_shadow_params_get`（非法值整次忽略）；
3. 场景 UBO 末尾追加 `vec4 spot_shadow_params`（x = 偏置、y = 软度、z = 强度），
   `SCENE_BLOCK_FLOATS` 300 → 304；
4. 着色器：`shadow_sample` 改为显式收偏置 / 软度（方向光调用点传 `shadow_params`，聚光传 `spot_shadow_params`）；
5. 用例 2：强度 0 等价关闭；软度 > 0 产生差异。

## 三、验收口径

| 项 | 口径 |
| --- | --- |
| 默认关闭 | `spot_shadow_enabled = 0` 时 UBO 新字段不改变既有画面（全量守护） |
| 独立生效 | 同一场景仅改 `spot_shadow_strength` → 画面差异明显；强度 0 → 与不开阴影差异 ≤ 2 像素 |
| 独立软度 | 软度 0 vs 0.75 → 硬边 / 软边差异 > 10 像素 |
| 构建 | 三树零错误（含着色器） |
| 回归 | 关卡 36 / 36、资产 20 / 20 |
