## 二、语义

1. 三项与方向光 `shadow_bias / shadow_softness / shadow_strength` **完全独立**，不再共享；
2. 默认值 `0.010 / 0 / 1`：透视深度精度沿距离变化剧烈，偏置默认高于方向光（0.003）；
3. `spot_shadow_strength = 0` → `spot_shadow_factor` 恒返回 1，画面与「未开聚光阴影」等价；
4. 软度沿用方向光的邻域映射（≤0.25 → 3×3、≤0.75 → 5×5、其余 → 7×7）；
5. 方向光阴影路径未变（`shadow_sample` 包装仍取 `shadow_params.y/.w`），既有画面逐字节不变。

## 三、踩坑记录（重要）

UBO 由 1200 扩到 1216 字节后，**管线模块两处描述符 `buffer_info.range` 仍写死 1200**，
导致着色器最后一个 `vec4` 落在范围外：首跑三个聚光用例全部差异 0（阴影完全不出现）。
改正 `range = 1216`（场景集 ＋ 粒子专用集）后恢复正常。结论：**改 `SCENE_BLOCK_FLOATS` 必须同步搜索 `range = 1200`**。
