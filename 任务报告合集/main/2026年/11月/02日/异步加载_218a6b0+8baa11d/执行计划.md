## 一、目标

OBJ 解析是纯 CPU 工作，大模型会阻塞主线程。本轮提供「后台解析 → 主线程建 GPU 资源」的异步入口：

- `mesh_load_obj_async(task, path)`：提交任务，立即返回（解析在后台线程）；
- `mesh_load_obj_async_poll(task, handle)`：主线程轮询；未完成返回假，完成时在当前调用里 `mesh_create` 并写出句柄；
- 任务状态封装为 `Asset_Async_Task`（公共头只暴露 `shared_ptr<void>`，不引 Vulkan 类型）。

## 三、语义约定

1. **提交**：`std::async(std::launch::async, ...)` 执行 `obj_mesh_load`，结果写进任务私有状态；路径非法提交即失败（任务不建立）。
2. **轮询**：
   - 未完成 → 返回假、`handle_out = 0`（调用方下一帧再轮询）；
   - 完成且解析失败 → 返回假（状态记为失败，后续轮询仍返回假）；
   - 完成且解析成功 → 首次轮询调用 `mesh_create` 建资源并缓存句柄，后续轮询直接返回该句柄（幂等）。
3. **线程安全**：解析结果在 `future.get()` 之后才读取（`future` 的同步语义保证先写后读）。
4. **关闭**：`shutdown` 后轮询一律返回假（不触达已销毁的模块）。

## 四、验收口径

| 项 | 口径 |
| --- | --- |
| 异步完成 | 提交后 ≤ 5 秒内轮询到成功，句柄非 0，且可 `mesh_draw` |
| 异步失败 | 不存在路径 → 轮询始终返回假、句柄 0 |
| 轮询幂等 | 成功后再轮询仍返回同一句柄（不重建资源） |
| 构建 | Renderer Debug ＋ Release、Test Debug 三树零错误 |
| 回归 | 本轮套件全过；窗口收口时跑全量 |
