## 一、目标

OBJ 解析是纯 CPU 工作，大模型会阻塞主线程。本轮提供「后台解析 → 主线程建 GPU 资源」的异步入口。

## 三、实现要点

1. **提交**：`std::async(std::launch::async, [state, path]{ return obj_mesh_load(path, state->data); })`；
   空路径 / 未初始化 / `task.state` 已存在 → 提交失败（不覆盖在途任务）。
2. **轮询**（主线程）：
   - `wait_for(0)` 未就绪 → 返回假、句柄 0；
   - 就绪 → `future.get()` 取结果（此后才读 `data`，靠 future 同步语义保证可见）；
   - 解析失败 → 返回假并定案（后续轮询仍假）；
   - 成功 → **首次轮询**调 `mesh_create` 建资源并缓存句柄，后续轮询直接返回该句柄（幂等，不重建）。
3. **线程安全**：`handle` / `built` 只在主线程轮询里写；后台线程只写 `data`（future 先行同步），故无需额外加锁。
4. **生命周期**：`shutdown` 后轮询直接返回假；任务状态由 `shared_ptr` 持有，`std::async` 的 future 析构会等后台线程收尾。
