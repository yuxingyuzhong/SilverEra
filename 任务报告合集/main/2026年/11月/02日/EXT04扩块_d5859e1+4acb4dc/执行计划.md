# 执行计划 · 第 401 轮　EXT-04：后处理推送块扩到 144 字节（自主定案实施）

- 起点：Renderer `d5859e1`、Test `4acb4dc`（2026-11-02 不定期窗口，终点 12:30）
- 前序：第 400 轮已按用户授权把 EXT-04 定为「方案 1：扩 144 ＋ 设备上限降级」

## 一、目标

让后处理链拥有**第四组 vec4（offset 128..143）**，供体积光阴影开关、雾基准高度、各向异性散射等使用，
不再抢占 offset 96（四参）/ 112（颜色四分量）的既有语义。

## 三、验收

1. 单级「反色」链：写合法 extra、写 NaN、写链外级序后，画面逐字节不变（既有片元未声明 offset 128）；
2. `Renderer_Post_Chain_Test.*` 全过；
3. `Renderer_*` 全组 ＋ 非渲染全组回归；
4. 不改变既有阶段语义：未调用新接口时 extra 全零，推送字节数在支持设备上为 64（含尾部 16 字节零）。

## 四、风险与回退

- 设备上限 < 144：布局降为 128 且帧模块只推 48 字节，`post_stage_extra_set` 拒绝写入并记日志（不崩、不出帧错误）。
- 推送字节数变化（48 → 64）只在支持设备发生；尾部 4 个浮点全零，旧片元不读取，故画面不变。
