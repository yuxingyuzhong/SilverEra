## 四、踩坑留痕

1. **Renderers 头快照不随 `RendererCore` 构建刷新**：Test 层用的是 `Application/Renderer/out/build/x64-Debug/include` 快照，
   新增门面后必须额外构建目标 **`RendererIncludeSnapshot`**，否则 Test 报「不是 Renderer 的成员」。
2. **能力展示 10 个新文件带重复 BOM**（`EF BB BF EF BB BF`）：MSVC 报 `xxx.cpp(1,1): error C4430`；已去重为单 BOM（与仓库一致，无 diff）。
3. **后处理链切换后首帧需要预热**：链刚切换的第一帧与后续帧不同（目标布局转换），用例必须先出一帧预热再取基线，
   否则「基线 vs 写 extra 后」会误判为画面差异 192。
4. **同一套件不得混用 `TEST` / `TEST_F`**：gtest 会直接判失败（`All tests in the same test suite must use the same test fixture class`）。
