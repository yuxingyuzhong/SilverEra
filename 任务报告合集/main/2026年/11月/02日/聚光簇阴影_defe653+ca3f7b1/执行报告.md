## 二、修复的真实缺陷

Cluster 记录数组的索引口径是「0 = 方向光、1 = 补光、其后为逐盏」，
而 `spot_shadow_index` 是**前向路径槽位**（0..7）。484 轮着色器在 Cluster 路径直接用记录索引比较，
故开启 Cluster 后聚光阴影完全不生效（实测差异 0）。本轮用 `Light_Record.reserved` 携带前向槽位，
Cluster 与前向两条路径对聚光阴影的判定口径统一。
