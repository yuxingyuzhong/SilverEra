# 执行计划 · 第 488 轮　Cluster 路径聚光阴影

- 起点哈希：Renderer `a36f884`、Test `99639a5`
- 外部库变更：**无**

## 一、问题

Cluster 记录索引（0 = 方向光、1 = 补光、其后为逐盏）与 `spot_shadow_index`（前向槽位）口径不同，
导致 Cluster 开启后聚光阴影不生效（首测差异 0）。

## 二、目标

1. `light_records_get` 为点光 / 聚光记录写 `reserved = 前向槽位`；
2. 着色器 Cluster 路径改用 `light.reserved` 匹配序号；
3. 用例：Cluster 开启后聚光阴影差异 > 100（并与前向路径同值 882）。

## 三、验收口径

| 项 | 口径 |
| --- | --- |
| Cluster 生效 | 开启/关闭差异 > 100 像素 |
| 前向不变 | 474/476/479/484 用例仍全过 |
| 构建 | 三树零错误（含着色器） |
