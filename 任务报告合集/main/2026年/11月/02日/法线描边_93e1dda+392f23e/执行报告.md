## 二、实现要点（复开发必读）

1. **不新增 MRT**：法线由深度反投影重建——`inverse(scene.view_proj) * vec4(ndc, raw_depth, 1)` 再透视除法。
   与 `屏幕空间反射.frag` 同一口径（同一 Scene_Block 声明、同一逆投影方式），故 set0 binding 0 无需任何新增绑定。
2. **逆矩阵只算一次**：`mat4 inverse_view_proj = inverse(scene.view_proj)` 在 `main` 内计算一次，中心与四邻域复用；
   否则每像素 5 次 4×4 逆矩阵会显著抬高开销。
3. **中心法线**：`cross(right − left, up − down)`；朝向相机校正（`dot(normal, camera − center) < 0` 取反）。
4. **折边检测**：中心与相邻两个邻域构成四象限小三角形，各取其法线（同样做朝向校正），
   取四者与中心法线的**最小点积**；`normal_edge = clamp((1 − min_dot) / 阈值, 0, 1)`。
   四个象限保证「任一方向的折边」都会体现在至少一个象限，无需 8 邻域。
5. **深度边缘兜底**：5 点 Laplacian（与 `深度描边.frag` 同口径阈值映射 0.0005..0.05，并按中心深度自适应），
   最终 `edge = max(normal_edge, depth_edge)`——轮廓（深度断层）与折边（法线突变）一并覆盖。
6. **关闭口径**：强度 ≤ 0.0001 或中心为天空（`raw ≥ 0.9999`）直接输出源色；半径 `w = 0` 归一到 1。
7. **NaN 防御**：`safe_normalize`（长度 < 1e-6 回退给定法线），在统一控制流内调用（无提前返回），
   避免邻域被钳到同一像素时 `cross` 为零向量。

## 三、用例与实测数据

| 用例 | 口径 | 结果 |
| --- | --- | --- |
| `法线描边强度为零原样输出` | 强度 0 vs 直通 | 最大差 **0** |
| `法线描边在折边处产生差异` | 折角网格，强度 1 / 阈值 0.10 | 压暗 **102** 像素（窗口 64×36 = 2304） |
| `法线描边与深度描边线条不同` | 同场景两条管线 | 差异 **126** 像素 |
| `法线描边阈值可配` | 0.02 vs 1.0 | 总压暗量 **23940 vs 14688** |
| `法线描边半径可配` | 缺省 0 / 1 / 2 | 缺省差 **0**；覆盖 **102 → 188** 像素 |
| `法线描边天空不描边` | 无几何（深度恒 1） | 最大差 **0** |

阈值用例改口径留痕：初版比较「压暗像素数」失败——深度项与法线项同时生效，且 0.10 阈值下法线项已饱和，
像素数相同；改为比较**整帧压暗量总和**（`darkened_sum`），才反映阈值灵敏度（0.02 阈值饱和 → 压暗量高 63%）。

## 四、性能与边界

- 每像素：1 次 `inverse(mat4)` ＋ 5 次深度采样 ＋ 5 次世界坐标重建 ＋ 4 次叉积；无循环、无额外纹理绑定。
- 边界：屏幕空间法线是**近似**——细物体（小于 2 像素宽）在轮廓处会因邻域跨越而出现法线抖动，可能产生锯齿；
  若需要更稳的描边，需候选 D 原方案（法线 MRT）。
- 与 `深度描边` 并存：两者可串联（法线描边补折边、深度描边补粗糙轮廓）；串联时的取源顺序按后处理链惯例。

## 五、与方向四的衔接

法线描边即卡通渲染的「轮廓线」基础。方向四「逐物体 toon 化」可直接复用本段的折边检测，
把描边参数（强度 / 阈值 / 颜色）纳入逐物体材质字段，实现「不同物体不同轮廓线粗细」。
