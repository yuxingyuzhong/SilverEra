# 执行计划：子部件标识 + 碰撞豁免前移

## 一、目标

1. **对外仍是一角色一碰撞体**：公共 API 只暴露 `collider_ID`，上层管理粒度不变。
2. **对内将每个子部件做成独立碰撞对象**：自碰（同一角色骨骼互撞）由 Bullet 正常检测，穿模问题交给碰撞本身解决。
3. **碰撞信息精确到子 ID**：接触点必须携带 `part_A` / `part_B`，不允许只有碰撞体级信息。
4. **豁免前移到窄阶段之前**：跨碰撞体按“同组对称互免”，同一碰撞体内按“对称子 ID 忽略对”；后置过滤删除。
5. 豁免语义保持对称，绝不引入“A 豁免 B 但 B 不豁免 A”这类决策逻辑。

## 二、为什么不用复合形状

- `btCompoundShape` 的子形状属于同一个 `btCollisionObject`，Bullet 只在不同对象之间建对，同一对象内部子形状永不互测。
- 因此“一角色一复合碰撞体”会结构性关闭自碰，无法满足骨骼防穿模需求。
- 结论：复合形状退出多部件场景。单部件 = 一个对象；多部件 = N 个独立对象，对外仍是一个碰撞体。

## 三、命名与语义

### 3.1 子 ID

- 类型 `uint16_t`，`0xFFFF` 保留为“无子部件”哨兵。
- 几何配置每个元素可选 `part_ID`；缺省按数组序分配 `0..N-1`。
- 同一碰撞体内必须唯一；重复或等于 `0xFFFF` 整条几何配置拒绝。
- 显式配置才有跨重建稳定性；缺省等价于旧的下标行为。

### 3.2 豁免

- 跨碰撞体：现有语义不变，两侧 `exemption_flag` 非零且相等即互免。
- 同一碰撞体内：新增“对称忽略对”集合，键为排序后的 `(较小ID, 较大ID)`，配置即双向生效。
- 两侧语义都是对称的，无方向性、无白名单/黑名单。
- 预过滤统一在 `btOverlappingPairCache::setOverlapFilterCallback` 的 `needBroadphaseCollision` 内完成。

### 3.3 结果

- `Collision_Contact` 增加 `part_A` / `part_B`。
- 离散与扫掠都必须能给出子 ID；新对象模型下命中对象自指针直接携带子 ID，不再依赖 `m_index0/m_index1`。
- 同一碰撞体的自碰允许出现 `collider_A == collider_B` 且 `part_A != part_B`；此时法线不做“由 B 指向 A”的方向约定，按流形原样输出。
- 简略事件 `DetectResult` 的条目扩展为 `collider_A/part_A/collider_B/part_B`，同一自碰按子 ID 对逐条上报。

## 四、数据结构与接口变更

### 4.1 后端对象模型

`Collider_Backend_Impl` 改为持有根变换 + 部件对象集合：

```cpp
//部件碰撞对象（每部件一个，地址稳定，自指针指向自身）
struct Geometry_Part_Object
{
    btCollisionObject object;
    uint64_t collider_ID = 0;
    uint16_t part_ID = 0xFFFF;
    Collider_Backend_Impl* owner = nullptr;
    Geometry_Part_Object() { object.setUserPointer(this); }
};

struct Geometry_Part
{
    uint16_t part_ID = 0xFFFF;
    std::unique_ptr<btTriangleMesh> mesh;   //网格先声明、后析构
    std::unique_ptr<btCollisionShape> shape;
    Transform local_transform = Transform::getIdentity();
    std::unique_ptr<Geometry_Part_Object> object; //堆分配保证自指针稳定
};
```

要点：

- `parts` 用 `std::vector<Geometry_Part>`，内部对象一律 `unique_ptr` 持有，避免扩容搬移导致 `userPointer` 失效。
- 删除 `compound` / `pending_compound` 及复合形状装配分支。
- 新增根变换 `Transform root_transform`；部件世界变换 = `root_transform * local_transform`。
- 新增 `std::unordered_map<uint16_t, uint32_t> part_index`（子 ID → 部件下标），装配与挂载时重建。
- 新增对称忽略集合 `std::unordered_set<uint64_t> part_ignored`，键为 `(minID << 16) | maxID`。
- 新增 `uint64_t exemption_flag`（从仅前端字段下沉到后端，供预过滤读取）。

### 4.2 `Collider_Backend` 公开接口

```cpp
uint32_t part_count(void) const;
bool part_exists(uint16_t part_ID) const;
bool motion_advance(const Motion& motion);                       //改根变换并重算全部部件
bool part_motion_advance(uint16_t part_ID, const Motion& motion);//改局部变换并重算该部件
void exemption_flag_set(uint64_t flag);
uint64_t exemption_flag_get(void) const;
bool part_ignore_set(const std::vector<std::pair<uint16_t, uint16_t>>& pairs);
```

- `world_transform_set/get` 语义改为根变换。
- `aabb_get` 返回全部部件包围盒并集。
- `object_attach/detach` 遍历全部部件对象。
- 单部件不再特殊退化：部件运动改其局部变换，效果等价于整体运动。

### 4.3 前端 `Collider`

- `Part_Motion::part` 由 `uint32_t` 改为 `uint16_t`（子 ID）。
- `exemption_flag` 保留（供镜像/转移复用），写入时同步下发后端。

### 4.4 几何配置新增字段

```json
{
  "geometries": [
    { "type": "box", "half_extent": [..], "position": [..], "part_ID": 3 },
    { "type": "box", "half_extent": [..], "position": [..], "part_ID": 7 }
  ],
  "part_ignore": [ [3, 7], [7, 3] ]
}
```

- `part_ID`：可选，`uint16`。
- `part_ignore`：可选，二维数组；内部按排序去重，重复方向只存一份。

### 4.5 检测结果

`Common/碰撞数据类型.h`：

```cpp
struct Collision_Contact
{
    uint16_t part_A = 0xFFFF;
    uint16_t part_B = 0xFFFF;
    Vector3 point;
    Vector3 normal;
    Scalar depth;
    Scalar fraction;
};
```

- 离散：由流形两侧对象 `userPointer` 反查 `Geometry_Part_Object`，取 `collider_ID` 与 `part_ID`。
- 扫掠：发起方部件在循环内已知；命中方部件由命中对象 `userPointer` 取。
- 新模型下子 ID 恒可得，`0xFFFF` 仅用于非碰撞体对象（空间边界等不产生碰撞对）。

## 五、豁免前移

1. `Region_Backend` 构造时安装自定义 `btOverlapFilterCallback`。
2. `needBroadphaseCollision(proxy0, proxy1)`：
   - 由 `proxy->m_clientObject` 的 `userPointer` 取 `Geometry_Part_Object`；
   - 两对象 `owner` 不同 → 比较 `owner->exemption_flag`，非零且相等返回 false；
   - 两对象 `owner` 相同 → 比较 `part_ignored` 中是否存在该排序对，存在返回 false。
   - 空间边界不参与（边界自身对象无部件身份，且不进入碰撞对枚举）。
3. 豁免配置变更后的刷新：
   - `exemption_flag_set` / `part_ignore_set` 调用 `world->getPairCache()->cleanProxyFromPairs(proxy)` 并 `world->updateSingleAabb`；
   - 或者简单地对全部部件执行 `object_detach` + `object_attach`，强制重建配对（配置变更属低频操作）。
4. 删除 `Collision_Region/core/检测执行.cpp` 的后置豁免过滤整段。
5. 扫掠路径不经过 pair cache，扫掠命中仍需按上述规则在提取阶段跳过被豁免对（扫掠是逐移动体主动查询，不是宽阶段配对）。

## 六、分段执行

### 段 A：后端对象模型改造

1. 部件对象化：每个部件独立 `btCollisionObject`，`userPointer` 指向 `Geometry_Part_Object`。
2. 根变换 + 局部变换传播；`motion_advance` / `part_motion_advance` 重写。
3. `object_attach/detach`、`aabb_get`、`object_contains` 改为多对象。
4. 删除复合形状装配与 `updateChildTransform`。
5. 验收：多部件碰撞体可挂载、可自碰；平移与旋转行为不变。

### 段 B：子 ID 贯通

1. 几何配置 `part_ID` 解析、唯一性校验、缺省分配。
2. 后端 `part_index` 映射；运动接口改子 ID；`part_exists`。
3. 事件 `parts[].part` 语义改子 ID，校验由“范围”改“存在”。
4. 结果回传 `part_A/part_B`；`DetectResult` 条目扩展子 ID。
5. 几何重建清理改为“按子 ID 保留仍存在者”，不再整段清空。
6. 验收：自碰结果能报出具体子 ID；重建后旧子 ID 运动被丢弃、保留者继续生效。

### 段 C：豁免前移

1. 碰撞体级 `exemption_flag` 下沉后端并下发。
2. `part_ignore` 配置与对称去重；后端忽略集合。
3. 安装重叠过滤回调，实现跨碰撞体与同碰撞体两条判断。
4. 配置变更后的配对刷新。
5. 删除后置过滤；扫掠提取阶段补充豁免跳过。
6. 验收：被豁免对不再产生流形（可用流形/接触数量验证），不同组照常。

### 段 D：收口

1. 全量 Debug/Release 构建与测试。
2. Bullet 泄漏门禁（仍只允许 `*/backend/**` 与 `数学转换.h`）。
3. 更新任务报告；项目导航按版次内更新口径另行处理。

## 八、风险与注意

1. **自指针稳定性**：部件对象必须堆分配；严禁把 `btCollisionObject` 直接放进可扩容容器。
2. **反查点同步**：所有 `impl_recover` 调用点都要改为“部件对象反查”，遗漏会导致碰撞对丢失或空指针。
3. **静态标记**：`btCollisionObject` 默认 `CF_STATIC_OBJECT`，仅做碰撞检测不受影响；`BT_DEBUG` 下静态-静态会打印一次告警，属既有现象。
4. **自碰法线**：同一碰撞体的接触没有 A/B 方向语义，需在文档与注释中写死“原样输出”。
5. **配对刷新**：豁免变更后必须清理旧配对，否则旧对持续参与窄阶段，豁免形同虚设。
6. **对象数上升**：一个角色内部对象数等于部件数，宽阶段开销随之上升；由预过滤削减相邻对。
7. **子 ID 稳定性**：依赖外部显式配置；缺省分配在几何数组顺序变化时仍会漂移。
