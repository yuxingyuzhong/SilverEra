# 执行计划：自定义类型命名整改

> 工作区：`白银纪元`；开发落点：`引擎层`（本地 `main` → 远端 `engine`）、`系统层`（本地 `main` → 远端 `system`）、`测试层`（分支 `test` → 远端 `test`）。
> 经用户裁决：本任务**不提交 PR**，直接改本地主分支，验收通过后推送。
> 全部路径均相对工作区根目录。

---

## 一、任务目标

按《agent开发指南·约束/命名约束/变量类型命名约束》「所有自定义类型名首字母大写」，把全项目**历史遗留的小写自定义类型名统一为首字母大写**，并同步全部使用处。

本任务为**字面重命名**：不改任何函数体逻辑、不改事件协议 tag、不改公开接口签名（仅涉类型名，以及随行入库的个别方法名/成员名），日志文本与运行行为保持原样。

## 二、改造范围

### 2.1 类型重命名清单（旧 → 新）

| 链路 | 旧名 → 新名 |
| --- | --- |
| 事件 | `event` → `Event`；`interface_ID` → `Interface_ID`；`attch_handler` → `Attach_Handler`；`event_handler` → `Event_Handler`；`events_handler` → `Events_Handler`；`needed_events` → `Needed_Events`（类型别名） |
| 四叉树 | `tree_state` → `Tree_State`；`tree_chunk_data` → `Tree_Chunk_Data`；`tree_record` → `Tree_Record`；`tree_manager_settings` → `Tree_Manager_Settings`；`Node_type` → `Node_Type`；`recur_record` → `Recur_Record`；`SubRect` → `Sub_Rect`；`range_relation` → `Range_Relation`；`recur_direct` → `Recur_Direct` |
| 随机数 / 碰撞 | `pcg32` → `Pcg32`；`cross_state` → `Cross_State` |
| 系统层 | `effect_group` → `Effect_Group`；`effect_record` → `Effect_Record` |
| 测试层选择器 | `测试选择模型` → `Test_Selection_Model`；`用例条目` → `Case_Entry`；`套件条目` → `Suite_Entry`；中文成员名与 15 个中文函数名同步英文化（详见执行报告） |

### 2.2 随行入库项

- **`Event_Broker` 重构（在建）**：`Event_Identity` 升为 engine 顶层结构体，`std::hash<Event_Identity>` 特化前置，内部表改三表结构（`acl_set` / `mapping_set` / `receivers`），终端接入方法 `info_register` → `attach`。随本版次一并入库。
  - 该重构承载三项**不属于本次命名整改**的标识符变化，故不列入 §2.1 对照表：`event_acl` → `Event_Identity`、`event_entries` → `receivers`（成员）、方法 `info_register` → `attach`。
- **`Config_Loader` 目录搬迁**：`引擎层/src/tools/Config_Loader/` → `引擎层/src/core/config/Config_Loader/`（承前序版次工作区残留的未提交改动，本次一并入库）。

### 2.3 明确不做

- 不改函数体逻辑与事件协议 tag；不改公开接口签名（仅类型名/方法名/成员名）。
- 文件命名维持中文，不改为英文。

## 三、分段执行计划

### 阶段一　引擎层：类型改名 + Event_Broker 重构入库 + Config_Loader 搬迁

覆盖 `引擎层/src/` 下事件系统、对象系统、四叉树两模块、坐标类型与依赖封装、碰撞系统、随机数生成器、工具层（Data_Validator / Logging / Mesh_Loader / Number_Allocator / Timer / Engine_Env / Auxi_Algorithm）与 `Config_Loader`（搬迁后）的全部使用处；`Event_Broker` 按重构后的实现落地。

### 阶段二　系统层：同步类型改名

`系统层/src/` 下实体、属性、效应三体系同步事件链路与 `Effect_Group` / `Effect_Record` 等类型名。

### 阶段三　测试层：同步类型改名与选择器函数名英文化

`测试层/src/` 下单元测试用例与主调选择器（`Test_Selection_Model` 及中文函数名/成员名）同步改名。

### 阶段四　构建回归与文档收尾

三层构建、全量用例回归、清理临时文件；工作站「项目导航」建立本版次、撰写任务报告、更新索引。

## 四、验证方案

1. **分层构建链**（顺序不可颠倒，层间只链接已构建静态库）：
   ```bash
   cmake -S 引擎层 -B 引擎层/out/build/x64-Debug -G Ninja && cmake --build 引擎层/out/build/x64-Debug
   cmake -S 系统层 -B 系统层/out/build/x64-Debug -G Ninja && cmake --build 系统层/out/build/x64-Debug
   cmake -S 测试层 -B 测试层/out/build/x64-Debug -G Ninja && cmake --build 测试层/out/build/x64-Debug
   测试层/EngineTests.exe --selector=off
   ```
2. 每层构建 `error C` 为 0；全量用例通过（基线对比，**不允许回归**）；`ctest` 通过。
3. 重命名为字面替换，旧类型名在源码中残留应为 **0**。
