## 三、`Event_Broker` 重构要点（随行入库）

源码文件：`引擎层/src/core/event/Event_Broker/事件中转器.h`（84 行）、`core/事件中转器.cpp`（244 行）、`局部命名空间使用.h`（19 行）。

- `Event_Identity` 由旧方案升为 engine 顶层结构体（成员 `category` / `tag`，`operator==` 比较两字段），并**前置** `std::hash<Event_Identity>` 特化（`hash_combine` 混合 category 与 tag）。
- 内部表由旧的「`acl_set` 大类行表 ＋ `ID_set`」改为三表：
  - `acl_set`：`unordered_map<Event_Identity, vector<uint64_t>>`（事件键 → 订阅方 ID 列表）；
  - `mapping_set`：`unordered_map<string, uint64_t>`（订阅方名 → ID）；
  - `receivers`：`unordered_map<uint64_t, function<void(shared_ptr<Event>)>>`（ID → 接收回调）。
- 终端接入方法 `info_register` 改名 `attach`，语义扩展为「首次登记 / 更新接收器 / 两参皆空即卸载」。
- 旧语义作废：`vector<uint16_t> acled_IDs` 的类型收缩风险（现统一 `uint64_t`）已消除。
- 详见本版次「项目导航 → 模块架构/事件系统.md」。
