## 五、预期风险与处置

1. **MSVC `std::holds_alternative<0>` 不可用**：本机 MSVC（14.51.36231）对 `holds_alternative<0>(v)` 报模板参数无效 → 一律改用 `v.index() == 0/1`。
2. **退化树 `bad variant access`**：区块边长等于树边长时根节点本身即唯一区块，原查找路径会 `std::get<0>` 失败 → 在 `block_seek` 加退化分支，并在 `child_node_recur` / `tree_expand` 加分支守卫。
3. **测试层链接失败易误判为四叉树问题**：真因是工具目录重组遗留，本轮一并迁移解决。
4. **提交范围甄别**：引擎层 `Engine_Env/引擎环境.h` 属用户在建的逻辑帧率新功能，与本任务无关 → 提交时排除；顶层未跟踪文件 `engine_log_probe.txt` 不提交。
