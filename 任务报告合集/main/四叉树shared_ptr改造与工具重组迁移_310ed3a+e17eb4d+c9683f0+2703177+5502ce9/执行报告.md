## 一、任务内容与最终形态

### 1.1 四叉树改造（用户前置信息 <1><2><3>）

三项改造全部落地：

| 改造 | 最终形态 |
| --- | --- |
| <1> 区块数据所有权 | `Tree_Chunk_Data<T>` 内以 `std::shared_ptr<T> ptr_data` 持有区块数据；树内叶子节点的 `data` 分支同为 `std::shared_ptr<T>`，查找结果对象与树内区块**共享所有权** |
| <2> 查找参数 | `block_seek(std::shared_ptr<Tree_Chunk_Data<T>>& receiver, ...)`、`range_seek(std::vector<std::shared_ptr<Tree_Chunk_Data<T>>>& receiver, ...)`；裸指针参数全面退场 |
| <3> 内部节点 | `Node::data` 由原始 `union` 改为 `std::variant<std::array<Node*,4>, std::shared_ptr<T>>`：**分支 0** = 四路子节点指针（中间节点），**分支 1** = 区块数据（叶子节点） |

关键实现细节（供快速重开发）：

1. `函数预声明.h`：`Node` 为 `Quadtree<T>` 的嵌套 `struct`（不再自带模板参数，凭外层模板取到 `T`）；构造函数按 `Node_Type` 用 `data.template emplace<0/1>(...)` 初始化对应分支；类内补回私成员 `Node root;`。
2. `数据结构.h`：`Tree_Chunk_Data<T>` 增 `std::shared_ptr<T> ptr_data = nullptr;` 与三参列表构造 `Tree_Chunk_Data(float x, float y, std::shared_ptr<T> ptr)`。
3. `core/区块信息检索.hpp`：
   - `block_seek` 新增**退化树分支**（`recur_level_max == 0`，即树边长等于区块单元）：根节点本身即唯一区块。若不处于区块分支则先 `emplace<1>` 分配；接收器为空则用 `new(std::nothrow)` 分配；`receiver->ptr_data = std::get<1>(root.data)`；中心坐标由 64 位范围以双精度求中点。
   - 常规路径末段 `receiver->ptr_data = std::get<1>(child_node->data);`。
   - `range_seek` 收集段改为构造 `std::shared_ptr<Tree_Chunk_Data<T>>` 并 `push_back`，其 `ptr_data` 取自 `std::get<1>(child_node->data)`。
4. `core/节点创建与树扩大.hpp`：`child_node_recur` 与 `tree_expand` 各加**分支守卫**——若当前节点处于区块分支（`data.index() == 1`）却需要子节点，先 `data.template emplace<0>(std::array<Node*,4>{nullptr,...})` 转为中间节点；子节点列表统一以 `std::get<0>(...)` 取得。
5. `core/设置与交互.hpp`：`unload` 的叶子分支删去手工 `ptr_now->leaf.~T()`，注释改为「区块数据由叶子持有的 `shared_ptr` 随节点析构自动释放」，仅 `delete ptr_now;`。
