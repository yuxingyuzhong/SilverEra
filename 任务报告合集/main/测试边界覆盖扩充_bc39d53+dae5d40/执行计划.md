# 执行计划 —— 测试边界覆盖扩充

## 一、任务目标

大幅增加测试用例，全方位提升边界覆盖度，目标用例总数 500+。
当前基线：350 例 / 22 套件，全通过（其中 `Quadtree_Test.退化树查询直接返回` 因用户在建的四叉树改动而失败，与本任务无关）。

## 二、范围与约束

1. 前置约束：用户正在并发修改四叉树与四叉树管理器，故**不改动**以下文件及其测试：
   - `引擎层/src/core/spatial/partition/Quadtree/**`
   - `引擎层/src/core/spatial/partition/Quadtree_Manager/**`
   - `测试层/src/单元测试/核心/四叉树测试.cpp`
   - `测试层/src/单元测试/核心/四叉树管理器测试.cpp`
2. 引擎层源码一律不改动；测试层只编译、链接既有 `EngineCore.lib`，**不重建引擎层**（避免编译用户在建的四叉树改动）。
3. 本轮不建立项目导航。
4. 遵循《agent开发指南》风格约束：中文注释、`<3` 行用 `//`（`//` 后无空格）、`>=3` 行用 `/**/`、一律换行注释；变量/函数下划线小写、动词后置；自定义类型名英文首字母大写；UTF-8。

## 三、实现方式

### 阶段一：为完全无测试的模块新增测试文件（4 个）

| 新增文件 | 被测接口 | 计划用例 |
|---|---|---|
| `测试层/src/单元测试/工具/哈希混合测试.cpp` | `engine::detail::hash_combine` | ~12 |
| `测试层/src/单元测试/工具/字段校验测试.cpp` | `engine::detail::field_check<T>` | ~24 |
| `测试层/src/单元测试/工具/路径校验测试.cpp` | `engine::detail::path_check` | ~12 |
| `测试层/src/单元测试/核心/碰撞体测试.cpp` | `engine::Collider` 搬移语义/挂载/反查 | ~14 |

要点：
- 哈希混合：确定性、种子被改写、零值、相同输入相同输出、不同输入大概率不同、连续调用累积、与位运算的稳定性。
- 字段校验：bool/整型/浮点/字符串/容器四类萃取；缺字段、类型不符、空字符串、空数组/对象、嵌套、边界数字。
- 路径校验：`path` 与 `string` 两个重载；空路径、不存在路径、目录路径、常规文件路径、相对/绝对路径。
- 碰撞体：默认构造反查自指针、移动构造后自指针重挂且源被清空、移动赋值、自赋值、`mounted_shape` 无部件返回空、`recover` 往返。

### 阶段二：扩充工具层现有套件（8 个）

`数值分配器测试`、`二分查找测试`、`路径字符串转换测试`、`随机数生成器测试`、`计时器测试`、`日志系统测试`、`网格加载器测试`、`数据校验器测试`，各补边界/异常/极值用例。

### 阶段三：扩充核心层现有套件（6 个）

`坐标类型测试`（含 ULP/NaN/无穷/往返转换边界）、`对象测试`、`对象池测试`、`事件测试`、`事件中转器测试`、`事件终端测试`。

### 阶段四：扩充主调与碰撞套件（3 个）

`测试选择模型测试`、`退出暂停判定测试`、`碰撞测试`（不含四叉树）。

## 四、分段执行与验收

1. 每完成一阶段：构建测试层（`cmake --build 测试层/out/build/x64-Debug`）→ 运行 `EngineTests.exe --selector=off` 全量回归。
2. 用例总数达到 500+ 且除既有的四叉树 1 例失败外无新增失败。
3. 完成后：测试层提交推送 `sliverera/test`；顶层快照提交推送 `origin/main`；工作站更新「执行报告.md」「报告提交历史.md」并推送 `origin/doc`；清理临时文件。
4. 本任务不产出引擎层改动，故不推送 `sliverera/engine`。
