# 拆分碰撞代理器与碰撞空间实现文件（单编译单元 → 多编译单元）

## 一、目标与验收标准

**目标**：把两个过长的实现文件拆成多个短文件，使单文件规模从 800～950 行降到 90～290 行量级；**不改变任何对外行为、不改变任何接口签名、不改变任何日志文本**。

| 目标文件 | 现状 | 拆后 |
| --- | --- | --- |
| `引擎层/src/core/spatial/collision/Collision_Proxy/core/碰撞代理器.cpp` | 919 行 | 删除，拆为 `core/` 下 5 个 `.cpp` |
| `引擎层/src/core/spatial/collision/Collision_Region/core/碰撞空间.cpp` | 839 行 | 删除，拆为 `core/` 下 4 个 `.cpp` |

**验收标准**
1. 引擎层增量构建 `exit=0`，告警与基线逐条一致（无新增）。
2. 测试层构建通过，全量回归 **338 PASSED / 0 failed / 0 DISABLED**，`ctest` 1/1。
3. `EngineCore.lib` 的**外部符号集合**改动前后完全一致（证明纯搬运）。
4. 两个模块目录下的 `.h` 与 `局部命名空间使用.h` 内容不变 → 系统层、游戏层、测试层调用方零改动。

## 二、已确认事实（本轮实测，非推断）

| 事实 | 依据 |
| --- | --- |
| 对外消费方只有两处 | 全仓 `grep -rn` 源码：`引擎层/src/core/spatial/common/碰撞系统运行包.h` include `碰撞空间.h`；`测试层/src/单元测试/核心/碰撞测试.cpp` include `碰撞代理器.h` |
| 系统层、游戏层对碰撞两模块零引用 | 同上 grep，无命中 |
| 两个 `.h` 是纯声明 | `碰撞代理器.h` 100 行、`碰撞空间.h` 125 行，无内联函数体 |
| 构建无需改 CMake | 引擎层 `file(GLOB_RECURSE ... CONFIGURE_DEPENDS "src/*.cpp")`；测试层同理，新增 `.cpp` 自动纳入 |
| 普通类不能照搬四叉树的拆法 | 四叉树两模块是模板类，`core/*.hpp` 由伞头文件 include；本两模块是普通类，实现若进头文件会重复定义，故实现必须落在 `.cpp` |
| 匿名命名空间辅助的使用者集中 | Proxy：`text_read` 仅服务 `region_boundary_set`/`config_apply`；`number_read`/`vector_read` 仅服务 `collider_config_apply`。Region：`Swept_Collector`/`pair_normalize`/`pair_unique` 仅服务 `detect`；`memory_malloc` 仅服务形状构建 |
| 行尾 | 引擎层存在 `autocrlf` 归一，改动后按仓库既有规则入库 |

## 三、拆分方案

**分组原则**：匿名命名空间的辅助只与它的使用者同文件（不把文件内部实现提到头文件，不让多 TU 各自持有同名辅助）；除分组归属外，**函数体一行不改**。若某个文件实际落到 120 行以下或 300 行以上，执行时在相邻分组间挪动一到两个函数，并在执行报告中如实记录。

### 3.3 不变量（必须始终成立）

1. `碰撞代理器.h` / `碰撞空间.h` / 两个 `局部命名空间使用.h` 内容不变。
2. 每个新 `.cpp` 顶部只加最小 include 集：`"../局部命名空间使用.h"` ＋ 该文件用到的工具头（`数据校验器.h` / `日志系统.h` / `网格加载器.h`）。
3. 所有函数体、日志字符串、`Log::warn` / `Log::error` / `Log::debug` 文本逐字保持。
4. 不新增、不删除、不改名任何类与函数；不调整类成员顺序。
5. 不新建测试用例（本次无新功能，按开发指南「未形成完整功能则略过测试」），以既有 338 条用例全量回归作为验证。

## 五、风险与回退

| 风险 | 处理 |
| --- | --- |
| 遗漏函数导致链接错误（`LNK2019`） | S2/S3 后全量构建暴露缺漏；另以「原文件函数总数 vs 新文件函数总数」逐条核对 |
| 辅助函数跨文件引用导致编译失败 | 已在 3.1/3.2 按使用者归组；若执行中发现跨组引用，就地调整分组（优先挪函数，不提高辅助可见性） |
| include 过少导致编译错误 | 以构建报错为准逐文件补最小 include，不批量复制整套 include |
| 符号集出现差异 | S6 逐条定位；若差异来自**可见性变化**（如某函数被移出匿名命名空间），立即修正后重跑 S4～S6 |
| 拆分引入行为变化 | 无逻辑改动为前提；338 用例全过 ＋ 符号集一致双重证据。任一不达标即 `git revert` 本次提交，不做局部补丁 |
| 行尾归一造成 diff 噪声 | 提交前 `git diff --stat` 确认改动行数与预期相符，噪声文件单独说明 |

**回退方式**：改动集中在引擎层单次提交内，回退即对该提交 `git revert`，不触碰测试层与工作站既有记录。
